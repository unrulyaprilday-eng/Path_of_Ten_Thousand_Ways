# 数值、历练所得与局外解锁

> 本文集中管理 DEMO 的数值调优入口、世界内所得规则和局外解锁边界。数值服务修行经历，不能重新把游戏拉回通用货币、逐战掉卡和永久数值碾压。

## 1. 数值原则

- 单局修行与规则联动是主要强度来源。
- 境界保证基础能力成长，道基、心法、法诀和法器决定构筑倍率。
- 数值表是 `DEMO tuning`，不是完整版本最终平衡。
- 同一个数值只能在本篇或配置真源中定义一次，其他文档只引用。
- 品阶决定能力成长空间；出现频率由具体场景、条件和事件池决定，不使用独立彩色稀有度掉落表控制沉浸体验。

## 2. DEMO 调优入口

### 2.1 构筑规模

| 项目 | DEMO tuning |
| --- | ---: |
| 开局本命法器 | 1 件：残剑胚 |
| 开局心法 | 1 部：旁支吐纳法一阶 |
| 开局主动法诀 | 2 门 |
| 最终主动法诀 | 通常 6-9 门 |
| 主修心法 | 1 部 |
| 正式后获法器 | 由境界和规则限制，避免堆叠 |

### 2.2 境界基准

| 境界 | 灵力上限 | 初始灵力 | 灵力获取系数 | 法诀通用威力系数 |
| --- | ---: | ---: | ---: | ---: |
| 炼气 | 5 | 3 | 1.00 | 1.00 |
| 筑基 | 8 | 4 | 1.25 | 1.50 |

筑基还必须获得一条道基规则；上表的数值提升不能代替规则提升。灵力基础自然增长以每秒 1 点为调优起点，最终由心法、状态和境界系数共同结算。

### 2.3 半实时节奏基准

| 项目 | DEMO tuning |
| --- | ---: |
| 本命残剑基础攻击冷却 | 2.2 秒 |
| 基础抽取间隔 | 4 秒 |
| 手牌上限 | 6 |
| 临时飞剑生命周期 | 参与 3 次齐射后消散 |
| 普通敌人意图 | 5-7 秒 |

牌库较小时，开局手牌直接包含两门初始法诀。终局 6-9 门指整副法诀牌库总量，任一时刻最多展示 6 张手牌；其余法诀通过抽取、弃置和洗回循环进入手中。抽取计时和强法冷却共同控制重复使用频率，不能靠加入填充牌拖慢循环。

### 2.4 费用预算

费用和冷却分别回答“当前能否支付”和“强效果能否连续出现”。DEMO 优先使用 0-5 费：

| 费用 | 预算倍率 | 定位 |
| --- | ---: | --- |
| 0 | 0.6 | 轻量启动与修正 |
| 1 | 1.0 | 基础操作 |
| 2 | 2.0 | 标准主力 |
| 3 | 3.0 | 核心效果与组合件 |
| 4 | 4.0 | 高价值组件 |
| 5 | 5.0 | 爆发与规则效果 |

更高费用只用于后续神通或特殊终局内容，不作为 DEMO 常规牌库填充。

### 2.5 伤害与敌人参考

| 境界 | 普通攻击 | 强力攻击 | 终结技 | AOE 单目标 |
| --- | ---: | ---: | ---: | ---: |
| 炼气 | 6 | 12 | 24-36 | 4 |
| 筑基 | 12 | 24 | 48-72 | 7 |

| 境界 | 普通怪生命 / 攻击 | 精英生命 / 攻击 | Boss 生命 / 攻击 |
| --- | --- | --- | --- |
| 炼气 | 20-40 / 3-8 | 80-120 / 8-12 | 250-400 / 12-18 |
| 筑基 | 50-100 / 8-15 | 180-300 / 16-24 | 600-900 / 25-40 |

多敌人遭遇按整组威胁预算分配，不能给每名敌人都套用单敌遭遇上限。小 Boss 和最终 Boss 还需结合阶段、部位与召唤物单独分配预算。

防御与回复的相对基准：

- 护体约等于同级普通攻击伤害的 `0.8`。
- 治疗约等于同级普通攻击伤害的 `0.6`。
- 单一常规减伤来源上限 `50%`。
- 反伤参考承受伤害的 `10%-40%`。
- 吸血参考造成伤害的 `5%-20%`。

## 3. 历练所得

玩家获得能力的第一责任人是场景和经历，不是通用掉落页。

| 来源 | 可提供内容 | 叙事职责 |
| --- | --- | --- |
| 普通战 | 线索、短期恢复、少量材料性结果；不保证新法诀 | 消耗状态并推进地区威胁 |
| 精英战 | 特殊器物、残卷、妖核、关键线索 | 风险换取独特修行条件 |
| 小 Boss | 本命炼形、心法进阶或筑基条件 | 完成本幕构筑里程碑 |
| 修炼地 | 调息、参悟、淬炼、斩旧、易式、祭炼 | 让成长发生在具体地点 |
| 洞府 / 秘境 | 心法、法诀、道基线索、特殊试炼 | 提供发现与领悟 |
| 奇遇 | 人物关系、精怪、残魂、旧契与代价选择 | 写入经历标记并改变后续内容 |
| 秘藏 | 稀有器物、禁术、隐藏路线条件 | 高风险高价值发现 |
| 最终 Boss | 一世结算、故事结果和局外解锁 | 不再发放本局无法使用的构筑奖励 |

## 4. 内容投放与保底

内部仍可使用标签、权重和保底，但不得在前台显示系统槽位或通用掉落概率。

- 每个能力至少有职责、流派、来源、阶段和前置标签。
- 同一事件和唯一能力一局内默认不重复。
- 每幕至少提供一次与当前构筑相关的成长机会。
- 连续错过关键循环时，后续合法场景提高补缺机会，而不是凭空把卡塞入战利品。
- 第二幕必须存在可达的筑基保底方案；特殊经历只解锁更有个性的筑基方式。
- 最终 Boss 前必须能形成自动攻击、灵力循环、主动介入和一次明确爆发，但不要求每局拿到同一组能力。
- 保底只保证“存在合法机会”，玩家仍可因路线和选择主动放弃。

权重模型可保留为内部机制：

```text
机会最终权重
= 基础场景权重
+ 当前心法 / 法诀 / 法器标签
+ 境界与构筑缺口修正
+ 经历标记修正
+ 连续未出现保底修正
```

手工地图约束、故事层位和前置条件始终高于随机权重。

## 5. 无货币代价

DEMO 不使用通用货币，不设置固定商店节点。强力机会通过世界内代价平衡：

- 损失当前或最大气血。
- 封存、移除或转化一门法诀。
- 获得临时负面法诀或持续状态。
- 牺牲、污染或改变当前法器。
- 强化下一场敌人或改变 Boss 阶段。
- 放弃下一次成长机会。
- 进入更危险、隐藏或不可回头的路线。
- 写入会改变人物关系、事件池、隐藏节点、Boss 或结局的经历标记。

代价在选择前说明直接影响；远期因果可以隐藏，但必须提前留下可被理解的伏笔。

## 6. 图鉴与局外解锁

局外系统只记录见闻、解锁内容和提供选择空间，不保存永久攻击、生命、境界或通用货币优势。

### 6.1 记录内容

- 根脚、开局故事与曾携带的本命器。
- 遇见和学会过的心法、法诀、法器与道基。
- 普通敌人、精英、小 Boss、最终 Boss 和已发现部位。
- 事件、人物、精怪、隐藏节点、经历标记与不同结局。
- 一世完成时的牌库、心法、法器、筑基方式和关键经历。

### 6.2 解锁内容

- 新事件、隐藏路线和境域内容。
- 新根脚、本命法器起点或开局故事变体。
- 新心法、法诀和法器进入对应世界来源池。
- 敌人情报、事件线索、外观和挑战条件。
- 不增加战力的传承道痕或重铸机会。

图鉴信息按经历逐步揭示：首次遭遇显示名称和形象，击败后显示基础行为，重复经历或相关事件再解锁弱点和背景。

## 7. 设计底线

- 不恢复灵石、悟道石、商店刷新或固定商店价格。
- 不恢复普通战后固定三选一加牌。
- 不用品质颜色和固定稀有率替代世界来源。
- 不把炼气、筑基等境界作为局外永久等级。
- 不让图鉴和局外解锁直接增加攻击、生命或灵力。
- 不以“单局 3000%-5000%、永久 300%”等宏观倍率代替可验证的 DEMO 调优。
