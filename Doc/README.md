# 修仙肉鸽卡牌 RPG 设计文档目录

## 当前执行锚点（2026-07-14）

当前 DEMO 只打透一条 15-18 分钟纵切：

    开卷 / 道痕整备
    ↓
    定根脚：只开放「世家旁支」
    ↓
    所携：只开放「残剑胚」
    ↓
    所往：只开放「旧矿地窟」
    ↓
    入场首战
    ↓
    战后所得
    ↓
    三层前路与逐战奖励
    ↓
    天劫化身
    ↓
    一世结算
    ↓
    再启一世

其他根脚、所携器物和地图继续展示，但必须明确锁定且不可进入。新逻辑统一使用 DemoJourneyVesselDefinition、OpeningSelection.Vessel 与 SetVessel；旧 JourneyLine / Relic 只保留配置与存量代码兼容，不再作为 P0 新逻辑或前台奖励类型。

战斗主定义是持续演算的半实时斗法：

- 阶段只保留 Intro / Running / Won / Lost。
- 初战 1 灵气、3 张手牌；普通战 2 灵气、4 张手牌；灵气上限 10，每秒恢复 1。
- 手牌上限 7，每 4 秒抽 1 张；满手时抽牌计时暂停。
- 飞剑每 2.2 秒自动齐射；临时飞剑参与 3 次齐射后消散。
- 敌人按 5-7 秒意图读条行动；Boss 使用三阶段读条和蓄雷爆发窗口。
- 玩家点击卡牌后立即结算并进入弃牌堆，不再存在规划队列、结束规划、自动规划或固定回合结算。

成长强制门槛：

| 阶段 | 必须成立 |
| --- | --- |
| 初战前 | 1 把飞剑、5 张基础牌；无主修、正式法器、遗珍或终结牌 |
| 首战所得 | 固定「凝剑诀 / 踏云遁 / 聚灵换息」；凝剑诀未选则进入后续保底 |
| 第一层末 | 启动牌与至少 2-3 个万剑组件；禁止神通和终结牌 |
| 第二层 | 必有「小诛仙剑阵」，并有「御剑诀」或「剑匣」至少一个 |
| 第三层 | 必出现「万剑诀」；高风险路线可额外获得「万剑归宗」 |
| Boss | 形成飞剑增殖、剑意积累、剑阵运转与一次明显爆发 |

最新版开局规则覆盖所有旧首战口径：凝剑诀不在初始牌组，只属于首战奖励与后续保底。每场战斗胜利先播放约 1.2 秒破敌反馈，再自动进入战后所得；地图不再插入独立的通用奖励节点。

局外闭环只做版本化 DemoMetaProgress：记录通关数、Boss 胜利、图鉴与解锁 ID，不保存局内战力或中途存档。首次击败天劫解锁「残剑道痕」，下一世可让首战所得重铸一次，不增加永久攻击或生命。
