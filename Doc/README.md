## 1. 当前设计锚点

当前 DEMO 要做透一条约 30-40 分钟的旧矿修仙纵切：

```text
沉浸式开局：根脚与所携合并
    -> 选择所往：旧矿地窟
    -> 第一幕：浅层矿道，6-8+ 个实际节点，怪兽小 Boss
    -> 第二幕：塌井与矿契，6-8+ 个实际节点，怪兽小 Boss
    -> 故事场景中炼气突破筑基
    -> 第三幕：剑炉与封契，6-8+ 个实际节点
    -> 最终 Boss：玄铁镇矿剑傀
    -> 依据本局经历结算一世因果
```

本轮已经锁定的方向：

- 同一个大境域逐幕深入，地图从下向上推进；标准路径每幕实际经过 7-8 个节点，合法范围 6-10 个。
- 地图采用手工骨架与种子变化。整体结构、幕职责和关键节点稳定；具体内容、顺序、左右位置和合法连线在约束内变化。
- 战斗/精英与事件/修炼/秘藏约各占一半，第一、二幕可以加入怪兽型小 Boss。
- 当前纵切不用通用货币、商店节点或灵石商店；获取与消耗都放回具体事件和修炼场景。
- 开局不是五张基础牌。玩家携带本命法器 `残剑胚`、一阶心法 `旁支吐纳法` 及其心诀、初始剑诀 `残卷御剑式`；只有两门主动法诀，本命法器按独立 CD 自动攻击。
- 法诀、心法升级、本命法器炼形和筑基条件都在剑洞、残卷、人物、秘境、小 Boss 或因果事件中获得，不使用悬空的逐战通用三选一。
- DEMO 局内完成一次 `炼气 -> 筑基`。境界统一提升灵力循环与已学法诀的通用成长，道基再根据本局经历提供一条规则变化。
- 支持有限多敌人，采用自动攻击与点击锁定；群攻、连锁和万剑按规则扩散，目标死亡自动转移。
- 普通战主角位于左下，以黑白长发男性三分之四背视角朝右上攻击；最终 Boss 位于正上方压屏。只在终极技、击杀和必要的 Boss 阶段转换时短促推镜。
- 整体视觉为黑白冷墨，青绿、朱砂和冷白雷光点色；米黄只用于局部纸张、符签和卡牌，不做全屏底色。
- 天劫不作为当前 DEMO Boss，保留给完整版本终局或隐藏挑战。

## 2. 实现状态说明

截至 2026-07-22，目标纵切已经成为可运行主流程，而不再只是迁移契约：沉浸式开局、所往选择、手工骨架加种子变化的三幕旅程图、事件与修炼、两只怪兽小 Boss、故事化筑基、筑基后多目标战、玄铁镇矿剑傀三阶段和一世结算均可确定性走通。地图会把完整节点与边快照写入 `DemoRunSaveV2`，旧 V2 仍可按种子回退恢复；隐藏节点、矿灵因果和结局读取具体经历标记。

战斗运行主体已支持 1-3 个独立目标、独立意图、点击锁定、死亡换目标和遭遇组配置。普通战使用左下到右上的斜向构图，最终 Boss 使用正上方压屏构图；残剑胚独立 CD、心法、法诀、筑基规则和剑傀甲片/契钉/核心阶段已接入。新流程不再进入固定路线卡、通用商店、逐战悬空三选一或天劫 Boss。

当前已经有 18 张连续 Unity 运行截图覆盖首页到结局，并含 `1920x1080`、`1280x720` 多目标战和两只怪兽小 Boss 专项画面。正式接入的首批资源包括旧矿战斗远景、黑白长发男性主角、铁脊矿兽、吞剑矿魈和玄铁镇矿剑傀。剩余工作主要是 P1/P2 表现扩充、地图/事件插画、承载物与 VFX 正式资源，以及删除仍为旧页面服务的兼容代码；具体状态以 `10` 和 `11` 为准。

## 4. 推荐阅读顺序

每次任务先读本文，再按任务选择：

- 项目定位或范围判断：`00` -> `01`。
- DEMO 流程、地图、节点或叙事：`02` -> `04` -> `06`。
- 战斗原型或战斗 UI：`03` -> `05` -> `04`。
- 数值、奖励或局外内容：`06` -> `04` -> `05`。
- 配置、随机地图、状态机或存档：`07` -> `02` -> `10`。
- UI、位图、角色、Boss 或场景资源：`08` -> `11` -> `03`。
- 实施任务：先读对应设计文档，再读 `10` 的当前阶段与 `09` 的验收要求。

其中 `02_DEMO旅程地图与叙事.md` 是当前“DEMO 第一阶段设计”入口，`10_DEMO重构实施计划.md` 是执行顺序，`11_资源制作单与开发记录.md` 中第 1 节是当前资源任务；第 2 节之后的历史记录不覆盖现行设计。

## 5. 冲突优先级

出现冲突时按以下顺序判断：

1. 本 README 的当前设计锚点。
2. 与任务最直接相关的 `00`-`09` 具体设计文档。
3. `10_DEMO重构实施计划.md` 的迁移与兼容约定。
4. `11_资源制作单与开发记录.md` 的当前活动制作单。
5. `11` 中的历史记录与原始 DOCX，仅用于追溯，不作为现行实现依据。

若目标设计与现有代码冲突，保留可运行兼容层并按 `10` 迁移，不反向修改设计去迎合旧实现。

## 6. 当前废弃口径

- 五张基础牌开局、固定三层套餐路线和逐战通用奖励页。
- 通用货币、灵石商店和以商店承担主要成长的流程。
- `定根脚 -> 受信物/所携 -> 所往` 三个割裂的开局选择页面；根脚与所携应由一段故事合并交付。
- 前台万剑/雷/血职业按钮、显式善恶值和与经历无关的随机筑基三选一。
- 单敌人横向站桩、主角正侧面蓝衣、全屏米黄宣纸和普通技能频繁推镜。
- 以天劫化身作为当前 DEMO 最终 Boss。
