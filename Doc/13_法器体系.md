# 法器体系

> 本文档统一定义局内 `法器` 系统。旧草案中的“遗物 / 道器 / 法宝”若作为前台并列系统出现，均以本文件为准收口为 `法器`。

## 1. 设计目标

法器负责提供三类体验：

- 改变规则：让玩法发生质变。
- 强化流派：补足当前 Build 的关键组件。
- 制造抉择：通过代价、风险或限制换取高收益。

## 2. 基础规则

| 规则 | 建议 |
| --- | --- |
| 生效范围 | 单局内永久生效 |
| 获取来源 | 精英、Boss、事件、商店、秘藏 |
| 携带上限 | 随境界提升 |
| 同名叠加 | 默认不可叠加，特殊法器可升级 |
| 移除方式 | 特殊事件、商店净化、Boss 替换奖励 |

## 3. 类型

| 类型 | 作用 | 示例 |
| --- | --- | --- |
| 启动型 | 帮助前期建立流派 | 剑骨 |
| 引擎型 | 提供持续循环 | 雷心 |
| 爆发型 | 提供关键爆发窗口 | 万剑剑匣 |
| 防御型 | 提供生存结构 | 护心镜 |
| 资源型 | 增加资源收益 | 聚灵符 |
| 风险型 | 代价换收益 | 血魔珠 |
| 规则型 | 修改底层玩法 | 残破古镜 |

## 4. 稀有度与投放

| 稀有度 | 定位 | 出现来源 |
| --- | --- | --- |
| 普通 | 基础补强 | 普通战斗、商店 |
| 稀有 | 流派组件 | 精英、事件、商店 |
| 史诗 | 构筑核心 | 精英、Boss |
| 传说 | 流派引擎 | Boss、稀有奇遇 |
| 神话 | 规则修改 | 终局 Boss、特殊奇遇 |

## 5. 强度预算

| 稀有度 | 数值收益参考 | 机制复杂度 |
| --- | ---: | --- |
| 普通 | 5%-15% | 单一数值或简单触发 |
| 稀有 | 15%-30% | 明确流派倾向 |
| 史诗 | 30%-60% | 可成为构筑核心 |
| 传说 | 60%-100% | 改变战斗节奏 |
| 神话 | 不按常规倍率 | 修改规则或胜利方式 |

## 6. 样例

| 法器 | 稀有度 | 流派 | 效果 |
| --- | --- | --- | --- |
| 剑骨 | 稀有 | 剑修 | 飞剑数量 +1 |
| 剑冢残碑 | 史诗 | 剑修 | 每消耗 10 层剑意，生成 1 把临时飞剑 |
| 万剑剑匣 | 传说 | 剑修 | 飞剑返回时有 30% 概率再次攻击 |
| 雷心 | 稀有 | 雷修 | 感电伤害 +30% |
| 九霄雷印 | 史诗 | 雷修 | 暴击时触发一次额外雷击 |
| 血魔珠 | 稀有 | 血修 | 每损失 10% 生命，伤害 +8% |
| 护心镜 | 稀有 | 通用 | Boss 战首次致死免疫 |
| 聚灵符 | 稀有 | 通用 | 每回合第一张 1 费牌免费 |
| 残破古镜 | 史诗 | 通用 | 每场战斗第一次复制效果增强 |

## 7. 与功法的分工

| 系统 | 负责内容 |
| --- | --- |
| 功法 | 这一局怎么修、怎么循环 |
| 法器 | 这一局靠什么器把规则放大或改写 |

## 8. 设计底线

- 法器必须能让玩家改变选择。
- 传说及以上法器应具有构筑记忆点。
- 风险法器必须让收益足够诱人。
- 经济型法器不能压过战斗型法器。
- 法器是统一前台名词，不再拆成并列的“遗物 / 道器 / 普通法宝”三套系统。
