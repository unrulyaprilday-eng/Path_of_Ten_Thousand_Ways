# 流派体系

> 本文档定义完整版本的流派生成框架。DEMO 阶段只截取其中一部分，具体范围见 `23_DEMO第一阶段设计.md`。

## 1. 设计目标

流派体系负责回答一个问题：

> 玩家这一世到底修成了什么道？

流派不是单一职业，而是由以下要素组合生成：

```text
道统 × 灵根 / 属性 × 核心状态 × 法宝 / 功法 × 遗物
```

## 2. 流派构成

| 要素 | 作用 | 示例 |
| --- | --- | --- |
| 道统 | 决定主要玩法骨架 | 剑修、法修、体修、魂修、器修 |
| 属性 | 决定伤害类型和状态方向 | 火、冰、雷、木、土、血、幽 |
| 核心状态 | 决定循环资源 | 剑意、雷意、魔念、丹意、佛缘 |
| 功法 | 提供长期被动和规则引擎 | 万剑归宗、九霄神雷诀 |
| 法宝 | 改变战斗规则 | 昊天镜、镇妖塔、九幽幡 |
| 遗物 | 提供局内永久强化 | 剑骨、雷心、血魔珠 |

## 3. 道统总表

| 道统 | 核心玩法 | 专属资源 | 主要爽点 |
| --- | --- | --- | --- |
| 剑修 | 高频攻击、飞剑、剑阵 | 剑意 | 万剑齐发、多段连击 |
| 法修 | 元素法术、范围爆发 | 灵气、雷意 | 全屏雷暴、火海扩散 |
| 体修 | 生命、反击、近战爆发 | 气血 | 越打越强、硬抗反杀 |
| 魂修 | 召唤、献祭、亡魂 | 魂火、魔念 | 尸傀铺场、牺牲爆发 |
| 器修 | 法宝、阵法、自动触发 | 神识 | 法宝连锁、自动炮台 |
| 丹修 | 回复、炼化、战斗成长 | 丹意 | 越战越厚、炼丹转化 |
| 天机修士 | 因果、预判、规则释放 | 因果 | 记录伤害后一次清算 |

## 4. 属性方向

| 属性 | 关键词 | 典型状态 | 适配玩法 |
| --- | --- | --- | --- |
| 火 | AOE、追加伤害 | 灼烧 | 多目标、连击触发 |
| 冰 | 控制、节奏压制 | 冰冻 | 防守、打断、拖回合 |
| 雷 | 爆发、连锁、暴击 | 感电、雷意 | 多段攻击、暴击流 |
| 木 | 回复、成长 | 丹意 | 持久战、生命成长 |
| 土 | 护盾、防御 | 佛缘 | 反击、护盾转伤 |
| 血 | 流血、吸血、风险收益 | 流血、魔念 | 压血爆发、Boss 杀手 |
| 幽 | 召魂、诅咒、献祭 | 魂火 | 亡魂、尸傀、资源回收 |

## 6. 流派阶段

| 阶段 | 层数 | 玩家目标 | 系统投放 |
| --- | ---: | --- | --- |
| 种子期 | 1-2 | 选择方向 | 核心功法、第一法宝、基础状态 |
| 成型期 | 3-4 | 形成循环 | 联动卡、遗物、升级、道途权重 |
| 爆发期 | 5+ | 完成质变 | 传说遗物、神通卡、终结技、Boss 奖励 |

## 7. 流派识别规则

系统应根据玩家已有组件识别当前倾向。

| 指标 | 权重 |
| --- | ---: |
| 已选择道途 | 40% |
| 同属性卡牌数量 | 20% |
| 同状态组件数量 | 20% |
| 已装备法宝类型 | 10% |
| 已获得遗物标签 | 10% |

当某个流派倾向超过 60%，奖励池应开始向该流派倾斜。

## 8. 混合流派规则

完整版本允许双流派，但必须在中后期开放。

| 主流派 | 副流派 | 示例 |
| --- | --- | --- |
| 剑修 | 雷修 | 雷剑流 |
| 剑修 | 器修 | 剑阵法宝流 |
| 法修 | 丹修 | 火鼎炼丹流 |
| 魂修 | 血修 | 血祭尸傀流 |
| 体修 | 佛修 | 金刚反伤流 |

混合流派开放条件：

- 合体境界后。
- 或单局内获得特定道器。
- 或 Boss 奖励触发双修奇遇。

## 9. 设计底线

- 每个流派必须有核心资源。
- 每个流派必须有至少一种质变遗物。
- 每个流派必须有可视化爽点。
- 流派不能只靠数值倍率区分。
- 玩家应能在中期明确判断自己的构筑方向。
