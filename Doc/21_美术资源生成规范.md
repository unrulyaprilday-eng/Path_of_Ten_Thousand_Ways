# 美术资源生成规范

> 本文档负责 AI 绘图方向、提示词和阶段资源清单。文件夹结构、命名规则和资源数量见 `22_项目资源生产手册.md`。

## 1. 美术方向

核心风格：

```text
暗黑水墨修仙 + 卷轴 UI + 节点地图探索
```

关键词：

- 修仙
- 水墨
- 国风
- 暗黑奇幻
- 道家符箓
- 飞剑
- 秘境
- 雷劫
- 古卷
- 仙侠

## 2. 风格边界

避免：

- 二次元萌系。
- Q 版。
- MMO 仙侠页游感。
- 写实人物写真。

追求：

- 神秘。
- 孤独。
- 探索。
- 飞升。
- 天道压迫感。

参考英文关键词：

```text
Dark Chinese Fantasy
Ink Wash Painting
Cultivation World
Ancient Taoism
Mystic Immortal Realm
```
