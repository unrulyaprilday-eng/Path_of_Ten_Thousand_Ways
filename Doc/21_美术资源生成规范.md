# 美术资源生成规范

> 本文档负责 AI 绘图方向、提示词和阶段资源清单。文件夹结构、命名规则和资源数量见 `22_项目资源生产手册.md`。

协作补充：

- 在 Codex 会话内，凡是需要生成或编辑位图类视觉资产，默认优先使用内部挂载的 `image_gen` / `imagegen` 能力推进。
- 如果内部挂载的 `image_gen` / `imagegen` 不可用、调用失败或不适合当前需求，再使用项目可用的 `imagegen2` skill 生成或编辑位图资源。
- 使用 `imagegen2` 时，仍必须遵守本文件的风格边界、提示词方向、资源优先级和命名落库要求。
- 不要把本文件中的“推荐模型”理解为必须依赖外部站点或额外环境后，才允许开始出图。
- 本文档的提示词与风格约束，同样适用于直接驱动会话内置图像生成工具。

## 1. 美术方向

核心风格：

```text
高留白写意水墨修仙 + 器物化卷轴 UI + 节点地图探索
```

关键词：

- 修仙
- 水墨
- 国风
- 写意
- 留白
- 点翠
- 石青
- 微朱砂
- 道家符箓
- 飞剑
- 秘境
- 雷劫
- 古卷
- 仙侠

当前参考图提炼：

- 人物方向：以孤身修士剪影、衣袍与发丝的笔触化开为主，重气韵，不重五官写实。
- 背景方向：远山、云海、断崖、竹影都应服从留白，不做整屏塞满。
- UI 方向：器面像题签、印泥、墨盘、旧纸，不像现代深色玻璃面板；允许点翠青、石青、淡金和微朱砂作为醒目落点。
- 总体气质：高级、安静、克制、诗性，不浑浊，不脏黑，不靠满屏压暗制造“高级感”。

## 2. 风格边界

避免：

- 二次元萌系。
- Q 版。
- MMO 仙侠页游感。
- 写实人物写真。
- 持续大面积黑底压色。
- 浑浊蓝黑或紫黑奇幻厚涂。
- 把“压迫感”理解成整屏发黑。

追求：

- 神秘。
- 孤独。
- 探索。
- 飞升。
- 天道压迫感。
- 留白与呼吸感。
- 可直接对外展示的商业化卖相。
- 黑白水墨为主，流派色只做克制点染。
- 宣纸、墨痕、旧印、玉石与轻金属的材质层次。
- 远看先识别轮廓和气口，近看再读细节。

参考英文关键词：

```text
Chinese ink wash xianxia
Minimalist negative space
Calligraphic silhouette
Refined Taoist scroll UI
Restrained jade and cinnabar accents
```

## 5. 阶段资源清单

| 阶段 | 资源 |
| --- | --- |
| 第一阶段 | Logo、登录背景、主界面背景、节点地图、卡牌边框、按钮、图标 |
| 第二阶段 | 功法卡牌、法器卡牌、丹药卡牌、奇遇事件 |
| 第三阶段 | Boss 立绘、NPC 立绘、宗门场景、秘境场景 |

开局起手流程补充要求：

- 当前 DEMO 开局链路固定为：`开卷 -> 定根脚 -> 受信物 -> 入首境 -> 择前路 -> 斗法`。
- `定根脚` 页要做入口，但首版只开放 `世家旁支`，其他根脚可用 `命数未显` 等状态表现。
- `受信物` 页属于 P0 展示资源，应按可对外发布 DEMO 的标准制作。
- `受信物` 页优先使用三张独立的大幅写意启程信物卡，而不是一个通用卡框简单换色。
- 三张启程信物卡应体现不同的来历与起势线索，而不是直接把“万剑 / 雷 / 血”写成页面大标题。
- `入首境` 页应使用 2-3 张由当前启程信物指向的场景卡；可以做成几乎铺满 UI 的拉通大场景，图多字少，只保留场景名、风险词与极短提示。
- `择前路` 页应使用 2-4 张图卡表达节点顺序和节奏差异，不再把旧版流派标签直接贴在卡顶。
- 色彩仍以黑白水墨为主，再做克制点染：
  - 剑势线：飞剑、剑痕、锋线、淡金细裂与宣纸破墨
  - 雷势线：雷纹、电痕、点翠青与天威裂光
  - 血势线：血玉、朱砂、飘带、断锋残痕
- 开局卡面每张只保留 1-3 条关键信息，优先让图像先成立。

定根脚页补充要求：

- 定根脚页的信息密度要明显低于受信物页。
- 每张根脚卡只强调：根脚名、身份短句、轻效果、改命按钮。
- 视觉重点是“身份成立”，不是“把玩法解释完”。
- 如果同屏展示多张根脚卡，必须保证留白，不把首页做成奖励三选一那种密集格子。

受信物页补充要求：

- 页面读法是“这个身份下的三条出山命运”，不是“从全游戏物品池里挑道具”。
- 每张卡同时展示启程线标题、极短来历、启程信物名、信物效果和 2-3 个标签。
- 启程信物图可以更有器物门面，但不要让物品脱离故事独立成系统。
- 可以保留后续“案台 / 书架 / 兵器架陈列”的场景化升级方向，但当前不新增一步选择。

战斗 UI 补充要求：

- 底部手牌区必须读成牌库操作区，不是固定技能栏。
- 灵气条需要显示当前值、上限和增长感。
- 主动法器和神通入口数量要少，避免在手牌旁再长出一排技能。
- 敌方意图、Boss 读条和关键预警必须始终清晰。
