# 美术资源生成规范

> 本文档负责 AI 绘图方向、提示词和阶段资源清单。文件夹结构、命名规则和资源数量见 `22_项目资源生产手册.md`。

协作补充：

- 在 Codex 会话内，凡是需要生成或编辑位图类视觉资产，默认优先使用会话可用的 `imagegen` 能力推进。
- 不要把本文件中的“推荐模型”理解为必须依赖外部站点或额外环境后，才允许开始出图。
- 本文档的提示词与风格约束，同样适用于直接驱动会话内置图像生成工具。

## 1. 美术方向

核心风格：

```text
黑白水墨修仙 + 商业化卷轴 UI + 节点地图探索
```

关键词：

- 修仙
- 水墨
- 国风
- 暗黑奇幻
- 道家符箓
- 飞剑
- 秘境
- 雷劫
- 古卷
- 仙侠

## 2. 风格边界

避免：

- 二次元萌系。
- Q 版。
- MMO 仙侠页游感。
- 写实人物写真。

追求：

- 神秘。
- 孤独。
- 探索。
- 飞升。
- 天道压迫感。
- 留白与呼吸感。
- 可直接对外展示的商业化卖相。
- 黑白水墨为主，流派色只做克制点染。

参考英文关键词：

```text
Dark Chinese Fantasy
Ink Wash Painting
Cultivation World
Ancient Taoism
Mystic Immortal Realm
```

## 5. 阶段资源清单

| 阶段 | 资源 |
| --- | --- |
| 第一阶段 | Logo、登录背景、主界面背景、节点地图、卡牌边框、按钮、图标 |
| 第二阶段 | 功法卡牌、法器卡牌、丹药卡牌、奇遇事件 |
| 第三阶段 | Boss 立绘、NPC 立绘、宗门场景、秘境场景 |

开局启程页补充要求：

- 启程页属于 P0 展示资源，应按可对外发布 DEMO 的标准制作。
- 优先使用三张独立的大幅水墨启程卡，而不是一个通用卡框简单换色。
- 三张卡面都应体现不同的来历、携行之物和首境去向，而不是只改标题。
- 色彩仍以黑白水墨为主，再以起势方向做克制点染：
  - 剑势线：飞剑、剑痕、锋线、水墨裂纸感
  - 雷势线：雷纹、电痕、裂光、天威压顶感
  - 血势线：血砂、飘带、煞气、断锋残痕
- 每张牌面只保留 3 条关键信息：来历句、携行之物、首境名。

定根脚页补充要求：

- 定根脚页的信息密度要明显低于启程页。
- 每张根脚卡只强调：根脚名、身份短句、轻效果、改命按钮。
- 视觉重点是“身份成立”，不是“把玩法解释完”。
- 如果同屏展示多张根脚卡，必须保证留白，不把首页做成奖励三选一那种密集格子。
