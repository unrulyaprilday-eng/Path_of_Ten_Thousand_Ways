# 项目资源生产手册

> 本文档负责资源生产流程、规格、目录和命名。美术风格与 AI 提示词见 `21_美术资源生成规范.md`。

## 1. 资源生产原则

- P0 先服务核心玩法可跑通。
- P1 补齐完整卡牌与流派资源。
- P2 替换正式美术与音效。
- P3 增加动画、特效和宣传资源。
- 所有资源命名必须可追踪用途、类型和序号。

补充说明：

- 这里的 `P2 替换正式美术与音效`，指的是大范围替换和高完成度收尾，不代表 P0 / P1 阶段不做图。
- 在 P0 阶段，只要某项视觉资源直接影响玩法验证、观感判断、信息识别或战斗演出，就应立即生成并接入。
- AI 绘图、参考图整理、裁切、透明化处理、导入 Unity 和试挂验证，均属于资源生产流程本身，而不是后置的包装工作。
- 对外展示用 DEMO 的入口 UI、定根脚页、启程页、战后奖励和 Boss 前整备界面，默认按商业化展示标准推进，而不是只做调试排版。
- 在 Codex 会话内，位图资源默认优先用 `imagegen` 生成或编辑；不要把资源生产误判为“先继续写代码，图片以后再说”。

## 2. UI 设计规格

### 2.1 主色

背景：

- `#F1EEE6`
- `#D9D4C8`
- `#232323`

点缀：

- 金色：`#D6B36A`
- 青色：`#5FA8D3`
- 紫色：`#8B5CF6`
- 红色：`#C53D3D`

补充要求：

- 主体画风以黑白水墨为主，不做持续偏暗黑的整屏压色。
- 强调层级靠纸面、墨迹、留白、材质和局部点色，而不是大面积黑底。
- 启程页应优先使用三张大幅独立器面，支持轻微动态装饰。

### 2.2 字体

| 用途 | 字体 |
| --- | --- |
| 标题 | 思源宋体 |
| 正文 | 思源黑体 |
| 数字 | DIN |

### 2.3 图标

图标风格：

- 线性 + 实心结合。
- 2 px 线宽。
- 圆角处理。
- 水墨金属质感。

常用图标：

- 背包。
- 功法。
- 法器。
- 丹药。
- 宗门。
- 邮件。
- 商城。
- 设置。

## 3. 卡牌资源规格

推荐比例：`5:7`。

卡牌结构：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 名称 |
| 中部 | 插画 |
| 底部 | 描述 |
| 左上 | 消耗 |
| 右上 | 品质 |

品质颜色以 `21_美术资源生成规范.md` 为准。

根脚卡补充规格：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 根脚名 |
| 中部 | 身份主视觉或象征物 |
| 下部 | 身份短句、1 条轻效果 |
| 底部 | 改命或确认按钮 |

说明：

- 根脚卡应比启程卡更克制、更空。
- 不需要塞满玩法标签，更不能把数值表直接堆在卡面上。
- 玩家在这一页主要是在确认“我是谁”，不是在做完整构筑判断。

启程卡补充规格：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 启程名、短副题 |
| 中部 | 独立水墨主视觉与大字印 |
| 下部 | 来历句、携行之物、首境 |
| 底部 | 明确行动按钮或点击区 |

说明：

- 启程卡优先按“展示卡 / 门面卡”处理，不照搬战斗手牌的信息密度。
- 不依赖 Hover 才能看懂选择差异。
- 允许加入飘带、墨粒、雷屑、剑痕等低成本微动效。
- 只要该页面承担首屏识别或流派判断职责，就不应退回“通用占位框 + 纯文字说明”的临时做法。

## 10. 生产检查清单

每个资源入库前检查：

- 文件名符合命名规范。
- 类型放在正确目录。
- 尺寸符合用途。
- 品质颜色与数值文档一致。
- 可在游戏 UI 中清楚识别。
- 已记录来源、版本和生成参数。
