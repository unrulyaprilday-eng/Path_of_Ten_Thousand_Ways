# 项目资源生产手册

> 本文档负责资源生产流程、规格、目录和命名。美术风格与 AI 提示词见 `21_美术资源生成规范.md`。

## 1. 资源生产原则

- P0 先服务核心玩法可跑通。
- P1 补齐完整卡牌与流派资源。
- P2 替换正式美术与音效。
- P3 增加动画、特效和宣传资源。
- 所有资源命名必须可追踪用途、类型和序号。

补充说明：

- 这里的 `P2 替换正式美术与音效`，指的是大范围替换和高完成度收尾，不代表 P0 / P1 阶段不做图。
- 在 P0 阶段，只要某项视觉资源直接影响玩法验证、观感判断、信息识别或战斗演出，就应立即生成并接入。
- AI 绘图、参考图整理、裁切、透明化处理、导入 Unity 和试挂验证，均属于资源生产流程本身，而不是后置的包装工作。
- 对外展示用 DEMO 的入口 UI、定根脚页、受信物页、战后奖励和 Boss 前整备界面，默认按商业化展示标准推进，而不是只做调试排版。
- 在 Codex 会话内，位图资源默认优先用内部挂载的 `image_gen` / `imagegen` 生成或编辑；如果不可用、调用失败或不适合当前需求，再使用 `imagegen2` skill 生图；不要把资源生产误判为“先继续写代码，图片以后再说”。
- 无论使用内部挂载生图能力还是 `imagegen2`，都应记录实际使用的工具、提示词要点、输出版本和最终落库路径，便于后续复现与替换。

## 2. UI 设计规格

### 2.1 主色

背景：

- `#F1EEE6`
- `#D9D4C8`
- `#232323`

点缀：

- 淡金：`#D6B36A`
- 点翠青：`#4FA39B`
- 石青：`#6F8EA8`
- 微朱砂：`#C45746`

补充要求：

- 主体画风以黑白水墨为主，不做持续压黑的整屏压色。
- 强调层级靠纸面、墨迹、留白、材质和局部点色，而不是大面积黑底。
- 开局的 `受信物` 页应优先使用三张大幅独立启程信物器面，`入首境` 页按当前信物展示 2-3 张合理首境候选场景图卡，P0 优先打磨 `旧矿地窟` 等最常出现的候选。
- `择前路` 页优先用图像和节点顺序表达差异，少字，不直接把旧流派名贴到卡顶。
- 点翠青、石青和微朱砂只做局部醒目落点，不做整页主色。

## 3. 卡牌资源规格

推荐比例：`5:7`。

卡牌结构：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 名称 |
| 中部 | 插画 |
| 底部 | 描述 |
| 左上 | 消耗 |
| 右上 | 品质 |

品质颜色以 `21_美术资源生成规范.md` 为准。

根脚卡补充规格：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 根脚名 |
| 中部 | 身份主视觉或象征物 |
| 下部 | 身份短句、1 条轻效果 |
| 底部 | 改命或确认按钮 |

说明：

- 根脚卡应比启程卡更克制、更空。
- 不需要塞满玩法标签，更不能把数值表直接堆在卡面上。
- 玩家在这一页主要是在确认“我是谁”，不是在做完整构筑判断。

启程信物卡补充规格：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 启程线标题、启程信物名 |
| 中部 | 独立水墨主视觉与象征印记 |
| 下部 | 极短来历句、信物效果 |
| 底部 | 明确行动按钮或点击区 |

说明：

- 启程信物卡优先按“展示卡 / 门面卡”处理，不照搬战斗手牌的信息密度。
- 玩家实际选择的是启程线，视觉焦点可以是信物。
- 不依赖 Hover 才能看懂选择差异。
- 允许加入飘带、墨粒、雷屑、剑痕等低成本微动效。
- 只要该页面承担首屏识别或流派判断职责，就不应退回“通用占位框 + 纯文字说明”的临时做法。

首境卡补充规格：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 场景名、风险词 |
| 中部 | 大幅场景图，优先展示云海、山势、断崖、古塔、矿窟等轮廓 |
| 下部 | 1 句极短提示，说明节奏或奖励口味 |
| 底部 | 确认点击区 |

说明：

- 首境卡必须图多字少，优先让“去哪里”成立。
- 首境页的候选来自当前启程信物，不是全地图自由菜单，也不是信物定死唯一地图。
- 允许多个候选共用统一器面结构，但每张图的山势、气口和点色要明显区分。
- 不要把信物效果、构筑标签、节点权重、奖励概率和大段说明堆在场景卡上。
- 当前首版先把 `旧矿地窟` 做成完整大地图门面，其他首境可先以低信息密度场景卡进入，后续补齐节点深度。

半实时战斗 UI 补充规格：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 敌人生命、意图读条、Boss 阶段 |
| 中部 | 2.5D 横版斗法、飞剑轨迹、受击反馈 |
| 底部 | 手牌、灵气条、牌库 / 弃牌数量 |
| 侧边 | 少量主动法器、神通充能、功法阈值 |

说明：

- 底部必须读成手牌区，不做固定技能栏。
- 主动法器数量要少，图标可以有冷却圈，但不能压过手牌。
- 灵气条要表达持续增长，避免看起来像回合制固定点数。
- 敌方意图和 Boss 预警比装饰特效优先级更高。

前路卡补充规格：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 前路名或短标签 |
| 中部 | 场景 / 器物 / 节点预览图 |
| 下部 | 2-4 个节点顺序图标 |
| 底部 | 1 句极短节奏提示 |

说明：

- 前路卡只表达“接下来怎么走”，不重复“你是什么流派”。
- 页面顶部不再出现 `万剑 / 雷 / 血` 这类旧版显式总标签。
- 每张卡尽量控制在 2 行以内的可见文字。

## 10. 生产检查清单

每个资源入库前检查：

- 文件名符合命名规范。
- 类型放在正确目录。
- 尺寸符合用途。
- 品质颜色与数值文档一致。
- 可在游戏 UI 中清楚识别。
- 已记录来源、版本、生成参数和实际使用的生图通道。
