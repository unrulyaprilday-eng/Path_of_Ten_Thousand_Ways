# 项目资源生产手册

> 本文档负责资源生产流程、规格、目录和命名。美术风格与 AI 提示词见 `21_美术资源生成规范.md`。

## 1. 资源生产原则

- P0 先服务核心玩法可跑通。
- P1 补齐完整卡牌与流派资源。
- P2 替换正式美术与音效。
- P3 增加动画、特效和宣传资源。
- 所有资源命名必须可追踪用途、类型和序号。

## 2. UI 设计规格

### 2.1 主色

背景：

- `#111111`
- `#171717`
- `#1D1D1D`

点缀：

- 金色：`#D6B36A`
- 青色：`#5FA8D3`
- 紫色：`#8B5CF6`
- 红色：`#C53D3D`

### 2.2 字体

| 用途 | 字体 |
| --- | --- |
| 标题 | 思源宋体 |
| 正文 | 思源黑体 |
| 数字 | DIN |

### 2.3 图标

图标风格：

- 线性 + 实心结合。
- 2 px 线宽。
- 圆角处理。
- 水墨金属质感。

常用图标：

- 背包。
- 功法。
- 法宝。
- 丹药。
- 宗门。
- 邮件。
- 商城。
- 设置。

## 3. 卡牌资源规格

推荐比例：`5:7`。

卡牌结构：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 名称 |
| 中部 | 插画 |
| 底部 | 描述 |
| 左上 | 消耗 |
| 右上 | 品质 |

品质颜色以 `21_美术资源生成规范.md` 为准。

## 10. 生产检查清单

每个资源入库前检查：

- 文件名符合命名规范。
- 类型放在正确目录。
- 尺寸符合用途。
- 品质颜色与数值文档一致。
- 可在游戏 UI 中清楚识别。
- 已记录来源、版本和生成参数。
