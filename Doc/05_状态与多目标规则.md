# 状态与多目标规则

> 本文定义半实时战斗中的目标、锁定、意图与状态结算。状态不是战斗日志里的附属数字，而是可以积累、消耗、转化和联动的战斗资源。

## 1. 有限多敌人

DEMO 支持有限多敌人，不把战场扩展成大规模单位管理。

| 遭遇 | 目标规模 |
| --- | --- |
| 普通战 | 1-3 名敌人，后段以 2-3 名为主 |
| 精英战 | 1 名主体，可带 0-2 个召唤物或构造体 |
| 小 Boss | 1 名主体，可在阶段中生成 1-2 个附属目标 |
| 最终 Boss | 主体唯一，但契钉、甲片、剑炉核心等可成为阶段目标 |

敌人拥有稳定的战场位置 ID、纵深、生命、状态、意图和可锁定状态。表现层如何绘制不改变这些战斗规则。

## 2. 自动攻击与点击锁定

- 未指定锁定时，本命法器和自动飞剑攻击当前最高威胁目标。
- 玩家点击可锁定敌人后立即切换锁定，不增加二次确认。
- 单体法诀默认作用于当前锁定目标。
- 群攻、雷链、万剑等效果按自身规则自动覆盖或扩散，不逐个要求玩家点目标。
- 锁定目标死亡、离场或变为不可选时，系统立即自动选择新目标，不让自动攻击停顿。
- Boss 部位或召唤物被击破后，若 Boss 主体仍可选，锁定默认返回 Boss。

默认威胁排序必须可预测：即将完成意图的敌人优先，其次是明确标记的高威胁目标，再按遭遇配置优先级与稳定位置顺序裁决。玩家手动锁定高于自动威胁排序，直到目标失效或玩家主动切换。

## 3. 敌方意图

每名敌人独立维护意图和读条：

- 意图至少包含行为 ID、目标、剩余时间和已知效果。
- 多名敌人的意图可以同时推进。
- 当前锁定目标可展开详细说明，其他敌人只显示足够判断危险的摘要。
- 控制、阶段转换和部位破坏必须明确处理当前读条：暂停、延后、替换或取消，不能静默重置。
- Boss 阶段脚本可以改变意图池，但不能绕开统一意图结算。

## 4. 状态数据模型

每个状态实例至少记录：

- 状态 ID。
- 来源单位或来源效果 ID。
- 所属目标 ID。
- 当前层数或阈值。
- 结算方式与下一次结算时间。
- 持续时间、剩余触发次数或移除条件。
- 是否可驱散、转移、消耗或跨战斗保留。

半实时状态默认按持续时间、触发间隔、命中次数、意图读条或阈值结算，不使用固定回合结束结算。

## 5. DEMO 核心状态

### 5.1 剑意

剑意是玩家侧的剑修资源，用于放大飞剑、法诀或终结爆发。

- 剑意属于玩家，不挂在单个敌人身上。
- 获取、上限和消耗均由法诀、心法、道基与法器配置。
- 剑意可以被部分效果消耗，转化为追击、临时飞剑、阵式或终结伤害。
- 不固定使用“每层伤害 +1%”作为永久规则；线性增伤只能是一个可调实现。

### 5.2 感电

感电是敌方目标上的连锁资源。

- 每名敌人独立记录感电层数。
- 飞剑、雷法或指定命中可引爆感电。
- 连锁优先选择尚未被本次连锁命中的合法目标，再按距离 / 纵深和稳定位置顺序选择。
- 目标不足时是否允许回跳由具体效果配置，默认不回跳。
- 单目标战中感电仍应有基础收益，避免雷剑在 Boss 战完全失效。

### 5.3 流血与煞契

流血可作为持续伤害；煞契或魔念可作为玩家侧风险资源。它们只在对应事件、心法或道基成立时进入本局，不能因为状态系统存在就默认投放。

### 5.4 护体、冻结与眩晕

- 护体属于可消耗防御资源。
- 冻结优先采用阈值触发延后一次意图，而非无限硬控。
- 眩晕属于稀有硬控；Boss 和小 Boss 应按配置转化为读条延后、部位失衡或弱化控制。

## 6. 多目标伤害规则

- 单体伤害只结算当前合法目标。
- 范围伤害对命中列表中的每个目标分别应用伤害、护体、抗性和状态。
- 连锁伤害必须保存本次链路访问记录，避免无意无限循环。
- 击杀触发按实际造成致死伤害的效果归属来源。
- 同一次攻击命中主体和部位时，由技能配置明确是否允许重复计入，不默认双倍伤害。
- 临时飞剑、自动齐射和主动法诀共享统一目标接口，不各自实现一套选敌逻辑。

## 8. 战斗因果与叙事因果分名

若未来保留“记录累计伤害再释放”的战斗机制，统一称为 `战斗因果`。玩家在事件中帮助、利用、束缚、击杀、超度、炼化或继承旧契产生的内容，统一称为 `经历标记` 或 `宿缘记录`。

两者不得共用字段、UI 名称或存档集合，避免战斗资源意外影响剧情分支。

## 9. 设计底线

- 多目标不增加逐张牌二次点选。
- 自动目标选择必须稳定、可解释，手动锁定必须即时生效。
- 状态归属于明确单位，不能继续假定战场只有一个 Enemy。
- 群攻与连锁按目标分别结算，不能只播放多目标表现而实际伤害单体。
- 天劫不属于 DEMO Boss 或默认战斗状态；仅保留为完整版本终局内容。
