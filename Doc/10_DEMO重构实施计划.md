# DEMO 重构实施计划

> 本计划把当前 15-18 分钟固定路线原型迁移为一条 30-40 分钟的沉浸式旧矿修仙纵切。设计真源见 `00`-`09`；资源缺口与历史记录见 `11_资源制作单与开发记录.md`。

## 1. 目标与成功标准

玩家以世家旁支身份取得残剑胚、旁支吐纳法与残卷御剑式，选择进入旧矿地窟，在一个连续大境域中经历三幕、完成炼气到筑基、形成自己的法诀与本命法器循环，处理沿途因果，最终击败玄铁镇矿剑傀并得到与经历一致的结局。

成功标准：

- 单局目标时长 30-40 分钟，作为 DEMO tuning。
- 三幕地图自下向上推进；标准路径每幕实际经过 7-8 个节点，合法范围 6-10 个。
- 地图使用手工结构与连线模板，节点类型、内容与合法顺序按种子变化。
- 开局只有残剑胚自动攻击、旁支吐纳法附带技能、残卷御剑式，共 2 门主动法诀。
- 最终法诀牌库约 6-9 门；所有能力均有故事内来源。
- 普通战支持 1-3 名敌人，采用自动攻击与点击锁定。
- 第一、二幕各有怪兽型小 Boss，第三幕最终 Boss 为玄铁镇矿剑傀。
- 第二幕末完成一次故事化 `炼气 -> 筑基`，境界同时改变灵力、法诀通用成长和道基规则。
- 不使用通用货币、商店节点、逐战通用三选一、路线卡套餐或天劫 Boss。
- 战斗、地图、事件、突破和结算在黑白冷墨基底上使用青绿、朱砂、雷光点染，不出现全屏米黄 UI。
- 节点间自动保存并可恢复；不保存战斗中间状态。

## 2. 范围边界

本轮包含：

- 一条完整的世家旁支旧矿故事线。
- 一个本命法器、一个初始心法、两门初始法诀及其成长。
- 纯剑主轴，雷剑与煞契作为可由经历解锁的局内分支。
- 三幕节点图、事件、修炼、秘藏、精英、小 Boss、筑基和区域 Boss。
- 一个可反复出现的矿灵角色及至少三种经历结果。
- 运行时存档、确定性种子、完整流程截图与自动烟测。
- 当前纵切所需正式资源生产与确定性回退。

本轮不包含：

- 天劫、魔尊、跨境域完整商业版流程。
- 通用灵石经济、商店、局外永久境界和永久数值战力。
- 多根脚、多本命法器大类、多地图的完整内容量。
- 联网、账号、云存档、商城或排行榜。
- 战斗中途存档、自由移动 ARPG 或高成本 3D 场景。

## 3. 目标运行状态机

`DemoFlowPhase` 收束为：

```text
Home
-> OpeningStory
-> RegionChoice
-> JourneyMap
-> NodeScene / EncounterIntro
-> Battle
-> BattleOutcome
-> JourneyMap
-> Breakthrough
-> JourneyMap
-> RunResult
```

状态职责：

| 状态 | 玩家主行动 | 合法去向 |
| --- | --- | --- |
| `Home` | 开始或继续一世 | `OpeningStory` / 已保存状态 |
| `OpeningStory` | 在沉浸场景中确认根脚并取得所携 | `RegionChoice` |
| `RegionChoice` | 选择所往 | `JourneyMap` |
| `JourneyMap` | 选择相邻可达节点 | `NodeScene` / `EncounterIntro` |
| `NodeScene` | 完成故事、修炼、秘藏或炼化交互 | `JourneyMap` / `Breakthrough` |
| `EncounterIntro` | 阅读敌人和风险并入阵 | `Battle` |
| `Battle` | 使用法诀、锁定目标并完成斗法 | `BattleOutcome` |
| `BattleOutcome` | 观看短促胜负反馈 | `JourneyMap` / `RunResult` |
| `Breakthrough` | 依据本局经历选择并完成筑基 | `JourneyMap` |
| `RunResult` | 查看经历、解锁并再启一世 | `OpeningStory` / `Home` |

删除前台 `RouteChoice`。旧 `RewardChoice` 仅作为迁移兼容，不再承载通用逐战奖励；具体所得由节点场景、战后短交互或里程碑状态表达。

## 5. 实施阶段

### 阶段 A：新数据骨架与兼容层

1. 为配置仓库加入新表模型、解析、JSON 聚合和引用校验。
2. 建立本命法器、心法、法诀、境界、经历和遭遇组定义。
3. 将残剑胚、旁支吐纳法、吐纳归息、残卷御剑式配置为第一批真数据。
4. 为旧 `DemoCard`、`DemoGongfa`、`DemoArtifact` 提供只读迁移映射。
5. 将 Boss 阶段改为数据驱动，移除运行时对“天劫”枚举和中文名的判断。

验收：CompileCheck 通过；旧流程仍可启动；新配置生成与引用校验有独立 smoke 输出。

### 阶段 B：旅程图与节点间存档

1. 实现 `DemoJourneyGraphGenerator`，输入种子和地图模板，输出三幕合法图。
2. 每幕生成 7-8 个标准路径深度，允许合法路径长度 6-10。
3. 固定幕起点、关键故事职责、小 Boss / Boss 深度；随机内容、左右位置、连线模板与非关键顺序。
4. 保证无死路、无重复事件、普通路线不连续三战、Boss 前可见一次修整机会。
5. 实现自下向上的地图视图、可达节点、已走墨迹、隐藏路径显现和相机滚动。
6. 实现 `DemoRunSaveV2` 原子写入、版本校验、损坏回退和节点完成后自动保存。

验收：固定种子图完全一致；批量种子均满足约束；从每种节点完成后重启都能恢复到地图且不重复结算。

### 阶段 C：沉浸式开局与故事节点

1. 合并 `OpeningRoot` 与 `OpeningVessel` 为 `OpeningStory`。
2. 使用祖龛 / 案台场景表现世家旁支身份、取得残剑胚、获得初始心法与剑诀。
3. 保留独立 `RegionChoice`；旧矿为唯一可进入目的地，其他地域只作为无伪行动的世界轮廓。
4. 建立三幕固定故事职责：追查旧契、发现祭炼真相、进入玄铁剑炉断契。
5. 实现矿灵反复出现及 `帮助 / 利用或束缚 / 击杀炼化 / 无视` 等经历结果。
6. 选择结果只写稳定经历标记，不显示统一善恶值；后续节点、筑基方式、Boss 阶段和结局读取具体标记。

验收：首次开局无三页伪选择；所有故事分支均有合法后续；重复一世不会继承局内能力，只保留已解锁见闻。

### 阶段 D：修行成长与筑基

1. 将残剑胚改为独立冷却自动攻击，不再作为普通卡牌或临时法器奖励。
2. 将心法实现为常驻规则与分级状态；升级可改变回灵、恢复和本命法器联动。
3. 法诀只通过剑洞、残魂、秘境、修炼、精英、小 Boss 和故事事件获得。
4. 建立法诀参悟、心法升阶、本命法器炼形、境界突破四条互不替代的成长线。
5. 第二幕末进入固定突破职责节点；基础稳固筑基永远可用，特殊经历解锁剑骨、清灵、雷脉或煞契等道基方式。
6. 筑基统一提升灵力获取与法诀通用系数，并由道基额外提供一条规则。
7. 第三幕第一场战斗确定性安排多目标，立即验证筑基规则。

验收：开局 2 门法诀可完整循环；终局 6-9 门牌库可稳定抽取、弃置和洗回，同时在手不超过 6 张；初始剑诀随境界成长不失效；每种筑基方式都能在第三幕产生可见差异。

### 阶段 E：多敌人战斗重构

1. 将单 `Enemy` 状态迁移为稳定 ID 的敌人集合。
2. 为每名敌人维护独立生命、状态、意图、读条、深度槽和视觉锚点。
3. 实现点击锁定、自动威胁目标、死亡自动换目标、单体与群体法诀分流。
4. 感电、流血 / 煞契、控制和 Boss 部位状态按目标归属；跨目标连锁读取合法目标集合。
5. 普通战接入 1-3 名敌人；精英、小 Boss 和 Boss 接入召唤物 / 部位。
6. 战斗结算只在所有必须击败的敌方目标死亡后触发。

验收：覆盖 1/2/3 敌人、锁定死亡、召唤、部位、连锁、AOE、状态迁移、胜负和日志；固定种子模拟无空引用或死锁。

### 阶段 F：战斗舞台与 HUD 重做

1. 普通战改为玩家左下三分之四背视、敌人右上多纵深、左下到右上的攻击轴。
2. Boss 战改为玩家左下、Boss 正上方压屏；小 Boss 保持放大的斜向构图。
3. 手牌与灵力移到下方中右，状态与意图贴近各自战斗主体。
4. 实现承载槽：无承载法器时使用场景落脚面；有承载法器时切换脚下表现；环绕、手持和背负法器分层。
5. 攻击轨迹以实际锚点生成，不再播放固定横向直线。
6. 仅终极技和击杀使用短促推镜；普通法诀、敌方技能与阶段转换不频繁切镜。
7. HUD 与页面取消全屏暖纸洗色和厚重上下黑台。

验收：普通 / 小 Boss / 最终 Boss 三套构图在 1920 和 1280 下成立；2、4、6 张同时在手均无重叠，6-9 门总牌库信息可读；3 名敌人意图可读且仅锁定目标展开。

### 阶段 G：三幕内容与 Boss

1. 第一幕接入浅层矿道、矿契线索、普通敌人、修炼 / 事件与矿兽小 Boss。
2. 第二幕接入塌井、残魂、吞剑矿魈、筑基条件和突破场景。
3. 第三幕接入剑炉、封契、秘藏、筑基后验证战和玄铁镇矿剑傀。
4. 剑傀实现甲片、契钉、核心三阶段；契钉与核心是可锁定目标。
5. 矿灵和旧契经历至少影响隐藏节点、Boss 阶段修正和两类结局；额外 Boss 变体列为 P1，不阻塞基础纵切。
6. Boss 胜利只发结局、见闻和局外解锁，不再发本局法诀。

验收：所有合法路径可通关或失败闭环；关键故事事件必达但位置可变；隐藏路线条件可重放验证。

### 阶段 H：资源生产与接入

资源按以下顺序逐张串行生产并验收：

1. 黑白长发男性主角三分之四背视战斗主体。
2. 普通敌人多纵深所需主体与怪兽小 Boss。
3. 玄铁镇矿剑傀主体、甲片、契钉和核心阶段层。
4. 三幕地图与战斗场景远 / 中 / 近景。
5. 地图节点、锁定标记、多意图、法诀和本命法器 UI 资源。
6. 心法、法诀、筑基和隐藏事件关键插画。
7. 飞剑、青绿灵力、朱砂契印和雷光 VFX。

每张资源先在展示目录验收，再同时落入 `UNITY/Assets/Art/<分类>/` 与 `UNITY/Assets/Resources/Art/<分类>/`。生成失败时不得接入半成品；必须在 `11_资源制作单与开发记录.md` 记录最终文件名、Resources key、尺寸、格式、构图、安全区、禁止项、提示词摘要、失败原因、目标路径和代码回退。

## 6. 存档与兼容

- `DemoRunSaveV2` 只在节点完成、选择提交和突破完成后写入。
- 进入战斗前保存前置节点状态；战斗中退出后从战斗前恢复，不保存敌人剩余生命。
- 配置版本、存档版本和随机种子必须写入存档。
- 旧 `DemoMetaProgress` 只迁移完成局数、图鉴和解锁 ID；天劫专属解锁改为玄铁剑痕或等价区域道痕。
- 旧局内存档如不存在直接开始新一世；如未来出现旧版本存档，版本不兼容时安全归档并回到首页，不猜测字段。
- 兼容层在新流程全部通过后删除，删除前必须有一次旧配置载入测试与新配置完整烟测。
