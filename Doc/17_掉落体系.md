# 掉落体系

> 掉落体系负责奖励池、稀有度、权重、保底和构筑引导。它现在必须同时接住新的开局结构，也就是说：奖励不是从真空里掉下来，而是要接上根脚、启程、首境与局内显化的连续性。

## 1. 设计目标

- 每局都有随机性。
- 每局又能稳定形成方向。
- 奖励会被开局起势和中期成型共同影响。
- 高稀有奖励有期待，但不会让低稀有奖励失去价值。

## 2. 奖励来源

| 来源 | 主要奖励 | 设计目的 |
| --- | --- | --- |
| 普通战斗 | 卡牌、灵石 | 推进基础构筑 |
| 精英战斗 | 法器、高品质卡牌 | 提供风险收益 |
| Boss | 神通、传说法器、功法强化 | 提供阶段质变 |
| 事件 | 功法、特殊法器、代价奖励 | 制造变局 |
| 商店 | 可购买奖励 | 修正构筑 |
| 洞府 | 功法、残篇 | 推进功法体系 |
| 秘藏 | 法器、稀有资源 | 提供特殊路线 |

## 3. 稀有度掉落概率

| 稀有度 | 普通战斗 | 精英 | Boss | 商店 |
| --- | ---: | ---: | ---: | ---: |
| 普通 | 65% | 35% | 0% | 45% |
| 稀有 | 25% | 40% | 30% | 35% |
| 史诗 | 8% | 20% | 45% | 15% |
| 传说 | 2% | 5% | 22% | 5% |
| 神话 | 0% | 0% | 3% | 0% |

## 5. 起手偏置如何进入掉落

掉落体系读取以下五类起手信息：

1. 根脚标签
2. 传承道痕标签
3. 启程线标签
4. 携行之物标签
5. 首境模板标签

这些信息只负责 `前两层的方向感`，不能替代中期构筑件。

### 5.1 起手阶段权重建议

| 来源 | 主标签加值 | 副标签加值 |
| --- | ---: | ---: |
| 根脚 | +8 | +4 |
| 传承道痕 | +12 | +6 |
| 启程线 | +18 | +8 |
| 携行之物 | +28 | +12 |
| 首境模板 | +10 | +5 |

## 6. 显化权重修正

玩家不是开局先选道途，而是在前两层逐步显化方向。

### 6.1 道途显化阶段

| 显化值 | 阶段 | 掉落表现 |
| --- | --- | --- |
| 0-39 | 未显化 | 仍以起手偏向和通用组件为主 |
| 40-69 | 起势 | 主标签相关候选显著增多 |
| 70-99 | 成形 | 功法、法器和关键卡明显倾斜 |
| 100+ | 定道 | 奖励池强烈收束到主道途 |

### 6.2 道途成形后的典型修正

| 道途 | 对应奖励权重提升 |
| --- | --- |
| 剑道 | 剑诀、飞剑、剑意、剑系法器 +40% |
| 法道 | 法术、灵气、元素状态、法系法器 +40% |
| 器道 | 神识、阵法、连锁、规则型法器 +40% |
| 魂道 | 召唤、献祭、魂火、魂系法器 +40% |
| 丹道 | 回复、炼化、丹意、成长型法器 +40% |

## 7. 已有组件修正

根据玩家已有构筑继续修正奖励池。

| 条件 | 修正 |
| --- | --- |
| 同属性卡牌 >= 3 | 对应属性奖励 +20% |
| 同状态组件 >= 3 | 对应状态奖励 +20% |
| 已有关键法器 | 相关功法和法器 +15% |
| 缺少防御组件 | 防御牌和恢复奖励 +10% |
| 卡组超过上限 80% | 删除和升级服务权重 +10% |

## 8. 保底规则

| 场景 | 保底 |
| --- | --- |
| 连续 2 次奖励无当前显化方向组件 | 下一次奖励至少出现 1 个当前显化方向组件 |
| 连续 3 次战斗无稀有以上奖励 | 下一次奖励稀有概率 +20% |
| Boss 前缺少核心输出 | 提高攻击或引擎组件权重 |
| Boss 前生命过低 | 修炼或恢复事件权重提高 |
| 商店刷新 | 至少 1 个当前显化方向商品 |

## 9. 三选一规则

战斗奖励三选一应采用结构化生成：

| 槽位 | 内容 |
| --- | --- |
| 槽位 1 | 当前显化方向相关奖励 |
| 槽位 2 | 通用补强或防御奖励 |
| 槽位 3 | 随机高波动奖励 |

这样既保证成型，也保留惊喜。

## 10. 奖励标签

每个奖励应至少有 2-4 个标签。

示例：

```text
御剑术：剑修 / 飞剑 / 攻击 / 启动
雷心：雷修 / 感电 / 法器 / 引擎
血祭：血修 / 禁术 / 风险 / 爆发
```

标签用于：

- 掉落权重
- 图鉴分类
- 商店筛选
- 流派识别

## 11. 设计底线

- 掉落不能完全随机。
- 保底不能让玩家每局都一模一样。
- 起手偏置只能帮助起势，不能让玩家第一层就毕业。
- 高稀有奖励要强，但不能让低稀有奖励无用。
- 玩家应感觉是在顺着这条出山路修道，而不是被系统硬塞答案。
