# 掉落体系

> 掉落体系负责奖励池、稀有度、权重、保底和构筑引导。目标是让随机性制造惊喜，而不是破坏流派成型。

## 1. 设计目标

- 每局都有随机性。
- 每局又能稳定形成方向。
- 奖励随道途和已有组件动态倾斜。
- 高稀有奖励有期待，但不让低稀有奖励失去意义。

## 2. 奖励来源

| 来源 | 主要奖励 | 设计目的 |
| --- | --- | --- |
| 普通战斗 | 卡牌、灵石 | 推进基础构筑 |
| 精英战斗 | 遗物、高品质卡牌 | 提供风险收益 |
| Boss | 神通、传说遗物、法宝 | 阶段质变 |
| 事件 | 功法、特殊遗物、代价奖励 | 制造变局 |
| 商店 | 可购买奖励 | 修正构筑 |
| 洞府 | 功法、残篇 | 推进功法体系 |
| 秘境 | 法宝、稀有遗物 | 提供特殊路线 |

## 3. 稀有度掉落概率

| 稀有度 | 普通战斗 | 精英 | Boss | 商店 |
| --- | ---: | ---: | ---: | ---: |
| 普通 | 65% | 35% | 0% | 45% |
| 稀有 | 25% | 40% | 30% | 35% |
| 史诗 | 8% | 20% | 45% | 15% |
| 传说 | 2% | 5% | 22% | 5% |
| 神话 | 0% | 0% | 3% | 0% |

## 4. 奖励类型权重

### 4.1 普通战斗

| 奖励 | 权重 |
| --- | ---: |
| 卡牌三选一 | 70% |
| 灵石 | 20% |
| 小型事件 | 5% |
| 低稀有遗物 | 5% |

### 4.2 精英战斗

| 奖励 | 权重 |
| --- | ---: |
| 遗物 | 50% |
| 高品质卡牌 | 25% |
| 功法残篇 | 15% |
| 法宝材料 | 10% |

### 4.3 Boss

| 奖励 | 权重 |
| --- | ---: |
| 遗物 | 35% |
| 神通卡 | 25% |
| 法宝 | 20% |
| 功法升级 | 15% |
| 大道残篇 | 5% |

## 5. 道途权重修正

玩家选择道途后，奖励池应动态倾斜。

| 道途 | 对应奖励权重提升 |
| --- | --- |
| 剑道 | 剑诀、飞剑、剑意、剑修遗物 +40% |
| 法道 | 法术、灵气、元素状态、法修遗物 +40% |
| 器道 | 法宝、神识、阵法、器修遗物 +40% |
| 魂道 | 召唤、献祭、魂火、魂修遗物 +40% |
| 丹道 | 回复、炼化、丹意、丹修遗物 +40% |

## 6. 已有组件修正

根据玩家已有构筑继续修正奖励池。

| 条件 | 修正 |
| --- | --- |
| 同属性卡牌 >= 3 | 对应属性奖励 +20% |
| 同状态组件 >= 3 | 对应状态奖励 +20% |
| 已有核心法宝 | 相关功法和遗物 +15% |
| 缺少防御组件 | 防御牌和恢复奖励 +10% |
| 卡组超过上限 80% | 删除和升级服务权重 +10% |

## 7. 保底规则

| 场景 | 保底 |
| --- | --- |
| 连续 2 次奖励无当前道途组件 | 下一次奖励至少出现 1 个当前道途组件 |
| 连续 3 次战斗无稀有以上奖励 | 下一次奖励稀有概率 +20% |
| Boss 前缺少核心输出 | 提高攻击或引擎组件权重 |
| Boss 前生命过低 | 修炼或恢复事件权重提高 |
| 商店刷新 | 至少 1 个当前道途商品 |

## 8. 三选一规则

战斗奖励三选一应采用结构化生成：

| 槽位 | 内容 |
| --- | --- |
| 槽位 1 | 当前道途相关奖励 |
| 槽位 2 | 通用补强或防御奖励 |
| 槽位 3 | 随机高波动奖励 |

这样既保证成型，也保留惊喜。

## 9. 奖励标签

每个奖励应至少有 2-4 个标签。

示例：

```text
御剑术：剑修 / 飞剑 / 攻击 / 启动
雷心：雷修 / 感电 / 遗物 / 引擎
血祭：血修 / 禁术 / 风险 / 爆发
```

标签用于：

- 掉落权重。
- 图鉴分类。
- 商店筛选。
- 流派识别。

## 10. 设计底线

- 掉落不能完全随机。
- 保底不能让玩家每局都一模一样。
- 高稀有奖励要强，但不能让低稀有奖励无用。
- 奖励池必须能被道途、状态、法宝和已有卡组共同影响。
- 玩家应感觉是“顺势修道”，不是被系统强行指定路线。
