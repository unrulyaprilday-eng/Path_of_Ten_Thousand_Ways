# 图鉴体系

> 图鉴体系负责收藏、解锁、成就感和轻量长期成长。新结构下，图鉴不仅记录“你拿过什么”，也记录“你这一世从哪里来、如何上路、最终修成了什么”。

## 1. 设计目标

- 记录玩家见过、获得过、击败过的内容。
- 记录根脚、启程、首境与最终道途之间的关系。
- 引导玩家尝试不同 Build，而不是重复刷数值。
- 提供轻量永久收益。

## 2. 图鉴分类

| 图鉴 | 内容 |
| --- | --- |
| 根脚图鉴 | 山门杂役、铁坊子、世家旁支等身份 |
| 启程图鉴 | 启程线标题、来历文案、携行之物、首境 |
| 传承道痕图鉴 | 已解锁道痕、偏向与来历 |
| 卡牌图鉴 | 攻击牌、术法牌、剑诀牌、禁术牌 |
| 功法图鉴 | 外功、内功、神通、大道 |
| 法器图鉴 | 启动型、引擎型、风险型、规则型 |
| 怪物图鉴 | 普通怪、精英、Boss、天劫 |
| 事件图鉴 | 洞府、心魔、雷劫台、商人、秘藏 |
| 流派图鉴 | 万剑流、雷剑流、血剑流等 |

## 3. 解锁规则

| 行为 | 解锁内容 |
| --- | --- |
| 首次遇见根脚或启程 | 解锁基础条目 |
| 首次获得 | 解锁卡牌 / 功法 / 法器基础条目 |
| 首次使用 | 解锁使用记录 |
| 完成特定条件 | 解锁进阶说明 |
| 使用其通关 | 解锁流派印记 |
| 击败相关 Boss | 解锁背景故事 |

## 4. 图鉴经验

| 品质 / 条目级别 | 首次解锁经验 |
| --- | ---: |
| 普通条目 | 1 |
| 黄阶 / 常规条目 | 3 |
| 玄阶 / 稀有条目 | 10 |
| 地阶 / 史诗条目 | 30 |
| 天阶 / 传说条目 | 100 |
| 道阶 / 神话条目 | 500 |

## 5. 图鉴等级

| 等级 | 所需经验 | 奖励 |
| --- | ---: | --- |
| 1 | 0 | 图鉴系统开启 |
| 2 | 50 | 初始灵石 +10 |
| 3 | 150 | 解锁 1 个初始卡牌候选 |
| 4 | 350 | 商店刷新次数 +1 |
| 5 | 700 | 解锁 1 个初始法器候选 |
| 6 | 1200 | Boss 图鉴显示弱点 |
| 7 | 2000 | 解锁高难度词条 |

图鉴奖励应偏向便利和选择空间，避免直接大幅增加战斗数值。

## 6. 开局图鉴

### 6.1 根脚图鉴

每个根脚条目至少包含：

- 根脚名
- 身份简介
- 常见启程线
- 偏向的首境
- 已完成次数
- 以该根脚完成过的流派印记

### 6.2 启程图鉴

每条启程线条目至少包含：

- 启程标题
- 来历文案
- 携行之物
- 首境名
- 主副标签
- 首次完成记录
- 对应常见成形流派

设计意义：

- 玩家能回看“这一局是怎么开的”。
- 图鉴本身成为世界观沉浸的一部分，而不是纯收集页。

## 7. 流派图鉴

流派图鉴记录玩家完成过的构筑。

| 流派印记 | 解锁条件 |
| --- | --- |
| 初窥门径 | 使用该流派击败第一个 Boss |
| 登堂入室 | 使用该流派通关 |
| 大道有成 | 使用该流派在高难度通关 |
| 逆天改命 | 使用该流派击败天劫且生命低于 10% |

推荐额外记录：

- 常见根脚
- 常见启程线
- 常见首境
- 本流派最常见关键法器

## 8. 怪物图鉴

| 信息 | 解锁条件 |
| --- | --- |
| 名称和立绘 | 首次遭遇 |
| 基础技能 | 首次击败 |
| 弱点 | 击败 3 次 |
| 背景故事 | 完成相关事件或成就 |

## 9. 图鉴与掉落关系

图鉴可以影响初始候选池和局外解锁，但不应直接污染局内掉落。

允许：

- 解锁新的根脚或启程线展示
- 解锁新的初始卡牌候选
- 解锁新的初始法器候选
- 解锁新的事件或 Boss 条目
- 解锁更高难度挑战词条

避免：

- 单纯提高所有伤害
- 强制玩家刷图鉴才能通关
- 让老玩家开局碾压新难度

## 10. 展示需求

每个图鉴条目应包含：

- 名称
- 类型
- 品质 / 稀有度
- 标签
- 效果说明
- 解锁状态
- 使用次数
- 通关次数
- 相关流派
- 世界观短文

## 11. 设计底线

- 图鉴奖励以选择空间为主。
- 图鉴应鼓励尝试，而不是制造重复劳动。
- 图鉴必须记录开局结构，不只记录战斗物件。
- 流派图鉴是玩家成就感的核心展示之一。
