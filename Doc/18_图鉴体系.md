# 图鉴体系

> 图鉴体系负责收藏、解锁、成就感和轻量长期成长。它应鼓励玩家尝试不同流派，而不是强迫重复刷数值。

## 1. 设计目标

- 记录玩家见过、获得过、击败过的内容。
- 引导玩家尝试不同道途和 Build。
- 提供轻量永久收益。
- 成为世界观、怪物、功法和法宝说明入口。

## 2. 图鉴分类

| 图鉴 | 内容 |
| --- | --- |
| 卡牌图鉴 | 攻击牌、术法牌、剑诀牌、禁术牌 |
| 功法图鉴 | 外功、内功、神通、大道 |
| 法宝图鉴 | 飞剑、鼎、镜、幡、塔、印 |
| 遗物图鉴 | 启动型、引擎型、风险型、规则型 |
| 怪物图鉴 | 普通怪、精英、Boss、天劫 |
| 事件图鉴 | 洞府、心魔、雷劫台、商人、秘境 |
| 流派图鉴 | 万剑流、雷剑流、血剑流等 |

## 3. 解锁规则

| 行为 | 解锁内容 |
| --- | --- |
| 首次获得 | 解锁基础条目 |
| 首次使用 | 解锁使用记录 |
| 完成特定条件 | 解锁进阶说明 |
| 使用其通关 | 解锁流派印记 |
| 击败相关 Boss | 解锁背景故事 |

## 4. 图鉴经验

| 品质 | 首次解锁经验 |
| --- | ---: |
| 凡阶 | 1 |
| 黄阶 | 3 |
| 玄阶 | 10 |
| 地阶 | 30 |
| 天阶 | 100 |
| 道阶 | 500 |

## 5. 图鉴等级

| 等级 | 所需经验 | 奖励 |
| --- | ---: | --- |
| 1 | 0 | 图鉴系统开启 |
| 2 | 50 | 初始灵石 +10 |
| 3 | 150 | 解锁 1 个初始卡牌候选 |
| 4 | 350 | 商店刷新次数 +1 |
| 5 | 700 | 解锁 1 个初始法宝候选 |
| 6 | 1200 | Boss 图鉴显示弱点 |
| 7 | 2000 | 解锁高难度词条 |

图鉴奖励应偏向便利和选择空间，避免直接大幅增加战斗数值。

## 6. 流派图鉴

流派图鉴记录玩家完成过的构筑。

| 流派印记 | 解锁条件 |
| --- | --- |
| 初窥门径 | 使用该流派击败第一个 Boss |
| 登堂入室 | 使用该流派通关 |
| 大道有成 | 使用该流派在高难度通关 |
| 逆天改命 | 使用该流派击败天劫且生命低于 10% |

## 7. 怪物图鉴

| 信息 | 解锁条件 |
| --- | --- |
| 名称和立绘 | 首次遭遇 |
| 基础技能 | 首次击败 |
| 弱点 | 击败 3 次 |
| 背景故事 | 完成相关事件或成就 |

## 8. 图鉴与掉落关系

图鉴可以影响初始候选池，但不应直接污染局内掉落。

允许：

- 解锁新的初始卡牌候选。
- 解锁新的初始法宝候选。
- 解锁新的事件或 Boss 条目。
- 解锁更高难度挑战词条。

避免：

- 单纯提高所有伤害。
- 强制玩家刷图鉴才能通关。
- 让老玩家开局碾压新难度。

## 9. 展示需求

每个图鉴条目应包含：

- 名称。
- 类型。
- 品质 / 稀有度。
- 标签。
- 效果说明。
- 解锁状态。
- 使用次数。
- 通关次数。
- 相关流派。
- 世界观短文。

## 10. 设计底线

- 图鉴奖励以选择空间为主。
- 图鉴应鼓励尝试，而不是制造重复劳动。
- 图鉴文本要补充修仙世界观。
- 流派图鉴是玩家成就感的核心展示。
