# 核心玩法系统设计（Gameplay Systems）

## 1. 节点式肉鸽地图
起点→构筑→强化→Boss→终局

节点类型：
战斗 / 事件 / 商店 / 修炼 / Boss

## 2. 流派成型系统
三阶段：
- 种子期（选方向）
- 成型期（联动出现）
- 爆发期（质变）

## 3. 道途系统
剑道 / 法道 / 器道 / 魂道

## 4. 战斗系统
45°视角 + 自动飞剑 + 卡牌操作

资源：
灵气 / 神识 / 剑意

## 5. 飞剑系统
自动攻击单位（雷/火/冰/血）

## 6. 法宝系统
规则改变器（镜/葫芦/鼎/塔）

## 7. 核心体验
构筑成型 → 联动触发 → 爆发清屏
