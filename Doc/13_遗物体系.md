# 遗物体系

> 遗物又称道器，是局内永久生效的规则修改器。它不应只是装备属性，而应改变玩家这一局的构筑方向。

## 1. 设计目标

遗物负责提供三类体验：

- 改变规则：让玩家玩法发生质变。
- 强化流派：补足当前 Build 的关键组件。
- 制造抉择：通过代价、风险或限制换取高收益。

## 2. 遗物基础规则

| 规则 | 建议 |
| --- | --- |
| 生效范围 | 单局内永久生效 |
| 获取来源 | 精英、Boss、事件、商店、奇遇 |
| 携带上限 | 随境界提升，参考 `06_境界与数值框架.md` |
| 同名叠加 | 默认不可叠加，特殊遗物可升级 |
| 移除方式 | 特殊事件、商店净化、Boss 奖励替换 |

## 3. 遗物分类

| 类型 | 作用 | 示例 |
| --- | --- | --- |
| 启动型 | 帮助前期建立流派 | 开局获得 1 层剑意 |
| 引擎型 | 提供持续循环 | 每次飞剑命中获得 1 点神识 |
| 爆发型 | 提供关键爆发窗口 | 每场战斗首次终结技伤害翻倍 |
| 防御型 | 提供生存结构 | 护盾不会在回合结束清空 |
| 经济型 | 增加资源收益 | 灵石获得 +20% |
| 风险型 | 代价换收益 | 生命低于 30% 时伤害 +80% |
| 规则型 | 修改底层玩法 | 每回合第一张攻击牌免费 |

## 4. 稀有度与投放

| 稀有度 | 定位 | 出现来源 |
| --- | --- | --- |
| 普通 | 基础补强 | 普通战斗、商店 |
| 稀有 | 流派组件 | 精英、事件、商店 |
| 史诗 | 构筑核心 | 精英、Boss |
| 传说 | 流派引擎 | Boss、稀有奇遇 |
| 神话 | 规则修改 | 终局 Boss、特殊奇遇 |

## 5. 遗物强度预算

| 稀有度 | 数值型收益参考 | 机制复杂度 |
| --- | ---: | --- |
| 普通 | 5%-15% | 单一数值或简单触发 |
| 稀有 | 15%-30% | 明确流派倾向 |
| 史诗 | 30%-60% | 可成为构筑核心 |
| 传说 | 60%-100% | 改变战斗节奏 |
| 神话 | 不按常规倍率 | 修改规则或胜利方式 |

## 6. 流派遗物样例

| 遗物 | 稀有度 | 流派 | 效果 |
| --- | --- | --- | --- |
| 剑骨 | 稀有 | 剑修 | 飞剑数量 +1 |
| 剑冢残碑 | 史诗 | 剑修 | 每消耗 10 层剑意，生成 1 把临时飞剑 |
| 万剑剑匣 | 传说 | 剑修 | 飞剑返回时有 30% 概率再次攻击 |
| 雷心 | 稀有 | 雷修 | 感电伤害 +30% |
| 九霄雷印 | 史诗 | 雷修 | 暴击时触发一次额外雷击 |
| 神火鼎 | 史诗 | 火修 | 灼烧触发时扩散到相邻目标 |
| 血魔珠 | 稀有 | 血修 | 每损失 10% 生命，伤害 +8% |
| 九幽幡 | 传说 | 魂修 | 敌人死亡时生成 1 个亡魂 |
| 昊天镜碎片 | 传说 | 器修 | 每场战斗第一次法宝效果触发两次 |
| 因果玉简 | 神话 | 天机 | 战斗结束时，将本场最高单次伤害的 20% 记录为因果 |

## 7. 风险遗物规则

风险遗物必须同时具备收益和代价。

| 代价类型 | 示例 |
| --- | --- |
| 生命代价 | 每回合开始失去 3% 最大生命 |
| 资源代价 | 初始灵气 -1，但伤害 +25% |
| 卡组代价 | 每场战斗开始加入 1 张心魔牌 |
| 路线代价 | 精英战奖励更高，但普通战治疗降低 |

## 8. 遗物槽位建议

| 境界 | 遗物上限 | 设计目的 |
| --- | ---: | --- |
| 炼气 | 2 | 建立基础方向 |
| 筑基 | 3 | 出现第一轮联动 |
| 金丹 | 4 | 支撑主流派成型 |
| 元婴 | 5 | 开始混合流派 |
| 化神 | 6 | 支撑复杂引擎 |
| 炼虚 | 7 | 增加规则变化 |
| 合体 | 8 | 双流派空间 |
| 大乘 | 9 | 终局构筑 |
| 渡劫 | 10 | 天劫压力应对 |
| 真仙 | 12 | 完整上限体验 |

## 9. 获取节奏

| 层数 | 遗物目标 |
| --- | --- |
| 1-2 | 给方向，不给完整引擎 |
| 3-4 | 给联动核心，帮助成型 |
| 5+ | 给质变组件，制造爆发 |
| Boss 后 | 给稀有或传说级选择 |

## 10. 设计底线

- 遗物必须能让玩家改变选择。
- 传说及以上遗物应具有构筑记忆点。
- 风险遗物必须让收益足够诱人。
- 经济遗物不能压过战斗遗物。
- 神话遗物数量必须严格限制。
