# 战斗系统与表现

> 本文是当前 DEMO 战斗设计真源。状态细则见 `05_状态与多目标规则.md`，视觉资源与生产规范见 `08_UI美术与资源生产规范.md`，实施顺序见 `10_DEMO重构实施计划.md`。

## 1. 战斗定位

战斗是牌库驱动的半实时修士斗法，但玩家进入战斗时不是带着一套现成卡组，而是带着这一世已经学会的少量法诀、心法和本命法器。

核心体验：

- 本命法器按独立冷却持续自动攻击。
- 敌人按意图读条行动，玩家始终能预判主要威胁。
- 心法是常驻循环规则，并提供一门可进入牌库的心诀。
- 剑诀、法术、身法以小型法诀牌库低频介入战斗。
- 普通战支持有限多敌人，构筑成型后必须出现多目标连锁与清场。
- 战斗表现像空中或纵深场景中的修士斗法，不读成横向站桩卡牌战。

## 2. 开局战斗载入

DEMO 开局只有：

| 来源 | 初始内容 | 战斗职责 |
| --- | --- | --- |
| 本命法器 | 残剑胚 | 独立冷却自动攻击，不进入牌库 |
| 一阶心法 | 旁支吐纳法 | 常驻回灵 / 轻回复规则，并提供 `吐纳归息` |
| 初始剑诀 | 残卷御剑式 | 主动催动残剑胚、积累剑意或改变下一次攻击 |

初始法诀牌库只有 2 门法诀。完整一世的牌库以 6-9 门为 DEMO tuning；所有法诀必须有世界内来源，不以逐战通用三选一填充。

两门主动法诀由开局故事能力包载入：`旁支吐纳法`提供主动心诀`吐纳归息`，`残卷御剑式`作为初阶剑诀。该载入接口按“根本修行法授予技能 + 初阶战技”定义；未来可以替换为炼体术技能与初阶拳法，战斗系统不得按“剑修”名称推导卡牌。

本命法器冷却、灵力上限、回灵速度、抽牌节奏与法诀费用均数据驱动。当前 `2.2s` 飞剑齐射只作为迁移调优起点，不是永久常量。

## 3. 半实时演算

| 系统 | 推进方式 |
| --- | --- |
| 灵力 | 按秒持续增长，受心法、境界与状态修改 |
| 本命法器 | 按独立冷却选择目标、出手、命中并归位 |
| 法诀牌库 | 抽取、打出、弃置、洗回；小牌库必须避免长时间空窗 |
| 敌人 | 各自维护意图、读条、目标和技能冷却 |
| 后获法器 | 多数自动或条件触发，少数主动件占独立入口 |
| 状态 | 按时间、命中、读条或阈值结算，不使用固定回合 |

灵力费用与冷却是两套预算：费用控制当下取舍，冷却控制重复频率。普通法诀不应同时使用高费用与长冷却双重惩罚。

## 4. 多敌人与锁定

普通战支持 1-3 名敌人；精英通常是一名主体，允许携带召唤物；小 Boss 和区域 Boss 可以生成部位、契钉或附属目标。

目标规则：

1. 玩家点击敌方主体、召唤物或 Boss 部位后立即锁定，不追加二次确认。
2. 未锁定时，本命法器优先攻击即将完成高威胁意图的合法目标，其次攻击前排或配置优先目标。
3. 单体法诀作用于锁定目标；群攻、雷链、万剑类效果按自身规则扩散。
4. 锁定目标死亡或失效后，系统自动选择新目标，不中断本命法器演算。
5. 锁定只改变可定向攻击，不改变敌方意图、范围伤害与场景危险结算。
6. Boss 的契钉、甲片核心等临时目标被击破后，锁定自动返回 Boss 主体。

每名敌人显示紧凑意图图标与倒计时；只有锁定目标展开详细说明。禁止为 3 名敌人复制 3 套顶部大面板。

## 5. 普通战空间构图

普通战使用带纵深的 2.5D 斜向构图：

- 主角位于左下，三分之四背视角，面向右上。
- 主角为男性长发剑修，墨黑外袍与灰白内衬为主色。
- 普通敌人分布在右上方前、中、后三个深度槽，面向左下。
- 场景透视、角色朝向和主要攻击轴共同形成左下到右上的斜向运动。
- 手牌与灵力集中在底部中间偏右，不遮挡主角与脚下承载物。
- 玩家状态靠近主角，敌方意图靠近目标，中央斜向通道留给飞剑与法术。

当前布局锚点：

- 主角主体根锚点在常规战为 `(0.175, 0.385)`、开场战为 `(0.19, 0.42)`；角色尺寸不随本次位移放大，脚部和承载面保持在底部操作区左侧安全区。
- 灵气增长条独立放在手牌上方约 `x=39%-66%`、`y=26%-30%`，不再藏在左上状态框内。
- 本命法器自动攻击倒计时贴近主角右侧和承载物，常规战位于 `(0.305, 0.35)`，开场战位于 `(0.32, 0.36)`。
- 手牌区限制在 `x=31%-89%`、`y=2%-23.5%`，不得向左吞掉角色、脚下法器或场景落脚面。
- 有承载类法器时替换脚下表现；无承载类法器时使用区域地面、断石或残梁。手持、背负与环绕法器不参与脚下切换。

不同深度槽只影响画面位置、缩放和轨迹，不改变战斗逻辑中的敌人强度或先后手。

## 6. Boss 战空间构图

区域 Boss 使用独立构图：

- 主角仍位于左下。
- Boss 位于正上方并占据上半屏主要面积，攻击方向为向下或斜向左下。
- 进入 Boss 战时允许一次构图切换；战斗过程中不频繁移动镜头。
- 前两幕小 Boss 保持右上斜向构图，但体型、前景遮挡和意图演出高于精英。
- 只有区域最终 Boss 使用上方压屏布局，保留视觉升级。

DEMO 最终 Boss 为 `玄铁镇矿剑傀`，天劫不进入当前纵切。其阶段职责：

| 阶段 | 机制与表现 |
| --- | --- |
| 玄铁锁矿 | 多段命中打落甲片，验证本命法器频率与多剑规模 |
| 残契缚剑 | 生成可锁定契钉，短暂束缚少量飞剑；击破后恢复节奏 |
| 剑炉开膛 | 青绿核心暴露并蓄力镇矿重斩，提供明确终结爆发窗口 |

第一幕小 Boss 优先使用矿兽类，第二幕优先使用吞剑矿魈等怪兽类，避免敌人长期只是人形残魂换名。

## 7. 承载物与角色分层

主角不能作为无承载的悬空贴图。战斗角色分层至少包含：

1. 场景落脚面或承载类法器。
2. 主角主体。
3. 长发、衣带、衣摆等风动层。
4. 环绕、手持或背负法器层。
5. 本命法器与战斗飞剑层。
6. 护体、受击、状态与终极技 VFX 层。

没有承载类法器时，主角站在符合场景的石台、断梁、崖面或悬石上。获得飞剑、葫芦、阵盘、墨莲等承载类法器后才替换脚下表现。印、镜、剑匣等不适合承载的法器应环绕、背负或手持。

承载法器不计入本命法器攻击数量，避免画面与数值语义冲突。

## 8. 镜头规则

- 普通攻击、出牌、敌方技能和普通受击不切镜头。
- 普通反馈依靠动作前摇、轨迹、局部震动、命中停顿、墨迹残留与声音完成。
- 终极技允许短促推镜、聚焦、瞬时慢速或墨迹遮切。
- 击杀允许短促停顿和破敌镜头，结束后直接进入战后过渡。
- Boss 阶段转换只改变姿态、场景层和光色，不得长时间夺走玩家操作视野。
- 镜头变化必须服从当前锁定目标位置，不播放固定横向演出。

## 9. 攻击轨迹与反馈

轨迹由攻击者锚点、目标锚点、法诀类型和构筑状态共同决定：

| 方向 | 轨迹语法 |
| --- | --- |
| 万剑 | 扇形、分叉弧线、回环列阵与多批齐射 |
| 雷剑 | 短促折线、闪断和跨目标连锁 |
| 煞契 / 血剑 | 弧钩、朱砂残线和回收式斩痕 |
| 敌方近战 | 从右上或上方向左下突进，返回原深度槽 |
| 场景危险 | 预警落点与角色、目标轨迹分层显示 |

命中反馈优先级：伤害数字与生命变化、目标后仰或墨散、锐利剑痕 / 雷光 / 朱砂残线、轻震与短停顿、残留痕迹。禁止以满屏白闪代替层次。

## 10. UI 与色彩

战斗主画面以黑、白、冷墨灰为基础，青绿、朱砂和冷白雷光按规则点染。米白或暖纸色只用于局部法诀、题签和卷轴器物，不得叠加全屏暖黄洗色。

顶部只承载必要生命、阶段与意图；底部操作区不得形成全宽厚重黑台。角色、飞剑和敌人必须比 UI 面板先被看见。

初始牌库只有 2 门法诀，后期牌库总量为 6-9 门；手牌同时展示上限为 6。战斗 UI 需在 `1920x1080` 和 `1280x720` 下验证 2、4、6 张同时在手，以及 6-9 门牌库的抽取、弃置和洗回信息，不能把 9 门法诀误做成 9 张同时铺开。

## 11. 时长与验收 tuning

| 遭遇 | 目标时长 |
| --- | --- |
| 入场首战 | 30-45 秒 |
| 普通战 | 50-80 秒 |
| 精英 | 80-110 秒 |
| 小 Boss | 100-150 秒 |
| 区域 Boss | 150-210 秒 |

以上为 DEMO tuning。战斗验收至少覆盖：

- 2 门初始法诀与 6-9 门后期牌库的循环。
- 1、2、3 名敌人的意图、锁定、自动攻击与死亡换目标。
- 群攻、连锁、状态逐目标归属和清场反馈。
- 普通斜向构图、小 Boss 构图与上方压屏 Boss 构图。
- 场景落脚与承载类法器切换。
- 终极技和击杀镜头不影响继续操作或结算。
- 无全屏米黄洗色、无顶部多面板堆叠、无底部黑台吞噬战场。
