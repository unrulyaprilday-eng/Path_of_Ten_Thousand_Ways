# 战斗场景规则设计

> 本文档只维护战斗界面、镜头、演出和流程规则。战斗在项目中的定位见 `01_核心框架设计.md`，战斗原型与流派验证见 `05_流派成型与战斗原型.md`。

## 1. 设计目标

玩家虽然通过卡牌操作战斗，但屏幕感受应是“修士斗法”，而不是站桩卡牌对战。

表现目标：

- 伪动态战斗表现。
- 高沉浸感空中斗法。
- 卡牌驱动动作与特效。
- 低成本高表现力。
- 流派姿态差异明显。

## 2. 战斗界面布局

### 2.1 顶部区域

- 战斗倒计时。
- 敌方状态信息。
- Buff / Debuff 显示。
- Boss 阶段提示。

### 2.2 中部战场区域

| 区域 | 位置 | 用途 |
| --- | --- | --- |
| 我方单位 | 左下区域 | 始终可见，展示流派姿态 |
| 敌方单位 | 右侧区域 | 始终可见，承接受击反馈 |
| 中央轨迹区 | 中间 | 法术、飞剑、投射物、连锁特效 |

我方单位表现规则：

- 持续待机动画。
- 轻微上下浮动。
- 根据流派显示不同姿态。

流派姿态示例：

| 流派 | 表现 |
| --- | --- |
| 飞剑流 | 人物站立于飞剑之上，飞剑缓慢摆动，衣摆飘动 |
| 法修流 | 悬空漂浮，法器环绕，灵气粒子持续流动 |
| 体修流 | 凌空踏步，气血环绕，力量感更重 |

### 2.3 底部操作区域

- 当前手牌，推荐 5-8 张。
- 灵气：当前值、最大值、回合恢复量。
- 法宝槽：主动法宝、冷却或神识消耗。
- 结束规划按钮。

示例：

```text
灵气：15 / 20
```

## 3. 场景分层

| 层级 | 内容 | 运动速度 |
| --- | --- | --- |
| 远景层 | 云海、仙山、星空、雷云、秘境 | 约 0.1 倍 |
| 中景层 | 悬空平台、天空裂隙、山谷、秘境建筑 | 约 0.3 倍 |
| 角色层 | 玩家、敌人 | 正常动画速度 |
| 特效层 | 飞剑、火焰、雷电、冰霜、剑气 | 根据技能演出 |

角色层应保持清晰，特效层不能长期遮挡手牌与关键状态。

## 4. 卡牌驱动演出规则

卡牌决定：

- 角色动作。
- 特效类型。
- 攻击轨迹。
- 命中反馈。
- 结算节奏。

### 4.1 飞剑系

| 卡牌 | 演出流程 |
| --- | --- |
| 剑气斩 | 飞剑离体 -> 飞行攻击 -> 命中目标 -> 返回角色身边 |
| 万剑诀 | 剑阵展开 -> 多把飞剑生成 -> 同时发射 -> 连续命中 |
| 剑遁 | 人物虚化 -> 快速位移 -> 残影特效 |

### 4.2 法术系

| 卡牌 | 演出流程 |
| --- | --- |
| 火球术 | 抬手施法 -> 火球凝聚 -> 飞向敌人 -> 爆炸 |
| 掌心雷 | 雷球形成 -> 雷电射出 -> 命中麻痹 |
| 九天神雷 | 天空变暗 -> 雷云出现 -> 落雷轰击 |

### 4.3 体修系

| 卡牌 | 演出流程 |
| --- | --- |
| 崩山拳 | 前冲 -> 重拳攻击 -> 返回原位 |
| 龙象劲 | 巨大拳影 -> 远程冲击 |
| 八荒踏 | 跃起 -> 踏击地面 -> 震荡波扩散 |

## 5. 受击反馈规则

| 触发 | 表现 |
| --- | --- |
| 轻击 | 小幅后仰 |
| 重击 | 大幅后仰 |
| 暴击 | 击飞、屏幕震动 |
| 冰冻 | 冰晶覆盖、动作减缓 |
| 雷击 | 电流特效、短暂抽搐 |
| 剑气攻击 | 剑痕、切割光效 |

受击反馈优先级高于攻击待机动画，但不能打断关键 Boss 阶段演出。

## 6. 战斗时间规则

战斗采用规划与执行交替结构。

| 阶段 | 推荐时长 | 玩家或系统行为 |
| --- | ---: | --- |
| 规划阶段 | 15 秒 | 出牌、调整顺序、激活法宝、规划连招 |
| 执行阶段 | 5 秒 | 系统演出飞剑、法术、连锁、伤害结算 |
| 下一轮 | 即时 | 刷新手牌、恢复资源、进入新规划阶段 |

超时规则：规划阶段结束时自动进入执行阶段。

## 7. 可读性规则

- 同屏特效过多时，弱化低优先级粒子。
- Boss 关键读条必须始终可见。
- 玩家当前灵气与手牌费用必须始终可读。
- 连锁爆发可以华丽，但结算来源需要在日志或浮字中可追溯。

## 8. 战斗表现结论

最终镜头形式采用 2.5D 横版空中斗法。

核心特色：

- 持续御剑飞行。
- 多层动态背景。
- 卡牌驱动演出。
- 强受击反馈。
- 修仙流派差异化表现。
