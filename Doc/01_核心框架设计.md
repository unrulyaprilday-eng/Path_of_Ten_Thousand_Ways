# 修仙肉鸽卡牌 RPG 核心框架设计

> 来源整理：`修仙肉鸽卡牌rpg 核心框架设计文档.docx`

## 1. 项目定位

本项目是一款专业独立向修仙肉鸽卡牌 RPG，融合以下方向：

- 修仙世界观
- Roguelike 肉鸽构筑
- 卡牌战斗
- RPG 长期养成
- 单局历练与局外成长

核心不是抽卡、数值堆叠或传统挂机修仙，而是：

> 这一世，我修成了什么道？

玩家每一局历练都会形成不同修炼流派，例如：

- 万剑流
- 天雷流
- 炼丹毒修流
- 血祭魔修流
- 无限法宝流
- 召魂尸傀流

核心乐趣来自 Build 构筑、功法联动、法宝组合、流派成型与爆发成长。

## 2. 整体游戏结构

游戏分为局外长期成长与局内单次历练。

### 2.1 局外：长期成长

局外系统承载玩家长期追求与账号成长，包括：

- 宗门修行
- 境界提升
- 功法解锁
- 法宝培养
- 宗门建设
- NPC 关系
- 道统成长
- 图鉴收集

### 2.2 局内：单次历练

局内流程承载肉鸽构筑与战斗体验，包括：

- 地图探索
- 战斗
- 随机事件
- 功法获得
- 法宝强化
- 奇遇
- Boss 挑战

每一次历练都可能成功飞升、中途陨落，或带回部分资源。

## 3. 世界观框架

### 3.1 世界结构

| 区域 | 内容 |
| --- | --- |
| 人界 | 各大仙门、王朝、秘境、妖兽山脉 |
| 魔界 | 魔宗、深渊裂隙、血海、邪神 |
| 灵界 | 飞升后开放，包含法则战斗与大能遗迹 |

### 3.2 核心阵营

| 阵营 | 特点 |
| --- | --- |
| 正道 | 稳定成长、防御、剑阵、灵气循环 |
| 魔道 | 献祭、吸血、风险收益、爆发 |
| 妖道 | 变身、持续成长、兽魂、狂暴 |
| 器道 | 法宝联动、傀儡、阵法、自动连锁 |

## 4. 玩家成长系统

### 4.1 境界系统

境界是长期目标核心。境界设计不应只是增加攻击或生命，而应解锁新机制、新系统和新 Build。

| 境界 | 核心作用 |
| --- | --- |
| 炼气 | 基础卡组开启 |
| 筑基 | 开启第二法宝槽 |
| 金丹 | 开启道纹系统 |
| 元婴 | 开启分身机制 |
| 化神 | 开启法则卡牌 |
| 炼虚 | 开启跨界历练 |
| 合体 | 开启双流派 |
| 大乘 | 开启天劫玩法 |
| 飞升 | 开启灵界 |

境界机制示例：

- 金丹：飞剑数量 +1，可同时维持两个灵根状态。
- 元婴：死亡后元婴短暂继续战斗。
- 化神：可使用法则卡。

### 4.2 灵根系统

灵根不是职业，而是属性倾向。

| 灵根 | 特点 |
| --- | --- |
| 火 | 燃烧、持续伤害 |
| 冰 | 控制、冻结 |
| 雷 | 爆发、连锁 |
| 木 | 回复、成长 |
| 土 | 护盾、防御 |

后期可出现稀有成长路线：

- 血灵根
- 剑灵根
- 天雷灵根
- 九幽灵根

### 4.3 道统系统

道统是真正的职业方向。

| 道统 | 特点 | Build 方向 |
| --- | --- | --- |
| 剑修 | 高频攻击、飞剑连击、剑阵 | 无限飞剑、暴击剑修、剑气扩散 |
| 法修 | 法术爆发、元素联动、大范围伤害 | 天雷流、烈焰流、冰封流 |
| 体修 | 反击、生存、近战爆发 | 吸血流、反伤流、狂暴流 |
| 魂修 | 控制、召唤、献祭 | 尸傀流、亡魂流、心魔流 |
| 器修 | 法宝组合、自动连锁、阵法 | 炮台流、连锁法宝流、阵法流 |

## 5. 战斗系统

### 5.1 战斗形式

推荐采用半即时卡牌战斗。

玩家通过消耗灵气打牌、控制法宝、操作飞剑来影响战局；敌人拥有攻击节奏和技能读条。目标是在保留卡牌策略的基础上，提高战斗表现力，让玩家感受到修士斗法。

### 5.2 战斗资源

| 资源 | 定位 | 用途 |
| --- | --- | --- |
| 灵气 Energy | 基础出牌资源 | 打出普通卡牌与基础术法 |
| 神识 Mind | 高级技能资源 | 操控法宝、启动阵法、控制分身 |
| 剑意 Sword Intent | 剑修专属资源 | 强化飞剑、触发剑阵 |

## 6. 卡牌系统

### 6.1 卡牌分类

| 类型 | 定位 | 示例 |
| --- | --- | --- |
| 功法牌 | 永久被动，改变规则，构筑核心 | 万剑归宗、九霄神雷诀 |
| 术法牌 | 主动技能 | 火球术、冰封术、天雷引 |
| 法宝牌 | 召唤法宝 | 镇妖塔、吞天葫、昊天镜 |
| 剑诀牌 | 飞剑专属 | 御剑术、剑气纵横、万剑齐发 |
| 禁术牌 | 高风险高收益 | 血祭、燃魂、天魔解体 |

## 7. 法宝系统

法宝不是装备，而是改变战斗玩法的核心组件。

| 法宝类型 | 特点 | 示例 |
| --- | --- | --- |
| 飞剑 | 高频攻击、连锁、剑阵 | 青冥剑、赤霄剑、天雷剑 |
| 鼎 | 炼化、持续增益、毒 | 神火鼎 |
| 镜 | 复制、反弹、幻象 | 昊天镜 |
| 幡 | 召魂、献祭、亡灵 | 九幽幡 |
| 塔 | 镇压、控场、防御 | 镇妖塔 |
| 印 | 爆发、镇杀、范围伤害 | 翻天印 |

法宝联动示例：

- 昊天镜 + 飞剑：复制飞剑攻击。
- 九幽幡 + 血祭功法：死亡单位生成亡魂。
- 神火鼎 + 火灵根：燃烧伤害翻倍。

## 8. 肉鸽构筑系统

核心原则：玩家每一局获得不同功法、不同法宝，并形成不同流派。

### 8.1 奇遇系统

| 奇遇类型 | 奖励或风险 |
| --- | --- |
| 洞府 | 获得功法 |
| 上古遗迹 | 获得法宝 |
| 心魔幻境 | 高风险高收益 |
| 神秘商人 | 购买稀有物品 |
| 渡劫台 | 挑战强化 |

### 8.2 遗物系统

遗物又称道器，是局内永久生效的规则强化。

| 遗物 | 效果 |
| --- | --- |
| 剑骨 | 飞剑数量 +1 |
| 雷心 | 雷法连锁次数 +1 |
| 血魔珠 | 损失生命提升伤害 |

### 8.3 卡牌进化

同一张卡可以升级并形成阶段成长：

- 火球术 -> 爆炎术 -> 九天炎爆
- 御剑术 -> 万剑诀 -> 剑河降世

## 9. 局内流程

### 9.1 标准一局流程

1. 宗门准备：选择角色、初始法宝、初始功法。
2. 历练地图：多节点路线，包含战斗、奇遇、商店与 Boss。
3. 阶段 Boss：例如妖王、魔尊、天劫。
4. 回宗结算：获得修为、材料与解锁内容。

## 12. 商业化建议

推荐方向：

- 外观型：飞剑皮肤、法宝特效、宗门外观、战斗特效。
- Build 扩展型：新角色、新道统、新法宝包。

不建议强数值付费、SSR 抽卡碾压或纯战力体系，否则会破坏肉鸽构筑乐趣。

## 13. 项目核心卖点

一句话定位：

> 一款以修仙世界为背景的 Roguelike 构筑 RPG。

核心体验：

> 玩家不是抽 SSR，而是这一世修成了什么道。

玩家爽点：

- 飞剑满屏
- 无限连锁
- 法宝组合
- 功法联动
- 极限 Build
- 渡劫飞升
- 逆天改命

## 14. 后续建议优先级

| 阶段 | 优先内容 |
| --- | --- |
| 第一阶段 | 战斗原型、卡牌系统、法宝系统、功法联动 |
| 第二阶段 | 肉鸽地图、奇遇系统、Boss 机制 |
| 第三阶段 | 宗门成长、NPC 关系、DLC 扩展 |

## 15. 核心原则

整个项目必须始终围绕构筑感，而不是数值碾压、单纯挂机或自动战力。

玩家每一局都应该：

- 有新套路
- 有新成长
- 有新组合

最终形成：

> 修仙版 Slay the Spire + RPG 成长 + Build 构筑。
