# 修仙肉鸽卡牌 RPG 核心框架设计

> 来源整理：`修仙肉鸽卡牌rpg 核心框架设计文档.docx`

## 1. 项目定位

本项目是一款专业独立向修仙肉鸽卡牌 RPG，融合以下方向：

- 修仙世界观
- Roguelike 肉鸽构筑
- 卡牌战斗
- RPG 长期养成
- 单局历练与局外成长

核心不是抽卡、数值堆叠或传统挂机修仙，而是：

> 这一世，我修成了什么道？

玩家每一局历练都会形成不同修炼流派，例如：

- 万剑流
- 天雷流
- 炼丹毒修流
- 血祭魔修流
- 无限法器流
- 召魂尸傀流

核心乐趣来自 Build 构筑、功法联动、法器组合、流派成型与爆发成长。

## 2. 整体游戏结构

游戏分为局外长期成长与局内单次历练。

### 2.1 局外：长期成长

局外系统承载玩家长期追求与账号成长，包括：

- 宗门修行
- 境界提升
- 功法解锁
- 传承道痕整备
- 法器图鉴与祭炼解锁
- 宗门建设
- NPC 关系
- 道统成长
- 图鉴收集

### 2.2 局内：单次历练

局内流程承载肉鸽构筑与战斗体验，包括：

- 定根脚
- 受信物（选择启程线与启程信物）
- 境域与节点探索
- 战斗
- 随机事件
- 功法获得
- 法器获取与祭炼
- 奇遇
- Boss 挑战

每一次历练都可能成功飞升、中途陨落，或带回部分资源。

## 3. 世界观框架

### 3.1 世界结构

| 区域 | 内容 |
| --- | --- |
| 人界 | 各大仙门、王朝、秘境、妖兽山脉 |
| 魔界 | 魔宗、深渊裂隙、血海、邪神 |
| 灵界 | 飞升后开放，包含法则战斗与大能遗迹 |

### 3.2 核心阵营

| 阵营 | 特点 |
| --- | --- |
| 正道 | 稳定成长、防御、剑阵、灵气循环 |
| 魔道 | 献祭、吸血、风险收益、爆发 |
| 妖道 | 变身、持续成长、兽魂、狂暴 |
| 器道 | 法器联动、傀儡、阵法、自动连锁 |

## 4. 玩家成长系统

### 4.1 境界系统

境界是长期目标核心。境界设计不应只是增加攻击或生命，而应解锁新机制、新系统和新 Build。

| 境界 | 核心作用 |
| --- | --- |
| 炼气 | 基础卡组开启 |
| 筑基 | 开启第二法器槽 |
| 金丹 | 开启道纹系统 |
| 元婴 | 开启分身机制 |
| 化神 | 开启法则卡牌 |
| 炼虚 | 开启跨界历练 |
| 合体 | 开启双流派 |
| 大乘 | 开启天劫玩法 |
| 飞升 | 开启灵界 |

境界机制示例：

- 金丹：飞剑数量 +1，可同时维持两个灵根状态。
- 元婴：死亡后元婴短暂继续战斗。
- 化神：可使用法则卡。

### 4.2 灵根系统

灵根不是职业，而是属性倾向。

| 灵根 | 特点 |
| --- | --- |
| 火 | 燃烧、持续伤害 |
| 冰 | 控制、冻结 |
| 雷 | 爆发、连锁 |
| 木 | 回复、成长 |
| 土 | 护盾、防御 |

后期可出现稀有成长路线：

- 血灵根
- 剑灵根
- 天雷灵根
- 九幽灵根

### 4.3 道统系统

道统是真正的职业方向。

| 道统 | 特点 | Build 方向 |
| --- | --- | --- |
| 剑修 | 高频攻击、飞剑连击、剑阵 | 无限飞剑、暴击剑修、剑气扩散 |
| 法修 | 法术爆发、元素联动、大范围伤害 | 天雷流、烈焰流、冰封流 |
| 体修 | 反击、生存、近战爆发 | 吸血流、反伤流、狂暴流 |
| 魂修 | 控制、召唤、献祭 | 尸傀流、亡魂流、心魔流 |
| 器修 | 法器组合、自动连锁、阵法 | 炮台流、连锁法器流、阵法流 |

## 5. 战斗系统

### 5.1 战斗形式

推荐采用牌库驱动的半实时斗法。

玩家通过消耗持续增长的灵气打牌、触发少量主动法器、释放神通来影响战局；飞剑、敌人、功法和多数法器持续自动演算。目标是在保留牌库、抽牌、手牌、弃牌等卡牌构筑感的基础上，提高战斗表现力，让玩家感受到修士斗法。

### 5.2 战斗资源

| 资源 | 定位 | 用途 |
| --- | --- | --- |
| 灵气 Energy | 基础出牌资源 | 打出普通卡牌与基础术法 |
| 神识 Mind | 高级技能资源 | 操控法器、启动阵法、控制分身 |
| 剑意 Sword Intent | 剑修专属资源 | 强化飞剑、触发剑阵 |

## 6. 卡牌系统

### 6.1 卡牌分类

| 类型 | 定位 | 示例 |
| --- | --- | --- |
| 功法牌 | 永久被动，改变规则，构筑核心 | 万剑归宗、九霄神雷诀 |
| 术法牌 | 主动技能 | 火球术、冰封术、天雷引 |
| 法器牌 | 调用法器 | 镇妖塔、吞天葫、昊天镜 |
| 剑诀牌 | 飞剑专属 | 御剑术、剑气纵横、万剑齐发 |
| 禁术牌 | 高风险高收益 | 血祭、燃魂、天魔解体 |

## 7. 法器系统

完整版本中，局内器物统一收口为 `法器`。

旧文档中的：

- 法宝
- 遗物
- 道器

在完整玩法中都视作法器体系的不同来源或不同品质，不再做三套并列前台系统。

法器的职责是：

- 启动一条构筑
- 放大已有循环
- 提供爆发窗口
- 提供防御或资源转化
- 修改局内规则

| 法器类型 | 玩法职责 | 示例 |
| --- | --- | --- |
| 启动型法器 | 帮助前期立势 | 剑骨、护心古玉 |
| 引擎型法器 | 让循环稳定运转 | 雷心、昊天镜 |
| 爆发型法器 | 提供关键清场或斩杀窗口 | 翻天印、万剑剑匣 |
| 防御型法器 | 补齐生存结构 | 护心镜、镇妖塔 |
| 资源型法器 | 提供灵气、抽牌、经济转化 | 紫金葫芦、聚灵符 |
| 规则型法器 | 改写底层玩法 | 残破古镜、因果玉简 |

世界观中仍允许把高阶、显眼、主动型法器称为“法宝”，但在系统层和 UI 层统一归类为法器。

## 8. 肉鸽构筑系统

核心原则：玩家每一局获得不同功法、不同法器，并形成不同流派。

### 8.1 奇遇系统

| 奇遇类型 | 奖励或风险 |
| --- | --- |
| 洞府 | 获得功法 |
| 上古遗迹 | 获得法器 |
| 心魔幻境 | 高风险高收益 |
| 神秘商人 | 购买稀有物品 |
| 渡劫台 | 挑战强化 |

### 8.2 开局与启程系统

完整版本不再直接让玩家点击“选择道途”，而是通过以下结构建立这一世的开局气质：

1. 首页整备传承道痕
2. 定根脚
3. 受信物（选择启程线与启程信物）
4. 进入首境与节点地图

其中：

- `根脚` 决定玩家是谁。
- `启程线` 决定玩家为何出山，并绑定一个启程信物。
- `启程信物` 决定本局第一推力，但不单独作为一套前台系统。
- `首境` 决定第一层的地图外壳和奖励口味。
- `功法与法器` 决定后续如何定道。

### 8.3 卡牌进化

同一张卡可以升级并形成阶段成长：

- 火球术 -> 爆炎术 -> 九天炎爆
- 御剑术 -> 万剑诀 -> 剑河降世

## 9. 局内流程

### 9.1 标准一局流程

1. 宗门准备：整备传承道痕，决定局外轻偏置。
2. 定根脚：确定此身来处。
3. 受信物：根据根脚选择一条启程线与启程信物，再进入首境。
4. 历练地图：在境域中推进节点，获得卡牌、功法、法器与资源。
5. 阶段 Boss：例如妖王、魔尊、天劫。
6. 回宗结算：获得修为、材料与解锁内容。

## 12. 商业化建议

推荐方向：

- 外观型：飞剑皮肤、法器特效、宗门外观、战斗特效。
- Build 扩展型：新角色、新道统、新法器包。

不建议强数值付费、SSR 抽卡碾压或纯战力体系，否则会破坏肉鸽构筑乐趣。

## 13. 项目核心卖点

一句话定位：

> 一款以修仙世界为背景的 Roguelike 构筑 RPG。

核心体验：

> 玩家不是抽 SSR，而是这一世修成了什么道。

玩家爽点：

- 飞剑满屏
- 无限连锁
- 法器组合
- 功法联动
- 极限 Build
- 渡劫飞升
- 逆天改命

## 14. 后续建议优先级

| 阶段 | 优先内容 |
| --- | --- |
| 第一阶段 | 战斗原型、卡牌系统、法器系统、功法联动 |
| 第二阶段 | 肉鸽地图、奇遇系统、Boss 机制 |
| 第三阶段 | 宗门成长、NPC 关系、DLC 扩展 |

## 15. 核心原则

整个项目必须始终围绕构筑感，而不是数值碾压、单纯挂机或自动战力。

玩家每一局都应该：

- 有新套路
- 有新成长
- 有新组合

最终形成：

> 修仙版 Slay the Spire + RPG 成长 + Build 构筑。
