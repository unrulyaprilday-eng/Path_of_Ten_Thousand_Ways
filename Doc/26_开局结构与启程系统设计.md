# 开局结构与启程系统设计

> 本文档定义完整版本的开局结构、命名体系、叙事入口和数值边界。它负责回答“玩家这一世从哪里来、为何出山、带着什么上路、先去何处修道”四个问题，并与 `03_核心玩法系统设计.md`、`15_地图与节点体系.md`、`17_掉落体系.md`、`19_Meta成长体系.md` 联动。

## 1. 设计目标

开局结构要同时完成四件事：

1. 让玩家觉得自己在开始“一世修行”，而不是点击一串系统菜单。
2. 在不堆叠过多选择步骤的前提下，为本局建立明确方向。
3. 让世界观、路线选择、首层地图和奖励偏向天然关联。
4. 为后续节点地图、流派成型和局外成长提供稳定接口。

核心原则：

- 开局先给身份，再给故事，再给路。
- 不再把“道途选择”作为纯抽象系统页直接端给玩家。
- 起手页的每个选项都必须同时承担叙事和玩法职责。
- 任何局外继承都只能提供轻偏置，不能替代单局构筑。

## 2. 命名体系

为避免旧术语混乱，完整版本统一使用以下命名：

| 层级 | 名称 | 用途 | 频率 |
| --- | --- | --- | --- |
| 局外整备 | 传承道痕 | 上一世或宗门留下的一缕道痕，提供轻量起手偏置 | 低频 |
| 开局身份 | 根脚 | 玩家此身的出身、来处和社会位置 | 每局 1 次 |
| 开局叙事选择 | 启程线 | 一条完整的出山理由，包含来历、携行之物和起势偏向 | 每局 1 次 |
| 开局携带物 | 携行之物 | 启程线中附带的起手物件，决定本局起势方向 | 每局 1 次 |
| 开局场景选择 | 首境候选 | 玩家在启程后选择的第一段修道路向与场景壳子 | 每局 1 次 |
| 地图外壳 | 境域 | 一类场景与节点模板，例如地窟、驿路、妖塔外层 | 多次 |
| 首张地图 | 首境 | 玩家确认后进入的第一个境域 | 每局 1 次 |
| 局内器物系统 | 法器 | 节点过程中获得的统一器物系统，整合旧“遗物 / 道器 / 非核心法宝”概念 | 多次 |

补充说明：

- `法宝` 在世界观中仍可作为高阶法器的称呼存在，但前台系统统一显示为 `法器`。
- `遗物` 不再作为前台主系统名词使用，只保留在历史文档或旧草案描述中。
- `携行之物` 不单独做成一套系统名；它作为启程线的一部分存在，避免再多一层抽象命名。

## 3. 完整开局流程

完整版本的开局流程如下：

```text
首页整备传承道痕
↓
定根脚
↓
启程（先定携行之物）
↓
首境（再定先去哪里）
↓
第一层路口
↓
节点历练
↓
功法 / 卡牌 / 法器逐步成型
↓
道途显化
↓
Boss 检验
↓
结算并带回局外资源
```

其中：

- `定根脚` 回答“你是谁”。
- `启程` 回答“你为何出山、带了什么”。
- `首境` 回答“你先去哪里、第一段历练是什么气口”。
- `节点历练` 回答“你如何把这一世修成某条道”。

## 4. 传承道痕

### 4.1 定位

传承道痕是局外整备项，不是局内完整装备。

它的职责是：

- 提供轻量候选偏置。
- 提供少量信息优势。
- 提供一类低频便利。
- 承担“上一世痕迹仍在”的长期沉浸感。

它不能：

- 直接给完整流派引擎。
- 直接替代功法或法器。
- 直接锁定本局最终道途。

### 4.2 强度边界

传承道痕的单项价值建议控制在以下范围：

| 类型 | 强度上限 |
| --- | --- |
| 候选类 | 多 1 个候选或 1 次重掷 |
| 权重类 | 单一标签 +8% 至 +12% |
| 路线类 | 单一节点或单一境域 +8% |
| 资源类 | 初始灵石 +10 至 +20 |
| 情报类 | 额外预览 1 个候选或 1 个节点 |

### 4.3 设计底线

- 每次只装备 1 枚传承道痕。
- 传承道痕优先影响“起手选择空间”，而不是“最终战斗上限”。
- 同一枚道痕不应使某条启程线成为必选答案。

## 5. 根脚系统

### 5.1 定位

根脚是此身的来处。

它不等于职业，不等于道途，也不直接规定最终 Build。
根脚只负责三件事：

- 提供身份代入。
- 决定启程线池的底色。
- 给首局环境和奖励倾向一个轻微偏置。

### 5.2 根脚规则

- 每局只拥有 1 个根脚。
- 前期默认随机根脚。
- 玩家可消耗 `改命签` 重掷 1 次。
- 中后期可解锁手选根脚。
- 稀有根脚通过宗门建设、成就或特殊局外资源解锁。

### 5.3 基础根脚池

完整版本基础根脚建议至少包含 6 个：

1. 山门杂役
2. 铁坊子
3. 行脚商裔
4. 世家旁支
5. 罪臣遗孤
6. 剑冢弃儿

### 5.4 根脚设计规则

根脚效果必须满足：

- 可感知，但不压过启程线。
- 提供路数，不直接给答案。
- 更偏向资源、路线与候选，而不是纯战斗白送数值。

### 5.5 根脚强度建议

| 维度 | 建议值 |
| --- | --- |
| 首层节点权重修正 | +4% 至 +8% |
| 奖励标签修正 | +6% 至 +10% |
| 初始资源修正 | +10 灵石至 +20 灵石 |
| 候选数量修正 | 首次额外 +1 候选 |

## 6. 启程系统

### 6.1 页面职责

`启程` 是完整开局结构的核心页面，副题固定为：

> 携一物上路

当前 DEMO 版本里，`启程` 已正式拆成 `携行之物` 与 `首境` 两个连续页面。

- `携行之物` 页只回答：你为何出山、你带了什么上路
- `首境` 页只回答：你先去哪里、前两层更偏向哪些节点

拆分原则是：

- 一个页面只做一件事
- 不把“带什么”和“先去哪”硬塞在同一张卡里
- 让玩家先定缘由与携行之物，再定第一段地图节奏

### 6.2 启程线结构

每条启程线包含以下字段：

| 字段 | 说明 |
| --- | --- |
| `line_id` | 启程线唯一编号 |
| `root_id` | 所属根脚 |
| `title` | 启程线标题 |
| `origin_text` | 来历叙事文案 |
| `carry_item_name` | 携行之物名称 |
| `carry_item_effect` | 起手物件效果 |
| `first_region_id` | 默认推荐的首境模板，供后续首境页展开 |
| `node_bias` | 节点权重修正，主要在首境页展示 |
| `reward_bias` | 奖励标签修正，主要在首境页和后续掉落里生效 |
| `risk_level` | 稳定 / 中庸 / 冒险 / 极险 |

### 6.3 候选生成规则

每局启程时显示 3 条启程线，生成顺序如下：

1. 从当前根脚池中抽取 2 条常规启程线。
2. 根据传承道痕补入 1 条偏向启程线。
3. 如果玩家已解锁稀有线，则 15% 概率将其中 1 条替换为稀有启程线。
4. 玩家选定携行之物后，再进入首境候选页，从 2-4 个场景候选中确认先去哪里。

### 6.4 启程线强度边界

启程线是本局最强的起手偏向来源，但仍不应完全锁死道途。

建议数值：

| 类型 | 数值建议 |
| --- | --- |
| 首境节点修正 | 单类节点 +10% 至 +18% |
| 奖励标签修正 | 主标签 +20% 至 +30%，副标签 +8% 至 +15% |
| 携行之物起手效果 | 等价于 0.5 件普通法器或 1 张低费核心牌 |

### 6.5 设计底线

- 启程线要讲故事，不能只写系统词。
- 同一根脚下的启程线必须明显区分“为什么出山”和“带什么上路”。
- 携行之物决定起势，不直接承担终局上限。

## 7. 境域与首境

### 7.1 境域定位

境域是节点地图的叙事外壳和数值模板。

它负责决定：

- 背景与氛围
- 首层敌群
- 首层节点权重
- 奖励口味
- 奇遇文案池

### 7.2 首境规则

- 每条启程线提供 1 个强推荐首境，并可展开 1-3 个同气质替代候选。
- 首境只决定第一层或前两层的主要氛围。
- 后续可转入新的境域分支，但仍保留首境留下的构筑底色。

### 7.3 基础境域模板

完整版本首批建议至少制作 6 个基础境域模板：

1. 山道驿路
2. 旧矿地窟
3. 妖塔外层
4. 迷林药谷
5. 雷泽险地
6. 祖地旧库

### 7.4 境域模板职责

| 境域 | 主要体验 |
| --- | --- |
| 山道驿路 | 稳定推进、商路事件、轻补给 |
| 旧矿地窟 | 战斗与搜寻并重，法器与飞剑偏向 |
| 妖塔外层 | 精英压力高，成长快，试炼感强 |
| 迷林药谷 | 事件、恢复、岔路与奇遇更多 |
| 雷泽险地 | 高风险高收益，爆发向奖励更多 |
| 祖地旧库 | 功法、秘藏、器物流派推进明显 |

## 8. 道途显化机制

### 8.1 设计目的

完整版本不再让玩家直接点击“选择剑道 / 雷道 / 血道”。

取而代之的是：

- 根脚给出底色。
- 启程线给出起势。
- 首层奖励和功法选择让道途逐渐显化。

### 8.2 道途显化值

系统为每条候选道途维护一个 `显化值`。

建议起手来源如下：

| 来源 | 主标签贡献 | 副标签贡献 |
| --- | ---: | ---: |
| 根脚 | 8 | 4 |
| 传承道痕 | 12 | 6 |
| 启程线 | 18 | 8 |
| 携行之物 | 28 | 12 |
| 首境模板 | 10 | 5 |
| 核心功法 | 35 | 15 |
| 核心法器 | 22 | 10 |
| 同标签卡牌 ≥ 3 | 15 | 0 |

### 8.3 显化阶段

| 显化值 | 阶段 | 含义 |
| --- | --- | --- |
| 0-39 | 未显化 | 尚未形成明确道途 |
| 40-69 | 起势 | 玩家能感到偏向，但仍可转向 |
| 70-99 | 成形 | 奖励池开始明显倾斜 |
| 100+ | 定道 | 本局主轴基本明确 |

### 8.4 设计底线

- 根脚和首境只能帮助起势，不能单独让道途定道。
- 核心功法和关键法器应成为定道主因。
- 玩家必须还能在第 1 层末到第 2 层初做一次真正的构筑判断。

## 9. 法器在开局结构中的位置

### 9.1 统一定义

法器是局内统一器物系统，前台不再区分旧“遗物 / 道器 / 普通法宝”。

法器负责：

- 启动
- 引擎
- 爆发
- 防御
- 资源
- 风险
- 规则改写

### 9.2 与功法的分工

| 系统 | 负责什么 |
| --- | --- |
| 卡牌 | 这一回合怎么出手 |
| 功法 | 这一局怎么修、怎么循环 |
| 法器 | 这一局靠什么器把规则推强或推歪 |

### 9.3 与携行之物的关系

携行之物不是正式法器槽位内的完整装备。

它更像：

- 一件未成器的引子
- 一件弱化版起手法器
- 一段会把本局推向某个方向的“线索”

后续节点中玩家拿到的法器，才是完整构筑件。

## 10. UI 结构建议

### 10.1 首页

首页常驻展示：

- 当前装备的传承道痕
- 已解锁根脚数
- 已解锁启程线变体数

### 10.2 定根脚页

定根脚页信息密度应较低，只承担身份揭示：

- 根脚名
- 一句身份文案
- 一条轻效果说明
- 改命签按钮

### 10.3 启程页

启程页标题固定为：

**启程**

副题固定为：

**携一物上路**

每张候选卡只保留：

- 启程线标题
- 来历句
- 携行之物名
- 携行之物效果
- 2-3 条辅助标签

### 10.4 首境页

选择携行之物后，单独进入 `首境` 页。

这一页只展示：

- 首境名
- 风险等级
- 前两层节点倾向
- 奖励口味或历练气质

不再重复展示完整启程叙事，也不再把“为何出山”和“先去哪里”揉成同一张卡。
这一页默认图多字少，场景图应先于说明文字成立。

### 10.5 第一层路口

进入地图后的第一层路口应被表达为“接下来走哪段历练”，而不是再次让玩家感觉自己在重选一次 `万剑 / 雷 / 血` 主路线。

可保留风格倾向作为次级信息，但页面主文案必须优先说明：

- 这条路先经历什么节点
- 节奏更稳还是更险
- 它会更早补哪类组件

## 11. 文案规范

### 11.1 根脚文案

根脚文案强调身份和来处，不直接讲玩法。

示例：

- 山门杂役：你在山门最不起眼的地方长大，记住的是规矩、差事和别人不愿做的活。
- 铁坊子：你闻着炉火和铁腥长大，知道许多兵刃的名字，也知道它们为何会断。

### 11.2 启程线文案

启程线文案采用“人物关系 + 情境 + 交付之物”结构。

标准句式：

- 你的[人物关系]在[情境]时，把[携行之物]交到了你手里。
- 临行前，[人物关系]将[携行之物]塞进了你袖中。
- [情境]之后，你只带走了[携行之物]。

### 11.3 境域文案

境域文案强调“为何来到这里”，而不是只写地形名词。

例如：

- 山道驿路：你第一次真正离开山门，看见的不是仙山，而是吃人的风雨和破败驿站。
- 旧矿地窟：铁屑、尘灰和失踪传闻一起埋在地底，谁都说下面没什么好东西，除了死人。

## 12. 与其他系统的接口

### 12.1 与节点地图

节点地图读取：

- 根脚标签
- 传承道痕标签
- 启程线标签
- 首境模板
- 当前显化值

输出：

- 第一层节点权重
- 第一层敌群池
- 第一层事件池

### 12.2 与掉落体系

掉落体系读取：

- 携行之物标签
- 首境奖励偏向
- 当前功法 / 法器 / 卡牌标签

输出：

- 卡牌候选
- 功法候选
- 法器候选

### 12.3 与 Meta 成长

Meta 成长负责逐步开放：

- 传承道痕槽位
- 根脚手选
- 稀有根脚
- 稀有启程线
- 启程线预览与图鉴

## 13. 设计底线

- 开局流程总步数不能继续膨胀；DEMO 当前固定为“启动页、定根脚、携行之物、首境、第一层路口”五步。
- `携行之物` 与 `首境` 的拆分在当前 DEMO 中属于允许且推荐的前台演出，不视为无意义膨胀。
- 根脚负责身份，启程负责故事和起势，地图负责养成，不要互相抢职责。
- 传承道痕永远不能强到压过单局选择。
- 启程线必须让玩家在视觉、文案和玩法上同时感觉“这是一条不一样的出山路”。
