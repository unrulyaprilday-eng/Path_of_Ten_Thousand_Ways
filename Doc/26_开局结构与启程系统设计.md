# 开局结构与启程系统设计

> 本文档定义完整版本的开局结构、命名体系、叙事入口和数值边界。它负责回答“玩家这一世从哪里来、为何出山、带着什么上路、先去何处修道”四个问题，并与 `03_核心玩法系统设计.md`、`15_地图与节点体系.md`、`17_掉落体系.md`、`19_Meta成长体系.md` 联动。

## 1. 设计目标

开局结构要同时完成四件事：

1. 让玩家觉得自己在开始“一世修行”，而不是点击一串系统菜单。
2. 在不堆叠过多选择步骤的前提下，为本局建立明确方向。
3. 让世界观、路线选择、首层地图和奖励偏向天然关联。
4. 为后续节点地图、流派成型和局外成长提供稳定接口。

核心原则：

- 开局先给身份，再给故事，再给路。
- 不再把“道途选择”作为纯抽象系统页直接端给玩家。
- 起手页的每个选项都必须同时承担叙事和玩法职责。
- 根脚决定候选池，不直接锁死唯一启程信物。
- 启程线先决定启动故事线、地图路线库与早期成长路径，不直接等同于 Build 按钮。
- 启程信物承接故事线带出的启动信物库，具体信物才负责本局 Build 起手倾向。
- 任何局外继承都只能提供轻偏置，不能替代单局构筑。

## 2. 命名体系

完整版本统一使用以下命名：

| 层级 | 名称 | 用途 | 频率 |
| --- | --- | --- | --- |
| 局外整备 | 传承道痕 | 上一世或宗门留下的一缕道痕，提供轻量起手偏置 | 低频 |
| 开局身份 | 根脚 | 玩家此身的出身、来处和社会位置 | 每局 1 次 |
| 开局叙事选择 | 启程线 | 一条完整的出山理由，决定地图路线库与早期成长路径，并带出启动信物库 | 每局 1 次 |
| 开局信物 | 启程信物 | 从启程线带出的启动信物库中承下的临行物件，决定本局 Build 起手倾向 | 每局 1 次 |
| 开局场景选择 | 首境候选 | 玩家在启程后选择的第一段修道路向与场景壳子 | 每局 1 次 |
| 地图外壳 | 境域 | 一类场景与节点模板，例如地窟、驿路、妖塔外层 | 多次 |
| 首张地图 | 首境 | 玩家确认后进入的第一个境域 | 每局 1 次 |
| 局内器物系统 | 法器 | 节点过程中获得的统一器物系统，整合旧“遗物 / 道器 / 非核心法宝”概念 | 多次 |

补充说明：

- `法宝` 在世界观中仍可作为高阶法器称呼存在，但前台系统统一显示为 `法器`。
- `遗物` 不再作为前台主系统名词使用，只保留在历史文档或旧草案描述中。
- `携行之物` 不再作为前台页面名。旧文档和程序字段里的 `carry_item_*` 可继续作为内部兼容字段，前台文案统一显示为 `启程信物`。

## 3. 完整开局流程

```text
开卷：首页整备传承道痕
↓
定根脚
↓
受信物：先定启程故事线，再承启程信物
↓
入首境：选择第一段修道路向
↓
择前路
↓
节点历练
↓
功法 / 卡牌 / 法器逐步成型
↓
道途显化
↓
Boss 检验
↓
结算并带回局外资源
```

其中：

- `定根脚` 回答“你是谁”。
- `受信物` 回答“你为何出山、会被哪类路线库牵引、临行承了什么”。
- `入首境` 回答“这件事把你引向哪里”。
- `节点历练` 回答“你如何把这一世修成某条道”。

### 3.1 前台命名建议

推荐前台主链路：

```text
开卷 -> 定根脚 -> 受信物 -> 入首境 -> 择前路 -> 斗法
```

命名取舍：

- `开卷`：比“启动页”更像打开一世修行的卷轴，适合首页门面。
- `定根脚`：保留修仙语感，回答此身来处。
- `受信物`：比“选信物”更有承命、受托、临行接物的仪式感。
- `入首境`：比“选择场景”更像踏入第一段修道路向。
- `择前路`：比“择去路”更主动，适合表达肉鸽路线选择。

`启程线` 仍作为系统层和配置层术语使用；前台页面标题优先用 `受信物`。

## 4. DEMO 纵切口径

当前 DEMO 首版先做：

```text
世家旁支
↓
3 条启程线
↓
3 个启程信物
↓
旧矿地窟
↓
3 层节点地图
↓
天劫化身
```

根脚入口仍要做出来，但首版只开放 `世家旁支`。其他根脚可显示为：

- `命数未显`
- `待解锁`
- `此世未至`

这样玩家能理解系统入口存在，但开发不会被多个根脚的内容量拖散。

## 5. 传承道痕

### 5.1 定位

传承道痕是局外整备项，不是局内完整装备。

它的职责是：

- 提供轻量候选偏置。
- 提供少量信息优势。
- 提供一类低频便利。
- 承担“上一世痕迹仍在”的长期沉浸感。

它不能：

- 直接给完整流派引擎。
- 直接替代功法或法器。
- 直接锁定本局最终道途。

### 5.2 强度边界

| 类型 | 强度上限 |
| --- | --- |
| 候选类 | 多 1 个候选或 1 次重掷 |
| 权重类 | 单一标签 +8% 至 +12% |
| 路线类 | 单一节点或单一境域 +8% |
| 资源类 | 初始资源 +10 至 +20 |
| 情报类 | 额外预览 1 个候选或 1 个节点 |

设计底线：

- 每次只装备 1 枚传承道痕。
- 传承道痕优先影响“起手选择空间”，不是“最终战斗上限”。
- 同一枚道痕不应使某条启程线成为必选答案。

## 6. 根脚系统

### 6.1 定位

根脚是此身的来处。

它不等于职业，不等于道途，也不直接规定最终 Build。

根脚只负责三件事：

- 提供身份代入。
- 决定启程线候选池。
- 给首局环境和奖励倾向一个轻微偏置。

### 6.2 根脚规则

- 每局只拥有 1 个根脚。
- 前期默认随机根脚或只开放少量根脚。
- 玩家可消耗 `改命签` 重掷 1 次。
- 中后期可解锁手选根脚。
- 稀有根脚通过宗门建设、成就或特殊局外资源解锁。

完整版本基础根脚建议至少包含：

1. 山门杂役
2. 铁坊子
3. 行脚商裔
4. 世家旁支
5. 罪臣遗孤
6. 剑冢弃儿

### 6.3 根脚设计规则

根脚效果必须满足：

- 可感知，但不压过启程线。
- 提供路数，不直接给答案。
- 更偏向资源、路线与候选，而不是纯战斗白送数值。
- 至少能派生 2-3 条气质不同的启程线。

强度建议：

| 维度 | 建议值 |
| --- | --- |
| 首层节点权重修正 | +4% 至 +8% |
| 奖励标签修正 | +6% 至 +10% |
| 初始资源修正 | +10 至 +20 |
| 候选数量修正 | 首次额外 +1 候选 |

## 7. 启程系统

### 7.1 页面职责

`受信物` 是完整开局结构的核心页面。系统层仍称为 `启程线`，前台页面名使用 `受信物`。

推荐副题：

> 携一物上路

前台解释：

- 玩家不是从全游戏物品池里挑信物。
- 玩家先在当前根脚下选择一条启程故事线。
- 故事线决定地图路线库与早期成长路径倾向；具体走哪段路、拿哪些节点，仍由后续节点选择决定。
- 故事线带出一个启动信物库；DEMO 首版可以简化为一条故事线固定一个启程信物。
- 启程信物才负责本局 Build 起手倾向，不能把故事线本身做成职业按钮。

例如：

```text
世家旁支
↓
祠堂夜雨 / 护身旧玉
灰烬符匣 / 余烬符匣
祖龛残匣 / 祖龛残匣
```

### 7.2 启程线结构

每条启程线包含以下字段：

| 字段 | 说明 |
| --- | --- |
| `line_id` | 启程线唯一编号 |
| `root_id` | 所属根脚 |
| `title` | 启程线标题 |
| `origin_text` | 来历叙事文案 |
| `route_pool_id` | 地图路线库编号，决定后续择前路与节点路线候选池 |
| `growth_path_hint` | 早期成长路径提示，不等于最终 Build |
| `carry_item_pool_id` | 启动信物库编号；DEMO 可退化为单信物 |
| `carry_item_name` | 内部字段：启程信物名称 |
| `carry_item_effect` | 内部字段：启程信物起手效果 |
| `first_region_id` | 默认推荐首境模板 |
| `node_bias` | 节点权重修正，主要在首境页展示 |
| `reward_bias` | 奖励标签修正，后续掉落生效 |
| `risk_level` | 稳定 / 中庸 / 冒险 / 极险 |

字段兼容说明：

- `route_pool_id`、`growth_path_hint`、`carry_item_pool_id` 是完整版本建议字段；当前 DEMO 也可先通过现有 `first_region_id`、`node_bias`、`reward_bias` 与 `carry_item_*` 表达同一层级。
- `carry_item_*` 是程序字段名，不要求前台照字显示。
- UI 文案优先使用 `启程信物`、`临行一物`、`信物效果`。

### 7.3 候选生成规则

每局启程时默认显示 3 条启程线：

1. 从当前根脚候选池中抽取 2 条常规启程线。
2. 根据传承道痕补入 1 条偏向启程线。
3. 如果玩家已解锁稀有线，则可用低概率替换其中 1 条。
4. 玩家选定启程线后，再进入首境候选页。

DEMO 首版可简化为：

- 只开放 `世家旁支`。
- 固定展示 3 条世家旁支启程线。
- 选定后进入 `旧矿地窟` 的入首境页。

### 7.4 启程线与信物强度边界

启程线是本局最强的路线与成长路径偏置来源，但仍不应完全锁死道途。Build 起手倾向主要由启程信物承担。

| 类型 | 数值建议 |
| --- | --- |
| 首境节点修正 | 单类节点 +10% 至 +18% |
| 奖励标签修正 | 主标签 +20% 至 +30%，副标签 +8% 至 +15% |
| 启程信物起手效果 | 等价于 0.5 件普通法器或 1 张低费核心牌 |

设计底线：

- 启程线要讲故事，不能只写系统词。
- 同一根脚下的启程线必须明显区分“为什么出山”“会进入哪类路线库”和“带什么上路”。
- 启程信物决定起势，不直接承担终局上限。

## 8. 世家旁支启程样例

| 启程线 | 地图路线库 / 成长路径 | 启程信物 | 信物 Build 倾向 | 标准文案 |
| --- | --- | --- | --- | --- |
| 祠堂夜雨 | 避祸旧路：稳进、修炼、护身事件 | 护身旧玉 | 护体、稳进、剑意 | 族中大乱后，叔父把一枚护身旧玉塞进你袖中。 |
| 灰烬符匣 | 焚宅余脉：风险事件、符灰线索、爆发补强 | 余烬符匣 | 爆发、符灰、风险 | 旧宅焚毁后，你从灰里捡出一只仍有余温的符匣。 |
| 祖龛残匣 | 祖物追索：秘藏、洞府、法器线索 | 祖龛残匣 | 秘藏、法器、飞剑组件 | 祖龛塌落时，只有这只封死的小匣没有碎。 |

同一根脚下的三条线应像三种不同命运：

- 去避祸。
- 去追索。
- 去取回。

它们不必定死同一个首境。更推荐的商业化结构是：同一信物把玩家的首境候选收窄到 2-3 个有因果关系的大地图，玩家再在 `入首境` 页决定第一脚踏进哪里。

## 9. 境域与首境

### 9.1 境域定位

境域是节点地图的叙事外壳和数值模板。

它负责决定：

- 背景与氛围。
- 首层敌群。
- 首层节点权重。
- 奖励口味。
- 奇遇文案池。

### 9.2 入首境规则

选定启程线后，玩家进入 `入首境` 页。

这一页只回答：

- 你先去哪里。
- 为什么这条启程线会把你带到这里。
- 前两层更偏向哪些节点。

完整版本中，每条启程线可提供：

- 1 个强推荐首境。
- 1-2 个同气质替代候选。

当前首境规则：

- `受信物` 负责确定为何出山、承了什么信物。
- `入首境` 负责展示该信物合理指向的 2-3 个首境候选。
- 玩家在这一页选大地图，但不是从全地图副本菜单里自由挑；候选必须和信物、根脚、启程线有因果关系。
- 这页信息密度必须低，只保留首境名、风险词、一句极短气质文案和确认点击区。
- 信物效果、构筑标签、节点权重和掉落概率不放在首境卡上。

世家旁支当前候选池建议：

| 启程信物 | 首境候选 |
| --- | --- |
| 护身旧玉 | 旧矿地窟、迷林药谷、商路荒谷 |
| 余烬符匣 | 雷泽险地、旧矿地窟、妖塔外层 |
| 祖龛残匣 | 祖地旧库、旧矿地窟、迷林药谷 |

旧矿地窟仍是 P0 优先打磨的完整大地图；其他首境可以先以低信息密度场景卡进入版本，后续逐步补深节点内容。

### 9.3 基础境域模板

完整版本首批建议至少制作：

| 境域 | 主要体验 |
| --- | --- |
| 山道驿路 | 稳定推进、商路事件、轻补给 |
| 旧矿地窟 | 战斗与搜寻并重，法器与飞剑偏向 |
| 妖塔外层 | 精英压力高，成长快，试炼感强 |
| 迷林药谷 | 事件、恢复、岔路与奇遇更多 |
| 雷泽险地 | 高风险高收益，爆发向奖励更多 |
| 祖地旧库 | 功法、秘藏、器物流派推进明显 |

## 10. 道途显化机制

完整版本不再让玩家直接点击“选择剑道 / 雷道 / 血道”。

取而代之的是：

- 根脚给出身份底色。
- 启程线给出地图路线库与早期成长路径。
- 启程信物给出 Build 起手倾向。
- 首层奖励和功法选择让道途逐渐显化。

建议起手来源：

| 来源 | 主标签贡献 | 副标签贡献 |
| --- | ---: | ---: |
| 根脚 | 8 | 4 |
| 传承道痕 | 12 | 6 |
| 启程线 | 18 | 8 |
| 启程信物 | 28 | 12 |
| 首境模板 | 10 | 5 |
| 核心功法 | 35 | 15 |
| 核心法器 | 22 | 10 |
| 同标签卡牌 >= 3 | 15 | 0 |

显化阶段：

| 显化值 | 阶段 | 含义 |
| --- | --- | --- |
| 0-39 | 未显化 | 尚未形成明确道途 |
| 40-69 | 起势 | 玩家能感到偏向，但仍可转向 |
| 70-99 | 成形 | 奖励池开始明显倾斜 |
| 100+ | 定道 | 本局主轴基本明确 |

设计底线：

- 根脚和首境只能帮助起势，不能单独让道途定道。
- 核心功法和关键法器应成为定道主因。
- 玩家必须还能在第 1 层末到第 2 层初做一次真正的构筑判断。

## 11. 法器在开局结构中的位置

启程信物不是正式法器槽位内的完整装备。

它更像：

- 一件未成器的引子。
- 一件弱化版起手法器。
- 一段会把本局推向某个方向的线索。

后续节点中玩家拿到的法器，才是完整构筑件。

| 系统 | 负责什么 |
| --- | --- |
| 卡牌 | 战斗中何时主动出手 |
| 功法 | 这一局怎么修、怎么循环 |
| 法器 | 这一局靠什么器把规则推强或推歪 |
| 启程信物 | 为什么这样起手，第一段路有什么偏向 |

## 12. UI 结构建议

### 12.1 首页

首页常驻展示：

- 当前装备的传承道痕。
- 已解锁根脚数。
- 已解锁启程线变体数。

### 12.2 定根脚页

定根脚页只承担身份揭示：

- 根脚名。
- 一句身份文案。
- 一条轻效果说明。
- 改命签按钮。
- 未开放根脚的 `命数未显` 状态。

信息密度必须低于受信物页。

产品内文案必须是世界观语气，不使用设计说明语气。避免把“根脚只定此身来处，不替你定最终道途”这类系统职责解释直接放到 UI 上。

定根脚页上屏文案建议：

- 副题：`签落案前，先认此身来处。`
- 副题备选：`一卷命书落案，此身由此开篇。`
- 世家旁支身份句：`你熟悉祠堂的规矩，也熟悉规矩背后那些不能写进族谱的旧债。`
- 轻效果标签可显示为：`此身余荫`
- 轻效果示例：`首次功法候选额外 +1 项`
- 确认按钮：`落印定身`
- 确认提示：`印成之后，自有人递来临行之物。`

### 12.3 受信物页

受信物页标题固定为：

**受信物**

副题建议：

**携一物上路**

每张候选卡只保留：

- 启程线标题。
- 一句来历。
- 地图路线库或早期成长路径提示。
- 启程信物名。
- 信物起手效果。
- 2-3 条信物 Build 倾向标签。

不依赖 Hover 才能看懂选择差异。

### 12.4 入首境页

选择启程线后，单独进入 `入首境` 页。

这一页只展示：

- 首境名。
- 风险等级。
- 前两层节点倾向。
- 奖励口味或历练气质。
- 一句“为何来到这里”的短文案。

不再重复展示完整启程叙事，也不把“为何出山”和“先去哪里”揉成同一张卡。

### 12.5 择前路

择前路表达“接下来走哪段历练”，不是重选一次 `万剑 / 雷 / 血`。

页面主信息：

- 这条路先经历什么节点。
- 节奏更稳还是更险。
- 它会更早补哪类组件。

风格倾向只能作为次级标签。

## 13. 文案规范

### 13.1 根脚文案

根脚文案强调身份和来处，不直接讲玩法。

根脚文案分两层：

- 设计说明可以解释“根脚负责身份底色、候选池和轻偏置”。
- 产品内文案只能写玩家这一世的来处、处境、旧债、人情和余荫，不直接解释系统职责。

示例：

- 山门杂役：你在山门最不起眼的地方长大，记住的是规矩、差事和别人不愿做的活。
- 铁坊子：你闻着炉火和铁腥长大，知道许多兵刃的名字，也知道它们为何会断。
- 世家旁支：你熟悉祠堂的规矩，也熟悉规矩背后那些不能写进族谱的旧债。

### 13.2 启程线文案

启程线文案采用“人物关系 + 情境 + 交付之物”结构。

标准句式：

- 你的[人物关系]在[情境]时，把[启程信物]交到了你手里。
- 临行前，[人物关系]将[启程信物]塞进了你袖中。
- [情境]之后，你只带走了[启程信物]。

### 13.3 境域文案

境域文案强调“为何来到这里”，而不是只写地形名词。

示例：

- 山道驿路：你第一次真正离开山门，看见的不是仙山，而是吃人的风雨和破败驿站。
- 旧矿地窟：铁屑、尘灰和失踪传闻一起埋在地底，谁都说下面没什么好东西，除了死人。

## 14. 与其他系统的接口

### 14.1 与节点地图

节点地图读取：

- 根脚标签。
- 传承道痕标签。
- 启程线地图路线库。
- 启程信物标签。
- 首境模板。
- 当前显化值。

输出：

- 择前路候选池。
- 第一层节点权重。
- 第一层敌群池。
- 第一层事件池。

### 14.2 与掉落体系

掉落体系读取：

- 启程信物标签。
- 首境奖励偏向。
- 当前功法 / 法器 / 卡牌标签。

输出：

- 卡牌候选。
- 功法候选。
- 法器候选。

### 14.3 与 Meta 成长

Meta 成长负责逐步开放：

- 传承道痕槽位。
- 根脚手选。
- 稀有根脚。
- 稀有启程线。
- 启程线预览与图鉴。

## 15. 设计底线

- 开局流程总步数不能继续膨胀；当前固定为“开卷、定根脚、受信物、入首境、择前路”五步。
- `启程信物` 不是单独系统页，它属于启程线。
- 根脚负责身份，启程线负责故事线、地图路线库和早期成长路径，启程信物负责 Build 起手倾向，地图节点负责具体养成选择，不要互相抢职责。
- 传承道痕永远不能强到压过单局选择。
- 启程线必须让玩家在视觉、文案和玩法上同时感觉“这是一条不一样的出山路”，而不是一个提前写死的职业答案。
