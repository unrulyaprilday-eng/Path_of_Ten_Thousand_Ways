# 修仙肉鸽卡牌RPG —— 项目总设计说明（Project Overview）

## 1. 项目定位
本项目是一款融合：修仙RPG + Roguelike节点式肉鸽 + 卡牌构筑 + 法宝飞剑战斗 + 局外宗门成长

核心体验：每一局 = 一次修仙证道过程 + 一个流派诞生故事

## 2. 核心玩法循环
局外：宗门成长（境界/功法/法宝/道统）
局内：节点式历练（构筑→战斗→Boss→回归）

## 3. 核心支柱
- 构筑优先
- 流派成型
- 爆发体验
- 修仙沉浸

## 4. 系统结构
境界 / 道统 / 功法 / 法宝 / 飞剑 / 节点地图

## 5. 战斗定位
半即时战斗 + 自动飞剑 + 卡牌策略 + 法宝联动
