## 1. 当前活动制作单

### 1.1 战斗首屏目标

- 主角为黑白主色的男性长发剑修，三分之四背视角，位于左下并朝右上方约 45 度攻击。
- 普通敌人位于右上，可在前、中、后三个纵深位置出现 1-3 个目标；不得横向排成卡牌队列。
- 普通战保持斜向稳定镜头。最终区域 Boss `玄铁镇矿剑傀` 位于画面正上方，占据上部大面积空间并形成压屏构图。
- 普通攻击和出牌不推镜；只在终极技、击杀和必要的 Boss 阶段转换时短促推镜、停顿或重构画面。
- 主角获得承载类法器时脚踩对应法器；没有承载类法器时站在旧矿断石、残梁、矿台或地面。环绕和手持法器不得强行放到脚下。
- 开局只有心法附带技能与初始剑诀两张法诀，本命法器按 CD 自动攻击。终局牌库总量为 6-9 门，但同时在手上限为 6；战斗 UI 必须覆盖 2、4、6 张同时在手和 6-9 门牌库循环信息，不把 9 门法诀同时铺开，也不再沿用“固定 3-7 张手牌”作为唯一验收口径。
- 多目标使用“自动攻击 + 点击锁定”。未锁定时自动攻击当前威胁最高目标；点击立即切换；目标死亡自动转移。锁定标记使用青绿墨圈、剑锋指向或小型印记，不增加二次确认。
- 每个敌人显示紧凑意图和倒计时；只有锁定目标展开详细说明。群攻、雷链和万剑自动扩散，不要求每张牌再次选目标。

### 1.2 色彩与材质

- 战场、角色、地图和大场景使用黑、白、冷墨灰。
- 青绿用于玩家灵力、本命法器核心、锁定与共鸣；朱砂用于伤害、危险与旧契；冷白雷光仅在雷系和高能瞬间出现。
- 米白、旧纸色只用于局部卡牌、符签、卷轴和小型信息承载，不对整屏做米黄洗色。
- 禁止现代玻璃面板、大面积黑条、紫黑厚涂、蓝衣主角、正文烘焙进图片和中文伪文字。

#### 1.3.1 集中资源冲刺与障碍清单

- 战斗布局、角色安全区、承载物锚点、灵气条、自动攻击提示和手牌区先用程序模块验证；锚点通过双分辨率截图后一次冻结完整 P0 清单。
- “尽量一次性生成”指在同一轮资源冲刺中连续完成清单，不把资源拆散到多轮临时补图；生图仍严格一次一张，完成目检并决定接受、拒收或阻塞后才开始下一张，禁止并发请求。
- 固定顺序：旧矿远景 -> 主角 -> 地面/承载物 -> 近景 -> 中景 -> 残剑自动攻击 -> 普通敌人 -> 锁定与紧凑意图 -> 两个小 Boss -> 剑傀主体/甲片/契钉/核心 -> 地图事件 -> 万剑 VFX。
- 清单状态统一为：`Planned -> Generating -> Accepted / Rejected / Blocked -> Integrated -> ScreenshotVerified`。
- 普通敌人和新增法器在稳定定义 ID 冻结后确定性命名：`char_<definition_id>_battle_001.png`、`vfx_battle_<definition_id>_<用途>_001.png`，不使用临时中文文件名，不覆盖来源或构图不同的旧版本。

### 1.6 首页与旅程入口

首页承担品牌、开始/继续一世、轻量见闻入口和设置，不做宗门大厅或营销落地页。当前流程语义统一为：

```text
Home -> OpeningStory -> RegionChoice -> JourneyMap
```

- 主视觉全屏承载品牌与旧矿远景，左侧安排开始/继续操作，右下只显示版本、最近一世与最远进度等轻信息；不使用中央大卡或多层嵌套面板。
- 首页与开局、地图、战斗共享黑白冷墨和青绿/朱砂点色；不再围绕天劫、携行三选一或首境多图卡生产新资源。
- `开始新局` 进入沉浸式根脚与所携故事；`继续悟道` 恢复最近节点间存档；无存档时明确禁用继续入口。
