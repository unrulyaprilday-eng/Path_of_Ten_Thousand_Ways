# 项目总纲与 GDD

> 本文定义项目长期不轻易改变的定位、核心体验、产品结构与阶段边界。具体单局系统见 `01_核心玩法与系统边界.md`；当前 DEMO 的旅程、地图和故事见 `02_DEMO旅程地图与叙事.md`。

## 1. 项目定位

本项目是一款融合修仙 RPG、节点式 Roguelike、法诀构筑、半实时斗法与轻量局外成长的独立游戏。

核心一句话：

> 修仙不是打怪升级，而是构筑一条属于自己的道途。

玩家经历的不是脱离世界的卡牌关卡串，而是一名修士在一世历练中获得法诀、参悟心法、炼化本命法器、突破境界、承担因果并最终验证自身道途的完整冒险。

## 2. 核心体验支柱

### 2.1 修仙沉浸

- 玩家先理解“这一世我是谁、为何出发、带着什么”，再进入构筑。
- 能力来自洞府、剑痕、残魂、秘境、师承、交易与抉择，不凭空从系统奖励页出现。
- 境界突破是旅程中的重大事件，不是脱离故事的升级弹窗。
- 选择留下具体因果，并通过人物、路线、敌人、Boss 和结局反馈。

### 2.2 构筑成道

- 开局只给足以生存和表达身份的最小能力，不预装完整卡组。
- 心法、本命法器、法诀和境界分别改变不同层面的规则。
- 中期必须形成可理解的循环，后期必须出现规则联动和爆发时刻。
- 道途由玩家经历与所得逐步显化，不在开局直接裸选职业按钮。

### 2.3 半实时斗法

- 本命法器、飞剑、敌人、状态和多数法器持续演算。
- 玩家通过小型法诀牌库低频介入，判断灵力、时机、目标和爆发窗口。
- 屏幕体验必须像修士在场景中斗法，而不是两张立绘配数值相减。
- 飞剑、法术、法器与场景反馈共同承担战斗爽点。

### 2.4 一世一途

- 每局都应有新的所得、因果、构筑与结局变化。
- 玩家能够复述“这一世在哪里悟得什么、帮助或伤害了谁、以何种方式突破”。
- 局外成长主要解锁新的起点、人物、事件和可能性，不以永久数值替代单局修行。

## 3. 产品结构

### 3.1 局内历练

一局的标准语义是：

```text
身份与故事开卷
↓
取得初始心法、本命法器与法诀
↓
选择所往境域
↓
在节点地图中战斗、探索、修炼与承担因果
↓
心法升阶、本命法器蜕变、法诀逐步成形
↓
完成一次有故事依据的境界突破
↓
挑战区域 Boss 或隐藏因果 Boss
↓
形成结局并带回解锁、见闻与道痕
```

### 3.2 局外长期成长

局外承载长期追求，但不直接赠送足以压过单局构筑的战力：

- 解锁根脚、起始故事与境域。
- 解锁新的心法、法诀、法器和事件进入候选池。
- 记录人物、Boss、法器、功法、结局与隐藏因果图鉴。
- 提供情报、重铸、预览或轻量候选偏置。
- 后续可扩展宗门、NPC 关系、道统与高难度规则。

## 4. 核心系统总览

玩家前台优先理解以下修仙语义：

| 系统 | 核心职责 | 玩家感受 |
| --- | --- | --- |
| 本命法器 | 固定周期自动行动，并在历练中炼形和改变攻击规则 | 一直陪我成长的器 |
| 心法 | 决定灵力循环、恢复方式、状态阈值和长期战斗节奏 | 我如何运转周天 |
| 法诀 | 以牌库形式承载剑诀、法术、身法、心诀与禁术 | 我在关键时刻如何落子 |
| 境界 | 提升全局能力基准，并解锁一条新的规则层 | 我的生命层次发生改变 |
| 法器 | 除本命法器外的局内器物，负责放大或改写规则 | 我用什么器把道途推强或推歪 |
| 因果 | 记录具体人物和事件选择，改变后续内容 | 世界记得我做过什么 |

系统层与 UI 层统一把旧文档中的“法宝、遗物、道器”收口为法器。世界观中可以把高阶、显眼或主动型器物称为法宝，但不再建立多套并列前台系统。

卡牌是法诀的交互载体，不是世界观中的凭空奖励。玩家看到的是一门具体剑诀、心诀、法术、身法或禁术，以及它来自何处。

## 5. 境界与完整版本成长

境界不能只增加攻击和生命。每次大境界提升至少同时承担：

- 提高灵力获取、上限或运转效率。
- 提高已学法诀的基础威力，使早期法诀不会自然淘汰。
- 开启一个新规则、系统位或战斗结构。
- 通过本局筑成的道基，让心法、法诀或本命法器发生质变。

完整版本可沿以下方向扩展，具体名称与开放顺序以后续专项设计为准：

| 境界 | 规则提升示例 |
| --- | --- |
| 炼气 | 建立基础灵力循环与法诀牌库 |
| 筑基 | 筑成道基规则，开放更深的法器或心法联动 |
| 金丹 | 开启道纹、复合灵根或本命法器核心变化 |
| 元婴 | 开启分身、替命或死亡后的特殊战斗结构 |
| 化神 | 开启法则类法诀与更高层规则 |
| 后续境界 | 逐步开放跨境域、双流派、高阶天劫与飞升内容 |

天劫属于高境界的重大挑战，不作为当前 DEMO 初入修行阶段的区域 Boss。

## 6. 世界与道统扩展

完整版本可由人界逐步扩展至魔界、灵界和更高层世界，但当前不提前铺开多世界内容。

长期道统方向包括但不限于：

| 道统 | 主要体验 |
| --- | --- |
| 剑修 | 飞剑、剑阵、剑意、蓄势斩击 |
| 法修 | 元素、法术爆发、范围与连锁 |
| 体修 | 生存、反击、近身爆发与气血转化 |
| 魂修 | 召唤、控制、献祭与残魂因果 |
| 器修 | 法器组合、傀儡、阵法与自动连锁 |

正、邪、妖、器等方向不是固定职业阵营按钮。玩家采用何种修炼方法、如何处理他者和愿意承担什么代价，才逐步形成这一世的道路。

## 7. 当前 DEMO 定位

当前 DEMO 只打透一条线：一名世家旁支男性长发剑修取得残剑胚，进入旧矿大境域，在三幕历练中从炼气走到筑基，最终挑战玄铁镇矿剑傀。

DEMO 目标不是展示最大内容量，而是证明以下体验已经成立：

1. 开局故事能自然交代身份、初始能力与所往。
2. 三幕节点历练能形成一次完整修仙冒险，而不是短流程菜单串。
3. 本命法器自动攻击与法诀低频介入能够形成清楚、华丽的半实时斗法。
4. 心法、法诀、本命法器和境界能通过故事事件逐步成长。
5. 中期能够成型，后期能够爆发，Boss 能检验这一世修成的规则。
6. 因果与隐藏内容能让同一旧矿产生可重玩的故事变化。

当前单局以 30–40 分钟作为 DEMO tuning 起点，最终时长以三幕实际节点数、战斗时长和事件阅读节奏验证，不作为不可调整的永久标准。

## 8. 阶段边界

### P0：当前纵切必须成立

- 沉浸式开局与旧矿三幕旅程。
- 手工骨架加种子变化的节点地图。
- 半实时法诀战斗、本命法器自动攻击和有限多敌人。
- 剑修主轴、心法升阶、一次筑基、本命法器炼化。
- 两个幕末小 Boss、玄铁镇矿剑傀和基础因果闭环。
- 地图、战斗、事件、突破、Boss 与结算的完整游戏化 UI。

### P1：在纵切成立后扩展

- 更丰富的法器规则、状态与隐藏事件。
- 因果导致的 Boss 阶段、隐藏路线和结局变体。
- 轻量局外道痕、图鉴和新起点解锁。
- 旧矿内更多敌人组合、精英和能力获取场景。

### P2：完整版本内容

- 更多根脚、所携与境域。
- 多道统、多大境界和多章节世界。
- 宗门、NPC 关系、长期图鉴与高难度系统。
- 经济、装备和其他非核心外围系统只在确有体验价值时扩展。

## 9. 设计红线

- 不做普通站桩卡牌对战。
- 不用大量基础牌和通用奖励页替代修仙成长。
- 不让境界退化为纯数值加成。
- 不让根脚或初始器物直接锁死终局 Build。
- 不用单一善恶值概括具体因果。
- 不以局外永久战力取代单局构筑。
- 不为增加节点而复制同质战斗、事件或三选一页面。
- 不把天劫、飞升等终局尺度内容提前消耗在当前 DEMO。
