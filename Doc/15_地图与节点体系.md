# 地图与节点体系

> 地图体系负责单局节奏、路线选择、风险收益和流派成型速度。完整版本中，地图不再是脱离身份的纯关卡菜单，而是由根脚和启程线自然带出的历练去向。

## 1. 设计目标

节点地图要让玩家在每局中持续做路线决策：

- 我为何来到这里？
- 我要稳步成长还是冒险拿核心法器？
- 我要去洞府悟法还是去秘藏赌高价值奖励？
- 我要先补生存还是继续压进攻？

## 2. 地图结构层级

完整版本建议采用三层结构：

```text
根脚
↓
启程线
↓
启程信物
↓
首境
↓
节点地图
↓
后续境域分支
↓
Boss
```

### 2.1 地图页定位

在新结构中，玩家进入的不是一个脱离叙事的“地图页”或“世界地图选择器”，而是一张已经被启程线定义过来历的 `历练路线页`。

也就是说：

- 根脚回答“你从哪里来”；
- 启程线回答“你为什么会走上这条路”；
- 启程信物回答“你临行带走了什么，这局从哪里起势”；
- 首境地图回答“你这一世第一步具体踏进了哪里”。

因此地图页的前台重点应是：

- 当前首境名与一句场景叙事；
- 2-4 条可选路线；
- 节点风险与奖励预期；
- 当前构筑在这张图上的修炼去向。

其中：

- `首境` 是第一层或前两层的主要场景外壳。
- `节点地图` 承担玩法决策。
- `后续境域` 负责把这一世的路线继续往深处推。

## 3. 节点类型

| 节点 | 功能 | 主要奖励 |
| --- | --- | --- |
| 普通战斗 | 基础构筑推进 | 卡牌、灵石、小概率法器 |
| 精英战斗 | 高风险高收益 | 法器、高品质卡牌 |
| 事件 | 代价选择和奇遇 | 功法、资源、特殊法器 |
| 商店 | 补齐构筑缺口 | 卡牌、法器、删除、刷新 |
| 修炼 | 恢复和强化 | 升级、治疗、悟道、祭炼 |
| 洞府 | 功法获取 | 主修、辅修、残篇 |
| 秘藏 | 高价值器物与地图线索 | 法器、稀有资源 |
| Boss | 阶段检验 | 高品质奖励、推进下一阶段 |

## 4. 基础节点权重

| 节点 | 基础权重 |
| --- | ---: |
| 普通战斗 | 28% |
| 精英战斗 | 12% |
| 事件 | 18% |
| 商店 | 10% |
| 修炼 | 12% |
| 洞府 | 10% |
| 秘藏 | 10% |

Boss 为阶段固定节点，不参与基础权重池。

## 5. 根脚与启程的影响

地图生成的第一优先顺序为：

1. 首境模板
2. 启程线偏向
3. 启程信物偏向
4. 根脚偏向
5. 传承道痕偏向
6. 当前生存与构筑状态

公式见 `27_开局系统配置表.md`。

## 6. 首境模板职责

| 首境 | 主要体验 |
| --- | --- |
| 商路荒谷 | 稳定推进、商店与资源更友好 |
| 旧矿地窟 | 战斗、秘藏、飞剑和法器偏向明显 |
| 妖塔外层 | 精英密度高、成长快、压力大 |
| 迷林药谷 | 事件、恢复、岔路与功法过渡更多 |
| 雷泽险地 | 高风险高收益，雷系与爆发更强 |
| 祖地旧库 | 洞府、秘藏、构筑加速更明显 |

## 7. 路线分叉

每层建议提供 2-4 条路线。

| 路线类型 | 特点 |
| --- | --- |
| 稳定路线 | 普通战斗、修炼、商店较多 |
| 冒险路线 | 精英、秘藏、事件较多 |
| 构筑路线 | 洞府、商店、升级节点较多 |
| 资源路线 | 战斗和经济事件较多 |

## 8. 设计底线

- 地图必须给玩家路线选择，而不是线性闯关。
- 首境必须和启程线的来历、去向、启程信物形成统一叙事。
- 节点奖励要服务道途显化，而不是完全随机。
- 玩家应感觉自己是在“顺着这条出山路修下去”，而不是进入无来历的公共副本。
