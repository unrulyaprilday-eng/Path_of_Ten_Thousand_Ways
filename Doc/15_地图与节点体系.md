# 地图与节点体系

> 地图体系负责单局节奏、路线选择、风险收益和流派成型速度。

## 1. 设计目标

节点地图要让玩家在每局中持续做路线决策：

- 要稳定成长还是冒险拿核心遗物？
- 要去商店补卡还是挑战精英？
- 要恢复状态还是继续强化？
- 要提前压缩卡组还是追求高稀有奖励？

## 2. 单局地图结构

完整版本建议采用多层历练结构。

| 阶段 | 层数 | 目标 | Boss |
| --- | ---: | --- | --- |
| 初入秘境 | 1-2 | 建立流派种子 | 小妖王 |
| 深入洞天 | 3-4 | 构筑成型 | 魔修首领 |
| 天劫前夜 | 5-6 | 构筑爆发 | 天劫化身 |
| 飞升试炼 | 7+ | 终局挑战 | 天道投影 |

DEMO 阶段可压缩为 3 层：种子期、成型期、天劫 Boss。

## 3. 节点类型

| 节点 | 功能 | 主要奖励 |
| --- | --- | --- |
| 普通战斗 | 基础构筑推进 | 卡牌、灵石、小概率遗物 |
| 精英战斗 | 高风险高收益 | 遗物、高品质卡牌 |
| 事件 | 代价选择和奇遇 | 功法、资源、诅咒、特殊遗物 |
| 商店 | 补齐构筑缺口 | 卡牌、遗物、删除、升级 |
| 修炼 | 恢复和强化 | 升级、治疗、净化 |
| 洞府 | 功法获取 | 主修、辅修、残篇 |
| 秘境 | 特殊规则挑战 | 稀有遗物、法宝 |
| Boss | 阶段检验 | 高品质奖励、进入下一阶段 |

## 4. 节点权重

| 节点 | 基础权重 |
| --- | ---: |
| 普通战斗 | 40% |
| 精英战斗 | 15% |
| 事件 | 20% |
| 商店 | 10% |
| 修炼 | 10% |
| Boss | 5% |

权重应根据层数和玩家状态动态调整：

- 玩家生命过低时，提高修炼节点出现率。
- 当前构筑缺少核心组件时，提高洞府或商店权重。
- 连续两层无精英时，提高精英候选概率。
- Boss 前至少提供一次补强机会。

## 5. 路线分叉

每层建议提供 2-4 条路线。

| 路线类型 | 特点 |
| --- | --- |
| 稳定路线 | 普通战斗、修炼、商店较多 |
| 冒险路线 | 精英、秘境、事件较多 |
| 构筑路线 | 洞府、商店、升级节点较多 |
| 资源路线 | 战斗和经济事件较多 |

## 6. 事件节点

事件应提供明确代价和收益。

| 事件 | 选择 | 结果 |
| --- | --- | --- |
| 古修洞府 | 参悟残卷 | 获得功法残篇，失去生命 |
| 心魔幻境 | 接受心魔 | 获得禁术，加入心魔牌 |
| 雷劫台 | 主动渡劫 | 胜利获得雷系遗物，失败受伤 |
| 神秘商人 | 购买道器 | 消耗灵石获得随机遗物 |
| 剑冢 | 取剑 | 获得飞剑组件，降低最大生命 |

## 7. 商店节点

商店提供构筑修正能力。

| 商品 | 功能 |
| --- | --- |
| 卡牌 | 补充主动手段 |
| 遗物 | 补齐流派核心 |
| 功法残篇 | 推进功法升级 |
| 删除卡牌 | 压缩卡组 |
| 升级服务 | 强化关键牌 |
| 净化服务 | 移除诅咒或心魔 |

## 8. 修炼节点

修炼节点三选一：

| 选项 | 效果 |
| --- | --- |
| 调息 | 恢复生命 |
| 悟道 | 升级一张卡或功法 |
| 炼器 | 强化法宝或飞剑 |

## 9. Boss 节点

Boss 是流派验证器。

| Boss | 验证目标 |
| --- | --- |
| 小妖王 | 是否有基础输出循环 |
| 魔修首领 | 是否有联动和资源管理 |
| 天劫化身 | 是否能处理爆发压力 |
| 天道投影 | 是否达到终局上限 |

Boss 奖励应能改变后续构筑，例如：

- 传说遗物。
- 神通卡。
- 大道残篇。
- 开启双流派。

## 10. 地图数值建议

| 参数 | 建议值 |
| --- | ---: |
| 每层节点数 | 6-10 |
| 每次可选路线 | 2-4 |
| 普通战斗时长 | 2-4 分钟 |
| 精英战斗时长 | 4-6 分钟 |
| Boss 战时长 | 5-8 分钟 |
| 单局完整时长 | 25-45 分钟 |
| DEMO 单局时长 | 12-20 分钟 |

## 11. 设计底线

- 地图必须给玩家路线选择，而不是线性闯关。
- 精英路线必须有诱人奖励。
- Boss 前必须提供补强机会。
- 事件不能只是随机好坏，要有代价选择。
- 节点奖励要服务流派成型，而不是完全随机。
