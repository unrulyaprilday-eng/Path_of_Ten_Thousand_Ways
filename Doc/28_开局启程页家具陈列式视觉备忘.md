# 开局启程页家具陈列式视觉备忘

> 状态：备忘录，暂不执行。  
> 用途：保留后续开局 UI 迭代方向，方便回头提醒与评估。  
> 关联文档：`21_美术资源生成规范.md`、`23_DEMO第一阶段设计.md`、`26_开局结构与启程系统设计.md`。

## 1. 备忘目标

把当前偏“卡片候选”的开局启程展示，进一步改成更有仪式感的场景化陈列：

- 玩家进入启程页时，看到的不是纯 UI 列表，而是若干起手物件摆放在家具陈设上。
- 家具可使用书架、茶几、案台、兵器架等带居室感的承载物。
- 玩家选中某个物件后，物件飞到镜头前方或角色面前，形成“携一物上路”的确认感。
- 页面左中位置固定展示自己的开局属性与起势摘要，避免纯氛围化后信息难读。

## 2. 与现有开局结构的兼容边界

- 这是 `启程页` 的视觉升级方向，不新增“单独选旧物”或“单独选遗物”的额外步骤。
- 仍遵循当前开局主流程：`道痕整备 -> 定根脚 -> 启程 -> 首境`。
- 这里口头上的“开局选择遗物”，落地时更适合对齐现有命名，优先解释为 `携行之物 / 启程携物` 的场景化呈现。
- 不应把页面做成杂物堆满的搜索玩法；候选数量仍以 3 个左右最稳妥，核心是选择仪式感，不是找物解谜。

## 3. 场景表现备忘

### 3.1 场景气质

- 基底仍是黑白水墨修仙，不转成写实室内模拟。
- 家具和器物应有洞府、书斋、山门偏厅的气质，带少量描金或流派点染。
- 画面应服务“启程前夜”或“临行取物”的情境，而不是普通仓库陈列。

### 3.2 画面构图

- 中右或右侧：家具与候选物件陈列区。
- 左中：玩家本局开局属性、起势标签、首境去向。
- 中央前景：被选中的物件飞出后停留的展示区。
- 背后可保留卷轴、窗景、墨山、烛火、云气等低频氛围元素，但不压过可交互物件。

### 3.3 可选承载物

- 书架：适合玉简、残卷、匣、镜、符匣。
- 茶几：适合小型器物、剑穗、葫芦、残印。
- 案台：适合卷轴、古镜、令牌、剑胚。
- 兵器架：适合短剑、剑匣、断刃、旧鞘。

## 4. 交互备忘

### 4.1 默认状态

- 候选物件静置在家具上，有轻微浮动、呼吸光或墨气流动。
- 家具本身只做弱动效，避免比物件更抢眼。

### 4.2 悬停状态

- 被指向的物件出现描金、轮廓亮边或微弱墨痕扩散。
- 左中的开局属性面板同步预览该物件对应的起势变化。

### 4.3 选中状态

- 物件脱离家具，向玩家面前飞出。
- 飞行过程可带短促拖尾、纸墨散开、剑气或符灰效果。
- 飞到前景后短暂停驻，展示名称、起手效果与首境去向。
- 二次确认后进入后续流程。

## 5. 左中开局属性区备忘

左中位置固定展示“这局你是谁、带了什么、会往哪边起势”，建议优先容纳：

- 根脚名
- 启程线标题或一句来历摘要
- 当前选中物件名
- 起手效果摘要
- 初始生命 / 灵气 / 飞剑数等关键开局属性
- 首境名
- 2-3 个起势标签

原则：

- 信息比启程卡更聚焦，不再大段铺文案。
- 先让玩家看懂“我带这个出山，会让我这局怎么开”。
- 属性区保持左中固定，避免物件飞出后信息位置来回跳动。
