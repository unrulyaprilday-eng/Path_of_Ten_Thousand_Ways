# DEMO 旅程、地图与叙事

> 本文定义当前 DEMO 的完整旅程、旧矿三幕地图、故事推进、节点职责、因果与 Boss 层级。它是当前纵切在旅程与叙事方面的最新真源。

## 1. DEMO 核心命题

当前 DEMO 讲述：

> 一名世家旁支男性长发剑修，在祖龛坍塌后取得残剑胚，循旧矿契的共鸣进入废弃矿脉；他在一处大境域中不断深入，获得心法与剑诀、炼化本命法器、见证旁支旧契的真相，从炼气走到筑基，最终面对玄铁镇矿剑傀。

这是一条需要做透的完整故事线，不在 DEMO 中同时铺开多个境域。单局以 30–40 分钟作为初始 tuning，每幕实际经过 6–8 个以上节点，具体时长以后续真实运行验证为准。

## 2. 沉浸式开局

开局流程收束为：

```text
首页 / 开卷
↓
祖龛坍塌：在同一场景中确认根脚并取得所携
↓
所往：独立选择境域
↓
旧矿入口
↓
首战
```

### 2.1 定根脚与所携合并

“世家旁支”不是一张职业卡，“残剑胚”也不是一件菜单装备。两者通过同一段可交互场景建立：

1. 祖龛在异动中坍塌，玩家从旁支旧物和人物关系中确认自己的身份。
2. 残破案台或祖龛废墟中只留下残剑胚、初始心法线索与一式残缺剑诀。
3. 玩家亲手拿起残剑胚，剑胚与腕上旧痕、祖龛残契或矿契产生共鸣。
4. 共鸣展开地图，引出独立的“所往”选择。

当前只开放这一条完整起点。未来其他根脚与所携必须拥有同等完整的来历、初始能力和所往理由后才能开放。

### 2.2 所往保留独立选择

所往回答“这次先去哪里”，应让玩家看到境域气质、已知风险与故事牵引。当前只有旧矿可进入；其他境域可以作为远景轮廓或锁定线索出现，但不能提供伪可点击选项。

## 3. 一处大境域，三幕深入

旧矿不是三张互不相关的地图皮肤，而是一张持续向深处展开的完整境域。

| 幕 | 区域气质 | 故事职责 | 幕末检验 |
| --- | --- | --- | --- |
| 第一幕：矿门与废道 | 入口天光、旧木架、废矿车、浅层残垣 | 找到旁支矿契与第一批异常痕迹，建立本命法器和基础法诀成长 | 怪兽型小 Boss，检验基础循环 |
| 第二幕：塌井与遗迹 | 冷墨深井、断桥、矿工遗迹、青绿矿脉 | 发现旁支、矿工与镇矿剑傀之间的旧事，寻找筑基条件 | 妖物或矿兽小 Boss，检验多目标和引擎 |
| 第三幕：玄铁剑炉 | 巨型锁链、废剑、朱砂封契、玄铁炉心 | 完成筑基后的选择，决定如何处理旧契并走向结局 | 玄铁镇矿剑傀 |

三幕使用同一张可持续滚动的地图和连续环境变化。击败幕末小 Boss 后，路径继续向矿脉深处显现，不切回完全独立的菜单章节。

## 4. 地图方向与空间语言

地图整体从下向上推进，局部分支向左上、正上和右上展开：

```text
                区域 Boss
             ╱     │     ╲
         节点 ── 节点 ── 节点
           ╲      ╱ ╲      ╱
             节点 ── 节点
                ╲  │  ╱
                  起点
```

采用这一方向的原因：

- 玩家从画面下方向上面对未知和威胁，与普通战左下向右上的攻击轴一致。
- 每一纵深带可以横向展示多个选择，适合 16:9 画面。
- 区域 Boss 始终位于上方深处，形成明确远期目标。
- “深入地下”通过矿井透视、入口天光消失、空间压缩、矿脉和锁链增加来表达，不把地理深度机械等同于屏幕向下。

地图本身应是一幅黑白水墨矿井长卷。节点是场景中的地点、人物、器物或异象，不是悬浮在抽象黑底上的统一圆点。

## 5. 节点规模与比例

- 每幕标准路线实际经过 6–8 个以上节点，默认包含幕末小 Boss 或区域 Boss。
- 高风险捷径可以少走节点并提前面对精英或失去修炼机会。
- 隐藏路线可以额外增加 1–2 个节点，提供特殊事件、秘藏或更高风险。
- 地图应展示多于玩家实际经过数量的节点，让路线选择具有长期规划意义。
- 三幕总长度以完整冒险成立为准，不为严格凑数复制同质节点。

当前比例以约一半战斗 / 精英、一半非战斗历练作为 DEMO tuning：

| 类别 | 职责 |
| --- | --- |
| 普通战斗 | 建立敌人生态、承受损耗、验证新能力 |
| 精英 | 提供高压机制、稀有媒介、法器或关键成长机会 |
| 奇遇 | 人物、旧事、代价选择和具体因果 |
| 修炼 | 心法升阶、疗伤、淬炼、斩旧、易式或定向悟法 |
| 洞府 / 秘境 | 通过环境互动悟得法诀、筑基条件或特殊规则 |
| 秘藏 | 法器、残卷、旧契证物和隐藏路线条件 |
| 幕末 Boss | 检验本幕构筑并推进主线 |

非战斗节点不能全部做成同一种随机问号或三张文字卡。玩家在地图上应能大致判断这是修炼场所、人物奇遇、洞府、秘藏还是高风险未知。

当前 DEMO 不使用通用货币，也不设置固定灵石商店。需要交换时，应通过具体人物、供奉、疗伤、祭炼、承诺、气血、牌库变化或后续风险形成沉浸式代价。

## 6. 手工骨架与种子变化

地图采用“手工结构 + 种子变化”，不是固定路线套餐，也不是完全自由随机。

### 6.1 固定骨架

- 三幕顺序、纵深范围和环境递进固定。
- 每幕起点、主线职责节点、幕末 Boss 与第三幕区域 Boss 固定。
- 每幕至少一个主线事件必定出现，但可在合理纵深范围内移动。
- 筑基相关节点在第二幕逐步铺垫，突破发生在第二幕末到第三幕入口的固定故事区间。

### 6.2 种子变化

- 从已手工验证的拓扑模板中选择本局连线。
- 普通战、精英、奇遇、修炼、洞府和秘藏在限定纵深内替换或调整顺序。
- 敌人组合、事件内容、能力候选和隐藏条件受同一局种子约束。
- 同一事件一局内不重复。
- 已完成事件和具体因果会改变后续可用节点池。

### 6.3 合理性约束

- 每个可进入节点至少有一条合法后续路径，不生成无意义死路。
- 普通路线避免连续三场战斗；明确标记的高风险路线可以例外。
- 幕末 Boss 前至少能看见一个修炼、恢复或整备机会，但玩家可以主动绕开。
- 基础筑基与通关所需职责不能依赖单一随机事件。
- 隐藏路线只有在取得线索、法器、人物关系或特定因果后才显现。
- 同一随机种子必须稳定复现地图、事件和遭遇，保证验证与继续游戏时一致。

## 7. 地图阅读与节点进入

当前幕基本公开，后续幕只显示轮廓、环境征兆和 Boss 远景：

- 普通战、精英、修炼和幕末 Boss 类型可见。
- 奇遇显示地点或人物主题，不提前公布全部结果。
- 秘藏显示收益与风险倾向，不公开具体物品。
- 隐藏节点在满足条件后由墨迹、裂缝、矿图或精怪引路显现。

节点进入流程：

```text
持续地图选择可达节点
↓
墨迹沿真实路径蔓延，角色位置移动
↓
镜头进入该节点的场景
↓
战斗 / 交互 / 修炼 / 悟法 / 祭炼
↓
播放简短结果与因果反馈
↓
返回原地图位置，显现新的可达路径
```

点击节点后直接进入对应场景，不再弹出第二层路线卡确认。只有精英、Boss 或高代价节点需要在场景中给予明确风险预告。

## 8. 主线故事骨架

### 8.1 第一幕：契从何来

- 残剑胚把玩家引向旧矿，而不是随机选择一处刷怪地图。
- 废弃矿车、矿工刻痕、残缺账册和旁支族印逐步证明族人与旧矿有关。
- 第一幕只揭示“旁支曾承担某种矿契”，不一次讲完真相。
- 玩家第一次遇到能够反复出现的精怪、残魂或矿灵角色，并决定如何回应。

### 8.2 第二幕：剑傀为何镇矿

- 塌井深处出现被废剑、契钉与矿髓侵蚀的怪物。
- 旧账、残魂证词和剑炉痕迹揭示：旁支族人曾被迫参与镇矿剑傀的祭炼与维护。
- 玩家逐步取得筑基媒介，例如剑碑认可、地脉灵眼、玄铁妖核、心法下卷或特殊人物帮助。
- 第二幕幕末小 Boss 的战利与因果决定可用的特殊筑基方式。

### 8.3 第三幕：如何斩断旧契

- 玩家以本局经历完成筑基，进入玄铁剑炉。
- 朱砂残契、巨大锁链、废弃飞剑和炉心记录说明剑傀为何仍在执行旧命令。
- 玩家面对的不是抽象天道，而是旧制度、旧契与前人选择留下的具体造物。
- 先前如何对待精怪、残魂、禁术和本命法器，会改变可达路线、Boss 阶段、助力或代价。

## 9. 能力与故事绑定

能力获得必须有具体场景来源，示例包括：

- 在断壁剑痕前承受一次剑意冲刷，悟得新的攻击剑诀。
- 在雷痕山洞或青绿矿脉中引雷入刃，获得雷剑变化。
- 找到旁支藏起的心法下卷，使初始心法升至二阶。
- 在废弃剑炉中温养、强炼或改造残剑胚。
- 超度矿工残魂后得到完整剑式；炼化残魂则得到更强但带因果的禁式。
- 帮助精怪开启墙后秘径；束缚或击杀它则取得即时资源并关闭相关故事。
- 在秘境中以气血、牌库变化、下一战强化或旧契承诺换取特殊规则。

普通战后不固定弹出三张卡。战斗可能留下线索、媒介、器物或参悟机会，也可以只完成风险消耗与故事推进。

## 10. 隐藏因果

DEMO 不显示统一“正道 / 邪道”数值。系统记录具体行为事实，例如：

- 对反复出现的精怪或矿灵是帮助、拒绝、利用、束缚还是击杀。
- 对矿工残魂是超度、吸收、无视还是交换。
- 对旁支旧契是焚毁、继承、篡改还是寻找见证者。
- 对禁术是拒绝、研习、转交还是封存。
- 对残剑胚是温养、强炼、吞噬其他器物还是保持本真。

这些因果可以影响：

- 后续事件和对白。
- 隐藏节点与地图捷径。
- 心法升阶、法诀与筑基方式。
- 本命法器外观和自动攻击规则。
- 小 Boss 形态、区域 Boss 阶段、隐藏 Boss 或结局。

### 10.1 反复出现的精怪角色槽

旧矿需要一个会多次出现、既能帮助又有自身诉求的精怪或矿灵角色，但不把“最后必然背刺”写成固定答案。

- 帮助它可能获得引路和隐藏节点，也可能让它逐步取回力量。
- 束缚或利用它可以立即强化本命法器，但会积累反噬条件。
- 击杀或搜刮会关闭其人物线，换取确定性资源或另一条敌对路线。
- 帮助但拒绝危险要求，可能使其在最终战破坏契钉或提供信息。
- 极端因果可以让它与剑傀融合、夺取炉心或成为隐藏 Boss 候选。

所有反转必须有前置伏笔、可观察异常和玩家参与，不能为了惊讶强行否定此前选择。

## 11. 筑基融入主线

筑基是第二幕收束和第三幕开端之间的重大叙事事件，不使用随机三选一弹窗。

玩家在前两幕实际获得不同条件；突破场景根据这些经历显示可交互对象，例如：

- 剑碑或前人剑痕：以剑意筑基。
- 青绿地脉灵眼：以清灵之法筑基。
- 雷痕矿脉：以雷脉筑基。
- 妖核、残魂或旧契：以更激进且带因果的方式强行筑基。
- 可信任的精怪或人物：开启特殊方式，同时提出其代价。

每局保留一个稳定但个性较弱的基础筑基方案，避免地图随机导致流程中断。特殊方案只由玩家此前真正取得的条件解锁。

突破后，第三幕第一组遭遇应尽快让新道基规则在战斗、角色外观、本命法器和地图回应中显现。

## 12. Boss 层级

### 12.1 第一幕小 Boss

使用矿兽或其他怪兽形态，工作名可为“铁脊矿兽”。它保持普通战右上斜向构图，但体型、扑击、碎岩和压迫感明显高于普通敌人，检验基础循环和生存。

### 12.2 第二幕小 Boss

使用妖物或受废剑侵蚀的怪兽，工作名可为“吞剑矿魈”。它可以携带矿核、召唤物或短暂干扰飞剑，检验多目标处理、法器引擎和筑基准备，但不能直接废掉剑修主轴。

### 12.3 最终 Boss：玄铁镇矿剑傀

- 它是旧宗门封矿后留下的巨型守矿剑傀，属于区域守关者，不是天道级存在。
- Boss 占据画面正上方的大面积空间，与普通敌人构图形成等级跃升。
- 玄铁甲片、朱砂残契、青绿剑炉核心构成阶段变化和可锁定目标。
- 甲片、契钉、剑炉核心或召唤构造体可作为临时目标，击破后自动回到 Boss。
- 先前因果可以改变契钉数量、阶段技能、精怪立场、隐藏阶段或结局，但标准 Boss 始终有不依赖隐藏线的可通关方案。

天劫从当前 DEMO 移除，保留给完整游戏的高境界最终挑战或隐藏 Boss。

## 13. 结局与重玩

击败玄铁镇矿剑傀后，结局至少应回答：

- 玩家最终如何处理旁支旧契。
- 本命法器在这一世被炼成什么。
- 反复出现的精怪、残魂或相关人物最终如何回应。
- 玩家筑成何种道基，并以什么方式离开旧矿。
- 哪些见闻、人物、法诀、法器、隐藏路线或新起点进入局外解锁。

不同种子负责改变本局经历顺序和组合，具体因果负责改变故事后果。两者共同提供重玩价值，但不能让主线真相和基础筑基变成纯随机抽取。

## 14. 旅程设计红线

- 不把三幕拆成三次固定路线套餐。
- 不让每幕只有两三个实际节点。
- 不用固定商店和通用货币填充非战斗内容。
- 不把所有奇遇、修炼、秘藏做成同一套三卡页面。
- 不让能力脱离场景和故事凭空出现。
- 不用完全随机拓扑制造断路、连续同类节点或主线错序。
- 不把精怪帮助或背刺写成无视玩家选择的固定桥段。
- 不让天劫或飞升尺度抢占当前区域故事的最终位置。
