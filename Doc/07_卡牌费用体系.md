# 卡牌费用体系

> 本章定义卡牌费用、灵气消耗、抽牌节奏和冷却预算。当前战斗主结构是 `牌库驱动的半实时斗法`，不是固定回合制卡牌。

## 1. 核心原则

- 费用不等于品质，也不等于稀有度。
- 费用决定单次出牌预算。
- 冷却决定节奏限制。
- 品质决定成长空间。
- 稀有度决定获取难度。
- 半实时战斗中，灵气持续增长，费用体现“攒势与释放”的手感。

公式：

```text
卡牌价值 = 费用预算 × 品质系数 × 机制系数 × 节奏系数
```

## 2. 费用预算

| 费用 | 倍率 |
| --- | ---: |
| 0 | 0.6 |
| 1 | 1.0 |
| 2 | 2.0 |
| 3 | 3.0 |
| 4 | 4.0 |
| 5 | 5.0 |
| 6 | 6.0 |
| 7 | 8.0 |
| 8 | 10.0 |
| 9 | 12.0 |
| 10 | 15.0 |

设计说明：

- 0 费卡负责启动、修正手牌和轻量触发。
- 1-2 费卡负责基础节奏。
- 3-5 费卡负责核心动作、资源转化和中型连招。
- 6 费以上负责爆发、神通或规则效果。

## 3. 半实时抽牌体系

推荐 DEMO tuning：

| 项目 | 建议 |
| --- | ---: |
| 初始手牌 | 4-5 |
| 手牌上限 | 7-8 |
| 基础抽牌间隔 | 3-5 秒 |
| 牌库为空 | 弃牌堆洗回牌库 |
| 弃牌时机 | 卡牌结算后进入弃牌区或冷却弃牌区 |

抽牌来源：

- 基础时间抽牌。
- 卡牌效果抽牌。
- 功法周期抽牌。
- 法器触发抽牌。
- 节点奖励修改抽牌速度或手牌上限。

## 4. 费用与冷却分工

费用回答：

> 现在能不能打得起这张牌？

冷却回答：

> 这张牌或同类强效果能不能连续出现？

设计底线：

- 不能只靠冷却来替代牌库循环，否则卡牌会退化成技能栏。
- 强牌可以有短冷却、消耗、封存或高费用，但仍应受抽牌和构筑影响。
- 法器主动效果可以使用冷却，但主动法器数量要少。

## 5. 状态预算入口

异常状态预算仍沿用机制强度估算，但结算单位改为持续时间、触发间隔或命中次数，不再默认按“回合结束”结算。

| 状态 | 基础预算参考 |
| --- | ---: |
| 流血 | 15 |
| 灼烧 | 12 |
| 中毒 | 20 |
| 感电 | 15 |
| 冰冻 | 50 |
| 眩晕 | 150 |

最终价值模型：

```text
境界 × 费用 × 品质 × 稀有度 × 机制设计 × 半实时节奏
```
