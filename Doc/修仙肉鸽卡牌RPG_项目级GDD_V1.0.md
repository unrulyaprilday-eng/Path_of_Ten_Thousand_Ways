# 修仙肉鸽卡牌RPG 项目级GDD V1.0

# 1. 项目概述

## 项目定位
修仙题材 + 肉鸽构筑 + 卡牌战斗 + RPG成长

目标是在低开发成本下，实现高沉浸感、高复玩性的修仙战斗体验。

核心卖点：
- 御剑斗法战斗演出
- 多流派构筑
- 肉鸽随机成长
- 境界突破养成
- 半即时战斗体验

# 3. 战斗系统

## 战斗模式

半即时卡牌制

每轮：

规划阶段（15秒）
↓

↓
下一轮
