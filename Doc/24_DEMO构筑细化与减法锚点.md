# DEMO 构筑细化与减法锚点

> 本文档不回答“第一版先做几张牌”，而先回答“DEMO 终局到底想让玩家修成什么”。先把终局 Build 写清楚，再倒推做减法、定卡池和定掉落。

补充说明：

- 本文沿用“万剑 / 雷剑 / 血剑”等 `道途` 称呼，只表示局内中后期显化出来的构筑方向。
- 它们不是开局直接裸选的按钮；开局入口仍遵循“定根脚 -> 受信物 -> 入首境”的完整结构。

## 1. 使用方式

本文件用于约束 DEMO 第一阶段的三条剑修道途：

- 万剑
- 雷剑
- 血剑

每条道途至少保留 1 套低门槛爽构筑和 1 套高门槛高上限构筑。

后续做减法时，不要先按“卡牌张数”删，而要先保住每套构筑的 3 个席位：

```text
启动席 -> 循环席 -> 收束席
```

- 启动席：拿到后，玩家立刻知道这局在玩什么。
- 循环席：拿到后，Build 从“能打”变成“会滚”。
- 收束席：拿到后，Boss 战出现明确爆发镜头。

设计底线：

- 每套构筑默认 3 张 Key 牌。
- 拿到其中 2 张时，必须已经有质变。
- 拿到第 3 张时，必须出现一局记得住的爽点。

## 2. 四维组合尺子

每套构筑都用同一组四维标准衡量。

| 维度 | 低值代表 | 高值代表 | 对体验的影响 |
| --- | --- | --- | --- |
| Key 牌获取难度 | 常见、早拿、路线宽 | 稀有、要定向、要赌路线 | 决定这套构筑常不常成 |
| Key 牌数量 | 2 张可基本运转 | 3 张以上才成型 | 决定构筑门槛 |
| 单张 Key 带来的跃升 | 线性补强 | 拿一张就变一个系统 | 决定中途有没有“突然滚起来” |
| 非 Key 牌强度 | 杂牌也能混着用 | 杂牌很弱，必须等 Key | 决定这套构筑是“从头爽到尾”还是“憋整局最后爆” |

推荐用法：

- 易成型构筑：Key 易拿，2 张就能打，非 Key 牌也不弱，终局上限略低。
- 难成型构筑：Key 更专、更难拿，前中期更憋，但终局上限明显更高。

## 3. 三道途六套终局构筑总览

| 道途 | 构筑名 | 节奏类型 | Key 获取难度 | 最低成型数 | 2 Key 质变 | 终局强度 |
| --- | --- | --- | --- | ---: | --- | --- |
| 万剑 | 万剑齐飞 | 从头爽到尾 | 低 | 2 | 飞剑数快速越线 | 中高 |
| 万剑 | 一剑开天门 | 憋整局最后一爆 | 高 | 3 | 剑意开始能囤能转 | 很高 |
| 雷剑 | 九霄连锁 | 中段开始持续爽 | 中 | 2 | 感电开始连锁引爆 | 高 |
| 雷剑 | 蓄雷天罚 | 先忍后炸 | 高 | 3 | 感电不再碎伤，开始蓄池 | 很高 |
| 血剑 | 血潮绞杀 | 稳定滚血线 | 低 | 2 | 流血层数开始自循环 | 中高 |
| 血剑 | 压血断生 | 危险换爆发 | 高 | 3 | 压血后资源与伤害一起起飞 | 很高 |

## 4. 万剑道途

### 4.1 万剑齐飞

一句话目标：

> 不是等最后一刀，而是从中期开始让屏幕上飞剑越来越多，最后直接把天劫淹掉。

默认骨架：

- 主修：御剑诀
- 辅修：剑心通明
- 神通：万剑归宗
- 关键法器：剑匣、剑骨、剑冢残碑、万剑剑匣

3 张 Key 牌：

| 席位 | 牌名 | 现状 | 作用 | 获取难度 |
| --- | --- | --- | --- | --- |
| 启动席 | 凝剑诀 | 现有 | 快速把剑意堆到飞剑增伤阈值之上 | 低 |
| 循环席 | 小诛仙剑阵 | 现有 | 把临时飞剑转成永久飞剑，开始越打越多 | 中 |
| 收束席 | 万剑诀 | 现有 | 把前面攒出的剑意一次性转成大爆发 | 中 |

2 Key 质变：

- `凝剑诀 + 小诛仙剑阵`：从“每个战斗节拍多几把剑”变成“永久飞剑开始滚雪球”。
- 这时哪怕收束牌还没来，演武阶段已经有明显的满屏感。

3 Key 大成：

- `凝剑诀 + 小诛仙剑阵 + 万剑诀`
- 先铺永久飞剑，再用剑意把单次斩击抬高，最后由神通 `万剑归宗` 做第二波归潮。

四维判定：

- Key 获取难度：低到中。三张牌都可以放进 DEMO 基础奖励池。
- Key 数量：2 张就能玩，3 张就很爽。
- 单张跃升：第二张最关键，拿到剑阵后体感陡增。
- 非 Key 牌强度：高。任何便宜飞剑牌、抽牌牌、护盾牌都能接进来。

体验定位：

- 这是万剑道途的低门槛主打构筑。
- 负责保证新玩家第一局就能看到“飞剑越打越多”的正反馈。

减法锚点：

- 绝不能删 `凝剑诀`。
- 绝不能让 `小诛仙剑阵` 掉得太晚。
- 就算后续删卡，也要保住“永久飞剑成长”这个席位。

### 4.2 一剑开天门

一句话目标：

> 前面像在养势，最后把整局攒出来的剑意、飞剑和镜像全部压成一剑，专门负责打出“开天门”的记忆点。

默认骨架：

- 主修：御剑诀
- 辅修：剑心通明
- 神通：万剑归宗
- 关键法器：昊天镜、残破古镜、聚灵符

3 张 Key 牌：

| 席位 | 牌名 | 现状 | 作用 | 获取难度 |
| --- | --- | --- | --- | --- |
| 启动席 | 凝剑诀 | 现有 | 把这套构筑的伤害底盘建立在剑意上 | 低 |
| 循环席 | 藏锋诀 | 现有 | 当前蓄势窗口内飞剑暂缓出手，改为转化为剑意或蓄势值 | 高 |
| 收束席 | 开天一剑 | 现有 | 消耗全部剑意与蓄势，对单体打出极高倍率斩击 | 高 |

2 Key 质变：

- `凝剑诀 + 藏锋诀`：飞剑不再只是持续伤害，而开始变成可被囤积的爆发资源。
- 这一步就会让玩家意识到：“我这局不是万剑齐飞，我是忍一轮换斩首。”

3 Key 大成：

- `凝剑诀 + 藏锋诀 + 开天一剑`
- 如果再叠加 `昊天镜` 或 `残破古镜`，会出现一次爆发窗口内双斩的顶级镜头。

四维判定：

- Key 获取难度：高。必须有 1-2 张专属高稀有牌。
- Key 数量：严格 3 张，少一张都不完整。
- 单张跃升：第二张开始换系统，第三张才真正结算。
- 非 Key 牌强度：中低。没有 `藏锋诀` 时，这套牌只是普通万剑壳。

体验定位：

- 这是万剑道途的高门槛高上限构筑。
- 它负责提供“一剑开天门”的海报级镜头。

减法锚点：

- 如果 DEMO 第一轮来不及，允许晚于 `万剑齐飞` 落地。
- 但只要做，就必须把“囤势”和“单体超大斩击”一起做出来，不能只做一张高伤牌冒充它。

## 5. 雷剑道途

### 5.1 九霄连锁

一句话目标：

> 飞剑每次出手都在带电，感电不是附加词条，而是整个演武阶段的主要爆发来源。

默认骨架：

- 主修：九霄神雷诀
- 辅修：引雷入窍
- 神通：九天引雷
- 关键法器：雷印、雷心、九霄雷印

3 张 Key 牌：

| 席位 | 牌名 | 现状 | 作用 | 获取难度 |
| --- | --- | --- | --- | --- |
| 启动席 | 雷剑 | 现有 | 让飞剑与感电第一次绑定 | 低 |
| 循环席 | 引雷诀 | 现有 | 快速把感电层数堆到可引爆区间 | 中 |
| 收束席 | 奔雷剑阵 | 现有 | 把飞剑数量和感电层数一起抬上去，触发连续雷击 | 中 |

2 Key 质变：

- `雷剑 + 引雷诀`：感电不再是慢慢磨，而是每个战斗节拍都开始有“引爆值”。
- 玩家会第一次明确看见飞剑后接雷击的自动连锁。

3 Key 大成：

- `雷剑 + 引雷诀 + 奔雷剑阵`
- 再叠主修 `九霄神雷诀` 与神通 `九天引雷`，一次演武阶段会出现多段雷击追落。

四维判定：

- Key 获取难度：中。第一张易拿，后两张应向雷剑路线倾斜。
- Key 数量：2 张就很好用，3 张会明显超线。
- 单张跃升：第一张定方向，第二张开始爆，第三张把次数做满。
- 非 Key 牌强度：中高。抽牌、保命和灵气牌都能顺利接进去。

体验定位：

- 这是雷剑的稳定主打构筑。
- 爽点不是单次最大数字，而是“每次飞剑都在触发新的雷击”。

减法锚点：

- 不要把雷剑做成普通伤害牌换皮。
- 必须保证 `雷剑` 本身就能触发感电互动，否则整条道途会空心。

### 5.2 蓄雷天罚

一句话目标：

> 前面不是一直炸，而是把雷压进敌人体内，等到 Boss 进入窗口时一口气放出天罚。

默认骨架：

- 主修：九霄神雷诀
- 辅修：引雷入窍
- 神通：九天引雷
- 关键法器：雷印、昊天镜、九霄雷印、残破古镜

3 张 Key 牌：

| 席位 | 牌名 | 现状 | 作用 | 获取难度 |
| --- | --- | --- | --- | --- |
| 启动席 | 引雷入刃 | 现有 | 让感电增长更快，并帮助过滤牌序 | 中 |
| 循环席 | 封雷匣 | 现有 | 当前蓄雷窗口内感电不引爆，改为保留并在下一次引爆窗口翻倍或增强 | 高 |
| 收束席 | 雷狱镇压 | 现有 | 在感电池足够深时一次性引爆，并兼顾生存 | 高 |

2 Key 质变：

- `引雷入刃 + 封雷匣`：从“边挂边炸”变成“我在养一池雷”。
- 这一步就是雷剑的系统级变化。

3 Key 大成：

- `引雷入刃 + 封雷匣 + 雷狱镇压`
- 再接神通 `九天引雷` 或终结牌 `九霄雷剑`，Boss 会在一轮里吃到大段连续落雷。

四维判定：

- Key 获取难度：高。`封雷匣` 必须是较高稀有的专属牌。
- Key 数量：严格 3 张，且对顺序有要求。
- 单张跃升：第二张最关键，因为它把整个玩法改成“蓄雷”。
- 非 Key 牌强度：中低。没拿到 `封雷匣` 时，它只是普通雷剑壳。

体验定位：

- 这是雷剑道途里“憋一发大的”代表。
- 它和 `九霄连锁` 的差异不能只体现在数值，而要体现在引爆时机。

减法锚点：

- 如果未来删内容，优先保 `九霄连锁`。
- 但只要保留 `蓄雷天罚`，就必须有“延后引爆”这一条规则牌，不能只靠把感电数字做高。

## 6. 血剑道途

### 6.1 血潮绞杀

一句话目标：

> 用飞剑把流血层数越滚越深，Boss 不是突然死，而是在你已经稳稳接管战场之后被血潮绞碎。

默认骨架：

- 主修：血煞经
- 辅修：血炼归元
- 神通：血狱断生
- 关键法器：紫金葫芦、血剑胚、血魔珠

3 张 Key 牌：

| 席位 | 牌名 | 现状 | 作用 | 获取难度 |
| --- | --- | --- | --- | --- |
| 启动席 | 血痕 | 现有 | 给敌人挂上第一层稳定可读的流血 | 低 |
| 循环席 | 血剑胚 | 现有 | 让飞剑本身也进入流血体系 | 中 |
| 收束席 | 血潮剑阵 | 现有 | 同时增加飞剑与流血层数，让绞杀进入滚雪球 | 中 |

2 Key 质变：

- `血痕 + 血剑胚`：从“我会叠 DOT”变成“飞剑每个攻击节拍都在加深血线”。
- 这时血剑已经和普通攻击套牌彻底分开。

3 Key 大成：

- `血痕 + 血剑胚 + 血潮剑阵`
- 再配 `血炼归元` 的回复与 `血煞经` 的流血增伤，整个构筑会又稳又痛。

四维判定：

- Key 获取难度：低到中。很适合作为血剑的第一套主打构筑。
- Key 数量：2 张即可稳定运转，3 张后开始明显碾压长线 Boss。
- 单张跃升：第二张决定成不成型，第三张决定滚不滚得起来。
- 非 Key 牌强度：高。保命牌、抽牌牌、补灵气牌都不浪费。

体验定位：

- 这是血剑道途里最适合做成“从中期开始就一直强”的构筑。
- 负责证明血剑不只是卖血爆发，也可以是稳定 Boss 杀手。

减法锚点：

- `血剑胚` 绝不能只是高伤牌，它必须把“飞剑也能上流血”这层规则做清楚。
- 没有这一层，血剑会退化成普通 DOT 套。

### 6.2 压血断生

一句话目标：

> 玩家主动把自己压到危险血线，用生命换资源、换爆发、换斩杀，最后一波血狱把 Boss 直接按死。

默认骨架：

- 主修：血煞经
- 辅修：血炼归元
- 神通：血狱断生
- 关键法器：紫金葫芦、昊天镜、血魔珠、护心镜

3 张 Key 牌：

| 席位 | 牌名 | 现状 | 作用 | 获取难度 |
| --- | --- | --- | --- | --- |
| 启动席 | 噬命开锋 | 现有 | 主动失去生命，换取灵气、剑意或飞剑数量 | 高 |
| 循环席 | 血祭养锋 | 现有 | 把掉血后的资源继续转成输出节奏 | 中 |
| 收束席 | 血祭斩 | 现有 | 在敌人已有流血与自己低血时完成爆发斩杀 | 高 |

2 Key 质变：

- `噬命开锋 + 血祭养锋`：生命第一次不再只是防线，而成了资源。
- 玩家会明确进入“我在赌一把大的”状态。

3 Key 大成：

- `噬命开锋 + 血祭养锋 + 血祭斩`
- 再叠 `血魔珠` 与神通 `血狱断生`，会出现低血反杀和斩杀翻盘的高压爽点。

四维判定：

- Key 获取难度：高。必须让这套构筑不是每局都随便成。
- Key 数量：严格 3 张，且对保命配件有额外依赖。
- 单张跃升：第一张就改玩法，第二张开始加速，第三张负责兑现。
- 非 Key 牌强度：中低。没拿到主动压血工具前，这套牌容易只有风险没有收益。

体验定位：

- 这是血剑道途里风险最高、上限也最高的代表。
- 负责提供“濒死翻盘”和“最后一刀吸回来”的高压镜头。

减法锚点：

- 如果只保留 `血魔珠` 这种低血增伤法器，而没有主动压血牌，这套构筑会变成被动挨打，不成立。
- 所以血剑高上限构筑必须有至少 1 张“主动卖血换资源”的牌。

## 7. 六套构筑的差异化定位

为了避免三道途都只是“叠数值然后放大招”，六套构筑的体验分工应刻意拉开：

| 构筑 | 爽感主轴 | 是否从头强 | 是否要憋 | 对 Boss 的杀法 |
| --- | --- | --- | --- | --- |
| 万剑齐飞 | 满屏飞剑、越打越多 | 是 | 否 | 用数量压死 |
| 一剑开天门 | 单次极限斩击 | 否 | 是 | 用一刀开门 |
| 九霄连锁 | 飞剑带雷、多段追击 | 中 | 略憋 | 用连锁炸死 |
| 蓄雷天罚 | 蓄雷后一轮清算 | 否 | 是 | 用时机炸死 |
| 血潮绞杀 | 流血越滚越深 | 是 | 否 | 用持续绞死 |
| 压血断生 | 卖血后极限反杀 | 否 | 是 | 用斩杀收死 |

这张表是后续做减法时最重要的提醒：

- 不是每条道途都要“先弱后强”。
- 不是每条道途都要“屏幕特效很多”。
- 不是每条道途都要“靠最后一张终结牌”。

差异越开，DEMO 越像真的有三条道，而不是同一条剑道换三个颜色。

## 8. 反推减法建议

如果 DEMO 第一轮不可能一次落地六套完整终局，推荐按以下顺序实现：

1. 先保每条道途 1 套低门槛主打：
   - 万剑齐飞
   - 九霄连锁
   - 血潮绞杀
2. 再补每条道途 1 套高上限代表：
   - 一剑开天门
   - 蓄雷天罚
   - 压血断生

减法原则：

- 可以删边缘牌，不能删席位。
- 可以先让高难构筑少 1 张强化法器，不能没有“玩法转向牌”。
- 可以先压低构筑数量，不能让三条道途都只剩“铺飞剑然后自动打”。

## 9. 对当前 DEMO 卡池的直接要求

基于当前方向，后续卡池与掉落至少要满足：

- 万剑必须同时存在“铺场型”与“蓄势单斩型”两种收束。
- 雷剑必须同时存在“即时连锁引爆”与“延后引爆蓄雷”两种时机差异。
- 血剑必须同时存在“稳定流血绞杀”与“主动压血换斩杀”两种风险结构。

- 任何一套构筑拿到第 2 张 Key 牌时，都必须已经让玩家感到“这局开始不一样了”。

如果做不到这一点，就说明当前不是“构筑不够多”，而是“构筑席位还没立住”。
