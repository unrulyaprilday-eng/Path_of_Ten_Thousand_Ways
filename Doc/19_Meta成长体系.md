# Meta 成长体系

> Meta 成长负责局外长期目标。新结构下，它最重要的新职责，是逐步把“开局如何开始一世修行”的选择权交还给玩家，但又不能让这种选择权变成开局即毕业。

## 1. 设计目标

- 给玩家长期追求。
- 逐步开放复杂系统。
- 逐步开放 `随机根脚 -> 重掷 -> 手选 -> 稀有根脚` 这条成长线。
- 鼓励多流派尝试。
- 控制永久数值膨胀。

核心限制：

```text
永久成长总收益 <= 300%
单局构筑收益 = 3000% - 5000%
```

## 2. Meta 模块

| 模块 | 作用 |
| --- | --- |
| 境界突破 | 解锁系统、上限和新地图 |
| 宗门建设 | 解锁功能建筑和局外便利 |
| 根脚与命盘 | 解锁手选根脚、改命上限和稀有根脚 |
| 传承道痕 | 解锁新的局外轻偏置 |
| 功法收藏 | 扩展初始候选池 |
| 法器祭炼 | 解锁法器图鉴、外观和少量整备便利 |
| 图鉴成长 | 提供轻量永久收益 |
| 成就系统 | 引导挑战和流派尝试 |
| 高难度阶层 | 提供长线挑战 |

## 5. 开局成长线

完整版本建议把开局自由度做成一条清晰的局外成长曲线：

### 5.1 前期

- 默认随机根脚
- 每局免费改命 1 次
- 可消耗 `改命签` 再重掷 1-2 次

### 5.2 中期

- 解锁手选普通根脚
- 解锁更多传承道痕
- 解锁更多启程线变体与首境图鉴

### 5.3 后期

- 解锁稀有根脚
- 解锁稀有启程线
- 解锁特殊命格或特殊传承道痕

设计意义：

- 新手先感受“这一世被命运推着走”；
- 老玩家再逐步获得“我开始学会逆天改命”的掌控感。

## 6. 局外收益类型

推荐收益优先级：

| 类型 | 推荐程度 | 示例 |
| --- | --- | --- |
| 解锁型 | 高 | 新根脚、新道痕、新卡牌候选、新事件 |
| 选择型 | 高 | 开局多一个候选、商店多一次刷新、启程多一次预览 |
| 便利型 | 中 | 图鉴显示弱点、路线预览 |
| 轻数值型 | 中 | 初始灵石 +10、初始生命 +5% |
| 强数值型 | 低 | 全局伤害 +20%，应严格限制 |

## 7. 永久成长上限

| 来源 | 收益上限 |
| --- | ---: |
| 境界 | 80% |
| 图鉴 | 50% |
| 成就 | 70% |
| 法器祭炼 / 收藏 | 50% |
| 宗门建设 | 50% |
| 总计 | <= 300% |

这里的收益包括生命、初始资源、初始金钱、商店折扣、候选数量、重掷便利等综合价值，不只是攻击倍率。

## 8. 成就系统

| 成就 | 条件 | 奖励方向 |
| --- | --- | --- |
| 万剑归宗 | 一场战斗中触发 100 次飞剑攻击 | 解锁剑修外观或候选卡 |
| 九霄雷动 | 单回合触发 20 次感电 | 解锁雷系法器 |
| 血海不灭 | 生命低于 10% 击败 Boss | 解锁血修事件 |
| 无伤渡劫 | 不受伤击败天劫 | 解锁高难度词条或稀有根脚 |
| 百法皆通 | 使用 10 种流派通关 | 解锁初始候选扩展 |

## 10. 局外与局内关系

| 局外提供 | 局内仍需完成 |
| --- | --- |
| 更多开局选择 | 仍需根据奖励构筑 |
| 轻量资源优势 | 仍需处理战斗压力 |
| 解锁高阶根脚和道痕 | 仍需通过功法 / 法器真正定道 |
| Boss 情报 | 仍需有对应 Build 应对 |

## 11. 设计底线

- Meta 不能让玩家忽略局内选择。
- 解锁比加数值更重要。
- 开局相关成长优先提供选择空间，不直接给终局强度。
- 宗门建设应服务玩法，不做纯装饰堆系统。
- 高难度应改变挑战结构，而不是只加血加攻。
