# Meta 成长体系

> Meta 成长负责局外长期目标。它可以提供解锁、选择空间和轻量收益，但不能压过单局构筑。

## 1. 设计目标

- 给玩家长期追求。
- 逐步开放复杂系统。
- 鼓励多流派尝试。
- 控制永久数值膨胀。

核心限制：

```text
永久成长总收益 <= 300%
单局构筑收益 = 3000% - 5000%
```

## 2. Meta 模块

| 模块 | 作用 |
| --- | --- |
| 境界突破 | 解锁系统、上限和新地图 |
| 宗门建设 | 解锁功能建筑和局外便利 |
| 功法收藏 | 扩展初始候选池 |
| 法宝养成 | 解锁初始法宝和外观 |
| 图鉴成长 | 提供轻量永久收益 |
| 成就系统 | 引导挑战和流派尝试 |
| 高难度阶层 | 提供长线挑战 |

## 3. 境界突破

| 境界 | 解锁内容 |
| --- | --- |
| 炼气 | 基础卡组、节点地图、普通战斗 |
| 筑基 | 第二法宝槽、精英节点 |
| 金丹 | 道纹系统、流派图鉴 |
| 元婴 | 分身机制、复活类奇遇 |
| 化神 | 法则卡牌、天道状态 |
| 炼虚 | 跨界历练、魔界地图 |
| 合体 | 双流派、混合道途 |
| 大乘 | 天劫玩法、高阶 Boss |
| 渡劫 | Ascension 难度、高阶词条 |
| 真仙 | 灵界、终局大道 |

## 4. 宗门建设

| 建筑 | 功能 |
| --- | --- |
| 藏经阁 | 解锁功法候选和功法升级 |
| 炼器阁 | 解锁法宝培养和法宝候选 |
| 丹房 | 解锁恢复、丹修路线和局外消耗品 |
| 试剑台 | 解锁战斗训练、流派挑战 |
| 天机阁 | 解锁图鉴、怪物弱点、因果路线 |
| 商会 | 解锁商店折扣和刷新 |

## 5. 局外收益类型

推荐收益优先级：

| 类型 | 推荐程度 | 示例 |
| --- | --- | --- |
| 解锁型 | 高 | 新卡牌候选、新法宝、新事件 |
| 选择型 | 高 | 开局多一个候选、商店多一次刷新 |
| 便利型 | 中 | 图鉴显示弱点、路线预览 |
| 轻数值型 | 中 | 初始灵石 +10、初始生命 +5% |
| 强数值型 | 低 | 全局伤害 +20%，应严格限制 |

## 6. 永久成长上限

| 来源 | 收益上限 |
| --- | ---: |
| 境界 | 80% |
| 图鉴 | 50% |
| 成就 | 70% |
| 法宝收藏 | 50% |
| 宗门建设 | 50% |
| 总计 | <= 300% |

这里的收益包括生命、初始资源、初始金钱、商店折扣、候选数量等综合价值，不只是攻击倍率。

## 7. 成就系统

| 成就 | 条件 | 奖励方向 |
| --- | --- | --- |
| 万剑归宗 | 一场战斗中触发 100 次飞剑攻击 | 解锁剑修外观或候选卡 |
| 九霄雷动 | 单回合触发 20 次感电 | 解锁雷系遗物 |
| 血海不灭 | 生命低于 10% 击败 Boss | 解锁血修事件 |
| 无伤渡劫 | 不受伤击败天劫 | 解锁高难度词条 |
| 百法皆通 | 使用 10 种流派通关 | 解锁初始候选扩展 |

## 9. 局外与局内关系

| 局外提供 | 局内仍需完成 |
| --- | --- |
| 更多初始选择 | 仍需根据奖励构筑 |
| 轻量资源优势 | 仍需处理战斗压力 |
| 解锁高阶内容 | 仍需满足掉落和成型条件 |
| Boss 情报 | 仍需有对应 Build 应对 |

## 10. 设计底线

- Meta 不能让玩家忽略局内选择。
- 解锁比加数值更重要。
- 宗门建设应服务玩法，不做纯装饰堆系统。
- 高难度应改变挑战结构，而不是只加血加攻。
- 玩家失败后也应获得少量进度，但不能奖励到鼓励故意失败。
