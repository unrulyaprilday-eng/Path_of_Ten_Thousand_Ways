# 经济体系

> 经济体系负责局内购买、局外成长和开局整备消耗。完整版本可以有多种资源，但第一原则仍然是控制理解成本，让玩家先看懂“这一世怎么起手”，再看懂“这一世怎么花钱修下去”。

## 1. 设计目标

- 资源种类少而清晰。
- 每种资源只承担 1-2 个核心用途。
- 局内资源服务构筑，局外资源服务解锁与选择空间。
- 开局相关消耗要有仪式感，但不能变成第四层资源门槛。

## 2. 资源总表

| 资源 | 类型 | 主要用途 | 获取来源 |
| --- | --- | --- | --- |
| 灵石 | 通用货币 | 商店购买、基础强化、事件支付 | 战斗、事件、结算 |
| 悟道石 | 强化资源 | 卡牌升级、功法升级、首层修炼强化 | 精英、Boss、修炼 |
| 改命签 | 开局资源 | 根脚重掷、少量启程刷新 | 结算、成就、命盘台 |
| 天材地宝 | 升阶资源 | 法器祭炼、功法升阶、境界突破 | 秘藏、Boss、局外玩法 |
| 天道本源 | 高阶资源 | 大道觉醒、终局成长 | 天劫、成就、高难度 |
| 功德 | 特殊资源 | 图鉴、善行系解锁、特殊宗门功能 | 特定事件、成就、善行路线 |

DEMO 阶段建议只开放：`灵石`、`悟道石`、`改命签`。

## 3. 局内经济

局内经济服务单局构筑。

| 消耗项 | 消耗资源 | 功能 |
| --- | --- | --- |
| 购买卡牌 | 灵石 | 补充主动手段 |
| 购买法器 | 灵石 | 补齐构筑核心 |
| 删除卡牌 | 灵石 | 压缩卡组 |
| 升级卡牌 | 灵石 / 悟道石 | 强化关键牌 |
| 功法参悟 | 悟道石 | 提升主修、辅修或神通效果 |
| 事件选择 | 灵石 / 生命 / 卡牌 | 代价换收益 |

### 3.1 商店价格建议

| 商品 | 基础价格 |
| --- | ---: |
| 普通卡牌 | 50 灵石 |
| 稀有卡牌 | 100 灵石 |
| 史诗卡牌 | 180 灵石 |
| 普通法器 | 120 灵石 |
| 稀有法器 | 220 灵石 |
| 史诗法器 | 380 灵石 |
| 删除卡牌 | 100 灵石，递增 50 |
| 升级卡牌 | 80 灵石或 1 悟道石 |
| 恢复生命 | 60 灵石 |

### 3.2 单局收入建议

| 来源 | 灵石 | 其他 |
| --- | ---: | --- |
| 普通战斗 | 30-50 | 小概率卡牌升级材料 |
| 精英战斗 | 60-90 | 1 件法器或 1 枚悟道石 |
| 事件 | -50 到 +120 | 视代价而定 |
| Boss | 120-180 | 悟道石、天材地宝 |
| 结算 | 按进度换算 | 修为、图鉴经验、少量改命签 |

## 4. 开局相关消耗

新开局结构的经济成本只允许落在“重掷”和“局外解锁”上，不允许把根脚、启程、启程信物拆成多个付费入口。

### 4.1 根脚重掷

| 项目 | 规则 |
| --- | --- |
| 免费改命 | 每局 1 次 |
| 额外改命 | 消耗 `改命签` 1 枚 |
| 单局额外改命上限 | 2 次 |
| 高阶解锁 | 可通过命盘台把普通根脚改为手选 |

### 4.2 启程刷新

| 项目 | 规则 |
| --- | --- |
| 默认启程候选 | 3 条 |
| 免费刷新来源 | 天机类传承道痕或宗门功能 |
| 额外刷新成本 | 1 枚改命签或等价命盘资源 |
| 设计底线 | 启程刷新不应比根脚重掷更常见 |

## 5. 局外经济

局外经济服务长期成长与新内容解锁。

| 消耗项 | 消耗资源 | 功能 |
| --- | --- | --- |
| 境界突破 | 修为、天材地宝 | 解锁系统和上限 |
| 根脚手选 | 改命签、功德 | 扩展开局选择权 |
| 传承道痕解锁 | 功德、天材地宝 | 扩展开局偏置池 |
| 法器祭炼 | 灵石、天材地宝 | 解锁法器外观、词缀分支 |
| 图鉴升级 | 图鉴经验、功德 | 提供轻量永久收益 |
| 大道觉醒 | 天道本源 | 开放终局规则 |

## 6. 资源控制规则

- 灵石是最常用货币，不能过度稀缺。
- 改命签必须有价值，但不应稀缺到玩家永远不敢用。
- 悟道石只投给真正关键的升级时点。
- 天材地宝与天道本源只服务中后期，不应污染首章体验。
- 同一阶段最多让玩家长期关注 2-3 种资源。

## 7. 永久成长限制

永久成长总收益建议不超过 300%。

| 来源 | 收益上限 |
| --- | ---: |
| 境界 | 80% |
| 图鉴 | 50% |
| 成就 | 70% |
| 法器收藏 / 祭炼 | 50% |
| 宗门建设 | 50% |

单局构筑收益应达到 3000%-5000%，确保肉鸽 Build 才是强度核心。

## 8. 设计底线

- 不为每个系统单独创造一种货币。
- 商店必须能帮助玩家修正构筑。
- 改命签应强化“逆天改命”的仪式感，而不是鼓励无限刷开局。
- 局外资源不能让玩家无视局内选择。
- 高阶资源必须有明确稀缺性和解锁门槛。
