# 经济体系

> 经济体系负责局内购买、局外成长和资源消耗。完整版本可以有多种资源，但第一原则是控制理解成本。

## 1. 设计目标

- 资源种类少而清晰。
- 每种资源有明确用途。
- 局内资源服务构筑，局外资源服务长期成长。
- 永久成长不能压过单局构筑收益。

## 2. 资源总表

| 资源 | 类型 | 主要用途 | 获取来源 |
| --- | --- | --- | --- |
| 灵石 | 通用货币 | 商店购买、基础强化、事件支付 | 战斗、事件、结算 |
| 悟道石 | 强化资源 | 卡牌升级、功法升级 | 精英、Boss、修炼 |
| 天材地宝 | 升阶资源 | 法宝、功法、卡牌升阶 | 秘境、Boss、局外玩法 |
| 天道本源 | 高阶资源 | 觉醒、大道、终局成长 | 天劫、成就、高难度 |
| 功德 | 特殊资源 | 图鉴、佛修、奖励加成 | 特定事件、善行路线 |

DEMO 阶段建议只开放：灵石、悟道石。

## 3. 局内经济

局内经济服务单局构筑。

| 消耗项 | 消耗资源 | 功能 |
| --- | --- | --- |
| 购买卡牌 | 灵石 | 补充主动手段 |
| 购买遗物 | 灵石 | 补齐构筑核心 |
| 删除卡牌 | 灵石 | 压缩卡组 |
| 升级卡牌 | 灵石 / 悟道石 | 强化关键牌 |
| 事件选择 | 灵石 / 生命 / 卡牌 | 代价换收益 |

## 4. 局外经济

局外经济服务长期成长。

| 消耗项 | 消耗资源 | 功能 |
| --- | --- | --- |
| 境界突破 | 修为、天材地宝 | 解锁系统和上限 |
| 功法解锁 | 悟道石、功德 | 扩展初始候选池 |
| 法宝培养 | 灵石、天材地宝 | 解锁法宝形态 |
| 图鉴升级 | 图鉴经验、功德 | 提供轻量永久收益 |
| 大道觉醒 | 天道本源 | 开放终局规则 |

| 史诗遗物 | 380 灵石 |

## 6. 单局收入建议

| 来源 | 灵石 | 其他 |
| --- | ---: | --- |
| 普通战斗 | 30-50 | 小概率卡牌升级材料 |
| 精英战斗 | 60-90 | 1 个遗物或悟道石 |
| 事件 | -50 到 +120 | 视代价而定 |
| Boss | 120-180 | 悟道石、天材地宝 |
| 结算 | 按进度换算 | 修为、图鉴经验 |

## 7. 资源控制规则

- 灵石是最常用货币，不能过度稀缺。
- 悟道石用于关键升级，投放要克制。
- 天材地宝只服务中后期升阶。
- 天道本源只服务高阶长期目标。
- 同一阶段最多让玩家关注 2-3 种资源。

## 8. 永久成长限制

永久成长总收益建议不超过 300%。

| 来源 | 收益上限 |
| --- | ---: |
| 境界 | 80% |
| 图鉴 | 50% |
| 成就 | 70% |
| 法宝收藏 | 50% |
| 宗门建设 | 50% |

单局构筑收益应达到 3000%-5000%，确保肉鸽 Build 才是强度核心。

## 9. 设计底线

- 不为每个系统单独创造一种货币。
- 商店必须能帮助玩家修正构筑。
- 删除卡牌要有价值，但不能廉价到无脑。
- 局外资源不能让玩家无视局内选择。
- 高阶资源必须有明确仪式感和稀缺性。
