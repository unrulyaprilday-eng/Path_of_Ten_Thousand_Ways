# 核心玩法与系统边界

> 本文定义一局游戏中的核心循环、玩家决策、系统分工和成长关系。当前 DEMO 的具体旅程与叙事见 `02_DEMO旅程地图与叙事.md`。

## 1. 核心玩法定义

游戏的核心不是“战斗后拿牌，再进入下一场战斗”，而是：

> 玩家在一次完整历练中，通过探索、修炼、战斗和因果选择，逐步获得并组织自己的心法、法诀、本命法器与道基规则。

卡牌构筑仍然存在，但前台语义统一为法诀构筑。每一张进入牌库的能力都应有来历、修炼方式和战斗意义。

## 2. 单局核心闭环

```text
故事开卷：确定身份并取得初始能力
↓
选择所往境域
↓
在持续地图中选择下一节点
↓
战斗 / 奇遇 / 修炼 / 洞府 / 秘藏
↓
获得法诀、心法进境、法器变化或具体因果
↓
构筑显化并改变后续候选、路线和战斗表现
↓
完成境界突破
↓
挑战阶段 Boss 与区域 Boss
↓
生成本局结局、见闻和局外解锁
```

节点结果完成后回到同一张地图继续推进，不再通过重复的“路线卡 -> 通用三选一 -> 确认”页面切割旅程。

## 3. 玩家决策层

| 决策层 | 发生位置 | 玩家实际决定什么 |
| --- | --- | --- |
| 身份与启程 | 开卷场景 | 接受何种来历、拿起什么、为何进入此境 |
| 路线 | 持续地图 | 选择稳险、能力来源、人物因果和隐藏方向 |
| 世界互动 | 奇遇、洞府、修炼、秘藏 | 帮助、拒绝、利用、炼化、参悟或承担代价 |
| 构筑 | 所得与修行 | 学什么法诀、如何升心法、怎样炼本命法器 |
| 突破 | 境界仪式 | 用本局实际取得的条件筑成何种道基 |
| 战斗 | 半实时斗法 | 何时出牌、保留多少灵力、锁定谁、何时爆发 |
| 因果 | 跨节点 | 如何对待具体人物、旧契、残魂和禁术 |

玩家不直接点击“选择万剑道”或“选择正邪”。道途由行为和构筑逐步显化。

## 4. 核心系统分工

| 系统 | 输入 | 输出 | 不承担的职责 |
| --- | --- | --- | --- |
| 根脚与开卷 | 身份、人物关系、旧事 | 叙事起点与轻量候选偏置 | 直接赠送完整流派 |
| 所携 / 本命法器 | 故事取得的初始器物 | 固定自动攻击与可成长器物核心 | 代替全部法诀或直接完成 Build |
| 心法 | 修炼经历、升阶条件 | 灵力循环、回复、阈值与一项心诀能力 | 作为普通攻击卡堆入牌库 |
| 法诀牌库 | 已悟剑诀、法术、身法、心诀、禁术 | 玩家主动介入战斗的低频决策 | 变成固定技能栏 |
| 其他法器 | 战斗、秘藏、祭炼与因果所得 | 自动触发、资源转化、规则放大或改写 | 建立法宝/遗物/道器三套前台分类 |
| 境界 | 修为、媒介、地点与因果条件 | 全局成长基准和新的道基规则 | 只增加攻击或生命 |
| 地图 | 境域骨架、种子、玩家状态、因果 | 合法可达节点和风险收益选择 | 用完全自由随机破坏叙事合理性 |
| 战斗 | 法诀、心法、法器、境界、敌人组合 | 胜负、损耗、故事推进条件 | 每战固定发一张牌 |
| 因果 | 具体人物与事件选择 | 后续事件、隐藏路线、Boss、结局变化 | 用一个善恶数值代替全部结果 |

## 5. DEMO 初始能力

当前 DEMO 开局只提供三项有故事来源的能力：

### 5.1 本命法器：残剑胚

- 按固定冷却自动攻击，是战斗持续演算的基础。
- 开局只表达一把残剑的速度、轨迹和命中，不预装飞剑增殖循环。
- 后续可以炼形、分化、附雷、入阵或承担其他规则变化。
- 本命法器是角色成长的一部分，不作为战后随机卡牌获得。

角色脚下的承载物与攻击中的飞剑数量是两个概念。角色可以脚踩承载类法器；没有承载法器时站在符合场景的断台、残梁、山石或地面上。脚下承载物不自动计入攻击飞剑数量。

### 5.2 初始心法

- 提供基础灵力获取、恢复或规则循环。
- 附带一个偏回复或规则型的心诀技能。
- 心法本体是常驻规则，心诀技能可以作为法诀进入牌库。
- 后续通过故事与修炼升至二阶、三阶，并在升阶时改变规则，而非只增加数值。

### 5.3 初始剑诀

- 提供最基础的主动攻击或催动本命法器能力。
- 首战让玩家看懂“法诀落子 -> 本命法器执行 -> 敌人受击”的关系。
- 它会随境界获得基础威力成长，也能在后续被补全、转式或与新法诀联动。

因此当前目标不是五张基础牌起手，而是以一项自动本命法器、一项心法规则和少量有来历的法诀建立最小可玩状态。最终牌库应保持小而有意义；精确张数属于 DEMO tuning，不在总规则中写死。

### 5.4 故事开局能力包

- 两门初始主动法诀必须由开局故事明确交付，不能由战斗系统按职业名硬塞进牌库。
- 当前剑修开局为：`旁支吐纳法`常驻生效并授予心诀`吐纳归息`，故事同时交付初阶剑诀`残卷御剑式`。
- 心法本体不是第三张主动牌；它是常驻循环规则，`吐纳归息`才是进入牌库的主动心诀。
- 开局能力包必须配置根本修行法、修行法授予的主动技能、初阶战技、本命器物、承载物和故事来源。
- 战斗内核不得写死“心法 + 剑诀”。未来炼体路线可以用“炼体术常驻规则 + 炼体主动技能 + 初阶拳法”替换，而不修改抽牌、灵气、目标和伤害接口。

## 6. 半实时斗法边界

战斗采用牌库驱动的半实时结构：

- 灵力按时间和心法规则持续获取。
- 本命法器按自身冷却自动攻击。
- 敌人按意图读条、技能冷却和阶段规则行动。
- 状态、飞剑和多数法器持续自动结算。
- 玩家从小型随机牌库中抽取法诀，在关键时机主动打出。
- 牌库、手牌、弃牌、洗牌、封存、消耗和冷却仍然影响决策，不能退化为固定按钮栏。

### 6.1 有限多敌人

- 普通战支持 1–3 名敌人，并分布在右上区域的不同纵深位置。
- 未锁定时，本命法器和飞剑自动攻击当前最高威胁目标。
- 玩家点击敌人即可切换锁定，不增加二次确认。
- 单体法诀优先作用于锁定目标；群攻、雷链和万剑效果自动扩散。
- 目标死亡后自动选择合法目标，不让自动攻击中断。
- 精英和小 Boss 可以携带召唤物或可攻击构造体；区域 Boss 的甲片、契钉与核心可以成为阶段目标。

### 6.2 系统控制层

| 控制层 | 频率 | 内容 |
| --- | --- | --- |
| 玩家决策层 | 低频 | 出牌、锁定、留灵力、选择爆发窗口 |
| 自动执行层 | 高频 | 本命法器、飞剑、法器、状态与敌人行动 |
| 构筑反馈层 | 跨战斗、跨节点 | 能力来源、心法升阶、法器炼化、境界和因果变化 |

设计底线：自动层必须让斗法持续发生，玩家层必须足以改变结果，两者都不能吞掉另一方的意义。

## 7. 构筑形成机制

### 7.1 道途显化

系统根据以下信息判断当前构筑方向：

- 已学法诀及其标签。
- 心法与升阶分支。
- 本命法器的炼化方向。
- 已获其他法器与状态循环。
- 境界突破时筑成的道基。
- 玩家在事件中采用的修炼方法与代价。

功法和道基负责真正定方向，法器负责放大和改写规则，法诀负责当下介入。根脚与初始器物只给出起势，不锁死终局。

### 7.2 启动、循环、收束

每套主要构筑至少要有三个职责席位：

```text
启动：第一次明确告诉玩家这局在修什么
↓
循环：让法诀、心法、本命法器或状态开始自动运转
↓
收束：在精英或 Boss 战形成可辨认的爆发方式
```

玩家获得其中两个关键职责时就应发生质变，不能等最后一件稀有奖励才开始好玩。高门槛构筑可以更依赖第三席位，但中途必须有清晰反馈。

### 7.3 构筑反馈

构筑变化必须同时反映在：

- 自动攻击的数量、冷却、轨迹或附带状态。
- 法诀牌面和实际演出。
- 角色周身、本命法器外观与承载物。
- 敌人受击、连锁、残留痕迹和死亡反馈。
- 地图候选、人物反应、隐藏路线和突破方式。

## 8. 心法、本命法器、法诀与境界的成长关系

| 成长线 | 主要改变 | 典型获得方式 |
| --- | --- | --- |
| 心法升阶 | 灵力循环、回复方式、资源转化和战斗节奏 | 找到下卷、得人指点、完成修炼或承担代价 |
| 本命法器炼化 | 自动攻击冷却、数量、轨迹、属性与规则 | 剑炉重炼、吞纳矿髓、温养、强炼或融合器物 |
| 法诀参悟 | 单项主动能力、牌库结构和具体联动 | 壁画、剑痕、残卷、残魂、秘境和战斗领悟 |
| 境界突破 | 灵力获取、全局威力、系统容量和道基规则 | 集齐条件后在合理地点完成突破仪式 |

境界可以直接强化剑诀，但分为两层：

1. 所有已学法诀按照境界获得基础威力成长，保证早期能力可持续使用。
2. 本局筑成的道基再给特定法诀、心法或本命法器增加规则变化。

当前 DEMO 讲述一次炼气到筑基的完整旅程。第一幕积累修为和线索，第二幕寻找筑基条件并在幕末完成突破，第三幕用新道基规则继续冒险并接受 Boss 检验。

## 9. 能力获取与奖励边界

能力主要从世界中获得：

- 在山洞剑痕中悟得新的攻击剑诀。
- 在青绿矿脉或雷痕秘境中悟得雷法或雷剑变化。
- 从旧账、残卷或他人传承中补全心法。
- 在剑炉或祭炼场景中改变本命法器。
- 从精英、小 Boss 和秘藏中取得高价值媒介或法器。
- 通过帮助、利用、超度、炼化或拒绝，换取不同能力与后续因果。

普通战主要承担风险、消耗、敌人信息和故事推进，不保证每战出现加牌奖励。需要展示所得时，应由具体物件、人物、场景或短演出承载，并允许玩家拒绝不适合的能力。

当前 DEMO 不使用通用货币和固定商店。修炼、奇遇、洞府和秘藏通过机会成本、气血、牌库变化、后续风险、具体物件或人物关系形成代价。

## 10. 成型保护

随机性不能破坏一局的基本成长承诺：

- 连续多个有效成长节点未出现当前主轴所需职责时，提高相关场景或能力权重。
- 每一幕至少存在一次可见的修炼、洞府或定向补缺机会，但玩家可以主动绕开。
- 关键主线能力和筑基基础方案不依赖单一随机事件。
- 已经拥有的能力不会重复发放失去价值的保底；应改为升级、转式或替代方向。
- 隐藏构筑可以因选择失败而关闭，但基础通关构筑不能因地图种子无解。

## 11. Boss 作为构筑检验

Boss 不是单纯增加生命和伤害的数值墙：

- 第一幕小 Boss 检验基础输出循环、生存与单一威胁处理。
- 第二幕小 Boss 检验有限多目标、引擎运转和突破前准备。
- 第三幕区域 Boss 检验筑基后的规则、目标切换、生存与爆发窗口。
- 隐藏 Boss 或阶段变化可以检验玩家此前承担的具体因果。

Boss 战必须给不同构筑留下合理的兑现方式，不要求只有某一张终结法诀才能通关。

## 12. 核心体验验收

一局成立时，玩家应能清楚感受到：

- 我知道这一世是谁、为何进入这处境域。
- 我的初始心法、本命法器和剑诀都来自故事。
- 战斗一直在发生，而我打出的法诀确实改变了目标、节奏或规则。
- 我在具体地点悟得了能力，而不是持续点击同一种奖励页。
- 第一幕开始起势，第二幕形成循环并完成筑基，第三幕使用新规则完成收束。
- 我的选择改变了人物、路线、Boss 或结局，而不只是改变一个善恶数字。
- 最终 Boss 检验了这一世修成的道。
