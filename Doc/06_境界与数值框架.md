## 2. 开局偏置预算

开局结构的新数值原则是：

> 道痕 < 根脚 < 启程线 < 功法 / 法器核心件

### 2.1 传承道痕预算

| 类型 | 建议上限 |
| --- | --- |
| 启程候选保证 | 多 1 个相关候选或 1 次免费刷新 |
| 节点权重修正 | 单类节点 +8% |
| 奖励标签修正 | 单标签 +10% |
| 资源修正 | 初始灵石 +15 或生命 +6 |
| 情报修正 | 额外预览 1 个候选或 1 个节点 |

### 2.2 根脚预算

| 维度 | 建议值 |
| --- | --- |
| 首层节点权重修正 | +4% 至 +8% |
| 奖励标签修正 | +6% 至 +10% |
| 初始资源修正 | +10 至 +20 灵石 |
| 首次候选修正 | 首次功法或法器额外 +1 候选 |

### 2.3 启程线预算

| 维度 | 建议值 |
| --- | --- |
| 首层节点主修正 | +12% |
| 首层节点副修正 | +6% |
| 主标签奖励修正 | +20% 至 +30% |
| 副标签奖励修正 | +8% 至 +15% |
| 启程信物强度 | 约等于 0.5 件普通法器或 1 张低费核心牌 |

设计底线：

- 根脚与道痕叠加后，不能直接取代前两层的构筑判断。
- 启程线是最强起手偏置，但仍不允许单独锁死终局流派。

## 8. 构筑倍率原则

完整版本中，强度来源的优先级应稳定维持为：

```text
单局构筑倍率 > 功法定道 > 法器放大 > 启程起势 > 局外永久成长
```

硬性控制：

- 永久成长总收益 <= 300%
- 单局完整构筑收益 = 3000% 至 5000%
- 开局偏置总价值通常不超过 1 件稀有法器

## 9. 核心公式

```text
卡牌价值 = 费用预算 × 品质系数 × 稀有度修正 × 机制系数
```

```text
首层节点最终权重
= 境域模板权重
× (1 + 根脚修正)
× (1 + 传承道痕修正)
× (1 + 启程线节点修正)
× (1 + 当前状态修正)
```

```text
奖励标签最终权重
= 基础标签权重
+ 根脚标签加值
+ 传承道痕标签加值
+ 启程线标签加值
+ 启程信物标签加值
+ 当前功法 / 法器 / 卡牌标签加值
+ 保底修正
```

```text
构筑倍率 > 永久成长倍率
```
