# 功法体系

> 功法是成长引擎，决定玩家一局中的长期规则和流派方向。卡牌负责即时操作，遗物负责局内规则强化，功法负责持续构筑路线。

## 1. 设计定位

功法不应只是属性加成，而应提供：

- 流派方向。
- 被动循环。
- 资源转化。
- 终局神通入口。
- 与法宝、状态、卡牌的联动规则。

## 2. 功法层级

| 层级 | 定位 | 示例作用 |
| --- | --- | --- |
| 外功 | 基础战斗技法 | 攻击、防御、抽牌、回能 |
| 内功 | 长期资源循环 | 灵气恢复、剑意成长、生命成长 |
| 神通 | 高阶主动或终结技 | 万剑齐发、九天神雷、大因果术 |
| 大道 | 终局规则修改 | 改写资源、胜利条件或战斗规则 |

## 3. 功法类型

| 类型 | 核心作用 | 示例 |
| --- | --- | --- |
| 剑诀 | 飞剑、剑意、多段攻击 | 御剑诀、万剑归宗 |
| 雷法 | 感电、暴击、连锁 | 九霄神雷诀、掌心雷经 |
| 火法 | 灼烧、AOE、爆炸 | 赤炎真诀、神火经 |
| 冰法 | 冰冻、控制、减速 | 玄冰诀、太阴寒经 |
| 血法 | 流血、自损、吸血 | 血煞经、天魔解体 |
| 丹法 | 回复、成长、炼化 | 青木长生诀、九转丹经 |
| 魂法 | 召唤、献祭、亡魂 | 九幽魂经、万魂录 |
| 器法 | 法宝、阵法、自动触发 | 百炼器诀、天工阵录 |
| 天道法 | 因果、功德、天劫 | 大因果术、天劫录 |

## 4. 功法槽位

| 槽位 | 数量 | 说明 |
| --- | ---: | --- |
| 主修功法 | 1 | 决定核心流派方向 |
| 辅修功法 | 2 | 补充联动和资源循环 |
| 神通 | 1-2 | 作为终结技或高阶爆发 |
| 大道 | 0-1 | 后期或特殊奇遇开放 |

DEMO 阶段建议只开放 1 个主修功法、1 个辅修功法、1 个神通。

## 5. 获取方式

| 来源 | 功法类型 |
| --- | --- |
| 开局选择 | 主修功法 |
| 洞府奇遇 | 稀有功法或辅修功法 |
| Boss 奖励 | 神通、大道残篇 |
| 商店 | 基础外功、功法残页 |
| 事件代价 | 魔道、禁术、天道功法 |
| 图鉴解锁 | 初始候选池扩展 |

## 6. 功法升级

功法升级采用残篇或悟道资源。

| 等级 | 效果 |
| --- | --- |
| 入门 | 解锁基础被动 |
| 小成 | 增强数值或触发概率 |
| 大成 | 新增联动规则 |
| 圆满 | 解锁神通强化 |
| 悟道 | 改变核心机制或开放大道 |

## 7. 功法冲突

部分功法不能无脑叠加，需要冲突规则控制复杂度。

| 冲突类型 | 示例 |
| --- | --- |
| 正魔冲突 | 正道功法与血祭禁术同时修炼会提高心魔概率 |
| 属性冲突 | 火法与冰法同时修炼时，部分状态互相抵消 |
| 资源冲突 | 剑意流和法力流争夺出牌资源 |
| 大道冲突 | 因果与天劫类大道不能同时圆满 |

冲突不一定禁止，也可以转化为风险收益路线。

## 8. 功法样例

| 功法 | 类型 | 稀有度 | 效果 |
| --- | --- | --- | --- |
| 御剑诀 | 剑诀 | 普通 | 每 3 次攻击获得 1 层剑意 |
| 万剑归宗 | 剑诀 / 神通 | 传说 | 消耗全部剑意，每 10 层生成 1 次飞剑攻击 |
| 九霄神雷诀 | 雷法 | 史诗 | 感电触发时有 25% 概率弹射 |
| 神火经 | 火法 | 史诗 | 灼烧造成伤害时，额外扩散 20% 层数 |
| 玄冰诀 | 冰法 | 稀有 | 冰冻值达到 100 后，目标受到伤害 +20% |
| 血煞经 | 血法 | 史诗 | 自身每损失 10% 生命，流血伤害 +15% |
| 青木长生诀 | 丹法 | 稀有 | 每获得 10 层丹意，恢复 5% 最大生命 |
| 九幽魂经 | 魂法 | 传说 | 召唤物死亡时，返还 1 点灵气 |
| 天工阵录 | 器法 | 史诗 | 法宝触发后，下一张法宝牌费用 -1 |
| 大因果术 | 天道法 | 神话 | 释放记录伤害，对目标造成等额因果伤害 |

## 9. 功法与其他系统关系

| 系统 | 关系 |
| --- | --- |
| 卡牌 | 功法改变卡牌效果、费用或触发条件 |
| 法宝 | 功法为法宝提供额外触发或复制 |
| 遗物 | 遗物强化功法循环或降低代价 |
| 状态 | 功法通常围绕某个核心状态建立 |
| 境界 | 高境界解锁神通、大道和双修空间 |

## 10. 设计底线

- 主修功法必须能定义一局方向。
- 神通必须有明显演出和终结感。
- 大道不能频繁出现，应作为稀有质变。
- 功法升级要优先解锁机制，不只是提高倍率。
- 禁术必须有代价，不能成为无脑最优解。
