# 功法体系

> 功法是成长引擎，决定玩家一局中的长期规则和流派方向。卡牌负责即时操作，法器负责局内规则强化，功法负责持续构筑路线。

## 1. 设计定位

功法不应只是属性加成，而应提供：

- 流派方向
- 被动循环
- 资源转化
- 终局神通入口
- 与法器、状态、卡牌的联动规则

## 2. 功法层级

| 层级 | 定位 | 示例作用 |
| --- | --- | --- |
| 外功 | 基础战斗技法 | 攻击、防御、抽牌、回能 |
| 内功 | 长期资源循环 | 灵气恢复、剑意成长、生命成长 |
| 神通 | 高阶主动或终结技 | 万剑齐发、九天神雷 |
| 大道 | 终局规则修改 | 改写资源、胜利条件、战斗规则 |

## 3. 功法类型

| 类型 | 核心作用 | 示例 |
| --- | --- | --- |
| 剑诀 | 飞剑、剑意、多段攻击 | 御剑诀、万剑归宗 |
| 雷法 | 感电、暴击、连锁 | 九霄神雷诀、掌心雷经 |
| 火法 | 灼烧、AOE、爆炸 | 赤炎真诀、神火经 |
| 血法 | 流血、自损、吸血 | 血煞经、天魔解体 |
| 丹法 | 回复、成长、炼化 | 青木长生诀 |
| 魂法 | 召唤、献祭、亡魂 | 九幽魂经 |
| 器法 | 法器、阵法、自动触发 | 天工阵录 |
| 天道法 | 因果、功德、天劫 | 大因果术 |

## 4. 功法槽位

| 槽位 | 数量 | 说明 |
| --- | ---: | --- |
| 主修功法 | 1 | 决定核心流派方向 |
| 辅修功法 | 2 | 补充联动和资源循环 |
| 神通 | 1-2 | 作为终结技或高阶爆发 |
| 大道 | 0-1 | 后期或特殊奇遇开放 |

## 5. 获取方式

| 来源 | 功法类型 |
| --- | --- |
| 启程线后续候选 | 起手主修倾向 |
| 洞府奇遇 | 稀有功法或辅修功法 |
| Boss 奖励 | 神通、大道残篇 |
| 商店 | 基础外功、功法残页 |
| 事件代价 | 魔道、禁术、天道功法 |

## 6. 与开局结构的关系

- 根脚和启程线负责起势，不直接代替功法定道。
- 功法是道途真正“成形”的关键环节。
- 启程线只负责让某类功法更容易在前两层出现。

## 7. 设计底线

- 主修功法必须能定义一局方向。
- 神通必须有明显演出和终结感。
- 功法升级要优先解锁机制，不只是提高倍率。
- 功法应是道途定向的第一责任人，不能被局外偏置或单件法器取代。
