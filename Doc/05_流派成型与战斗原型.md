# 流派成型与战斗原型

> 本文档关注“玩家如何在一局内形成流派”。战斗场景和演出规则见 `04_战斗场景规则设计.md`，数值预算见 `06-11` 数值圣经。

## 1. 原型验证目标

首个战斗原型需要验证：

- 玩家能通过低频出牌影响高频自动战斗。
- 飞剑、法宝、功法之间能形成可理解的联动。
- 中期前后能看出明确流派方向。
- 后期能出现清屏、秒 Boss 或规则质变。

## 2. 战斗控制结构

| 控制层 | 频率 | 内容 |
| --- | --- | --- |
| 玩家决策层 | 低频 | 出牌、激活法宝、释放终结技、选择战斗节奏 |
| 自动执行层 | 高频 | 飞剑攻击、Buff 触发、法宝联动、持续伤害 |
| 构筑反馈层 | 跨回合 | 状态积累、资源成长、联动倍率、奖励方向变化 |

## 3. 飞剑原型

飞剑是自动战斗单位，每把飞剑包含：

- 攻击频率。
- 属性。
- 行为 AI。
- 剑诀槽。
- 可被法宝或功法复制、强化、转化。

| 飞剑 | 行为方向 |
| --- | --- |
| 雷剑 | 弹射攻击，适配感电和暴击 |
| 火剑 | 持续灼烧，适配群体和追加伤害 |
| 冰剑 | 冻结控制，适配节奏压制 |
| 血剑 | 吸血成长，适配流血和魔念 |

## 4. 法宝原型

法宝负责改变战斗规则，而不是只提供属性。

| 法宝 | 原型效果 |
| --- | --- |
| 昊天镜 | 复制技能或飞剑攻击 |
| 紫金葫芦 | 吸收伤害并转化为资源 |
| 九龙鼎 | 持续炼化，强化灼烧或中毒 |
| 镇妖塔 | 控制压制，降低敌人行动频率 |

## 5. 三阶段构筑结构

### 5.1 种子期：1-2 层

目标：确定流派方向。

投放内容：

- 第一核心功法。
- 第一法宝。
- 第一流派倾向。

示例：

- 剑修：御剑诀。
- 法修：雷法初解。
- 魔修：血煞入体。

### 5.2 成型期：3-4 层

目标：构筑系统开始运转。

投放内容：

- 功法联动。
- 法宝组合。
- 卡牌升级。
- 状态资源循环。

成型标志：

- 飞剑数量明显增加。
- 雷法可以稳定连锁。
- 法宝能触发复制或转化。
- 玩家能说清“我这局在玩什么”。

### 5.3 爆发期：5 层以后

目标：构筑完成并形成质变。

投放内容：

- 核心遗物。
- 完整联动系统。
- 输出爆发机制。
- 终结技或规则修改效果。

爆发示例：

- 万剑齐发。
- 全屏雷暴。
- 无限复制镜像。
- 高风险血祭斩杀。

## 6. 流派形成机制

### 6.1 权重掉落

根据玩家当前选择提高对应奖励出现概率。

| 当前倾向 | 奖励池变化 |
| --- | --- |
| 剑修 | 剑系卡牌、剑意、飞剑法宝增加 |
| 雷修 | 雷法、感电、暴击组件增加 |
| 器修 | 法宝、复制、自动触发组件增加 |
| 魂修 | 召唤、献祭、亡魂组件增加 |

### 6.2 道途锁定

第 2 层必须选择道途，用于收束构筑方向。

首版道途：

- 剑道。
- 法道。
- 器道。
- 魂道。

### 6.3 同系倍率

同系组件达到数量阈值后触发新的规则。

| 条件 | 示例效果 |
| --- | --- |
| 3 张火系 | 灼烧扩散 |
| 5 张火系 | 全屏火海 |
| 3 个飞剑组件 | 飞剑数量 +1 |
| 5 个飞剑组件 | 开启剑阵 |

## 7. Boss 验证机制

| Boss 阶段 | 验证目标 |
| --- | --- |
| 中 Boss：妖王 | 是否有基础输出循环 |
| 后 Boss：魔尊 | 是否形成完整联动 |
| 终 Boss：天劫 | 是否达到流派上限并能承受压力 |

Boss 不只是数值墙，而是流派检测器。每个 Boss 至少应测试一种构筑能力，例如持续输出、爆发窗口、控制处理、资源管理或生存压力。

## 8. 成型失败保护

为了避免玩家整局拿不到核心组件，需要加入保护机制：

- 连续两层未出现当前道途奖励时，提高相关权重。
- 商店固定刷新至少一个当前道途商品。
- Boss 前提供一次修炼或补强节点。
- 事件可用代价换取核心方向组件。

## 9. 核心体验闭环

```text
选择道途
↓
构筑核心卡牌
↓
逐步强化联动
↓
流派成型
↓
进入爆发期
↓
击败 Boss
↓
完成一世修行
```

设计底线：

- 每局必须有方向。
- 中期必须能运转。
- 后期必须有爆发。
