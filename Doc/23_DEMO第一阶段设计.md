# DEMO 第一阶段设计

> 2026-07-14 执行锚点：本文定义当前 P0 纵切，覆盖旧的“启程线 / 启程信物 / 入首境”、规划执行回合和“凝剑诀在初始牌组”口径。开局配置契约详见 31_所携所往开局规则.md。

## 1. 核心目标

DEMO 只验证一句话：

> 玩家在 15-18 分钟内，以「世家旁支」身份携「残剑胚」进入「旧矿地窟」，从一把飞剑构筑到万剑齐发，并以本局形成的剑阵与爆发击碎天劫化身。

如果这一条不好玩，其他根脚、器物、地图、流派和局外数值成长全部暂缓。

## 3. 开局战力边界

开局只有：

- 1 把基础飞剑。
- 5 张基础牌：2 张剑气斩、2 张剑遁、1 张踏云遁。
- 初战 1 点灵气和 3 张起手牌。

开局没有：

- 凝剑诀。
- 主修、辅修和神通。
- 正式法器或独立遗珍。
- 小诛仙剑阵、万剑诀等收束牌。

凝剑诀只在首战固定三选一和后续保底中出现，任何旧文档或后备代码不得再把它加入残剑胚初始牌组。

## 4. 半实时战斗

战斗阶段只保留 Intro / Running / Won / Lost。

| 参数 | 初战 | 普通 / 精英 / Boss |
| --- | ---: | ---: |
| 初始灵气 | 1 | 2 |
| 灵气上限 | 10 | 10 |
| 回灵 | 每秒 1 | 每秒 1 |
| 初始手牌 | 3 | 4 |
| 手牌上限 | 7 | 7 |
| 自动抽牌 | 每 4 秒 1 张 | 每 4 秒 1 张 |
| 飞剑齐射 | 每 2.2 秒 | 每 2.2 秒 |
| 敌方意图 | 5-7 秒 | 精英更短；Boss 分阶段 |
| 临时飞剑 | 参与 3 次齐射后消散 | 同左 |

规则：

- 卡牌点击后立即结算并进入弃牌堆。
- 牌库为空时将弃牌洗回。
- 满手时抽牌计时暂停，不吞掉下一张牌。
- 敌人与飞剑持续行动，暂停和 1x / 2x 只改变时间速度。
- 所有“本回合 / 下回合 / 每回合”效果改写为时间窗、下一次齐射或每次洗牌触发。
- 胜利后保留约 1.2 秒破敌反馈，再自动进入战后所得。

时长目标：

| 战斗 | 目标 |
| --- | --- |
| 初战 | 30-45 秒 |
| 普通战 | 50-80 秒 |
| 精英 | 80-110 秒 |
| Boss | 150-210 秒 |

通过敌方生命、伤害和读条调整时长，不恢复固定回合结构。

## 5. 三层前路

### 第一层

| 前路 | 节点顺序 | 恢复 | 保证收益 |
| --- | --- | --- | --- |
| 稳定线 | 普通战 -> 修炼 | 有 | 标准奖励与启动补缺 |
| 冒险线 | 精英 -> 精英 | 无免费恢复 | 更早、更高品质奖励 |
| 构筑线 | 修炼 -> 整备 -> 普通战 | 仅配置明确恢复 | 定向补主轴缺口 |

### 第二层

| 前路 | 节点顺序 | 保证收益 |
| --- | --- | --- |
| 稳修 | 定向补缺 -> 普通战 | 小诛仙剑阵与标准生存 |
| 追锋 | 精英 -> 精英 | 更快获得高品质引擎 |
| 秘器 | 核心整备 -> 精英 | 御剑诀或剑匣缺口 |

### 第三层

| 前路 | 节点顺序 | 保证收益 |
| --- | --- | --- |
| 整备冲劫 | 整备 -> Boss | 万剑诀、生存保底与恢复 |
| 闭关悟道 | 终结补强 -> 整备 -> Boss | 万剑诀与 Boss 前整备 |
| 背水破劫 | 精英高奖 -> Boss | 万剑诀；可额外获得万剑归宗 |

每场战斗胜利都进入战后所得，地图不再额外插入通用奖励节点。精英战使用更高奖励档位。

## 6. 强制成长门槛

| 阶段 | 必须成立 |
| --- | --- |
| 初战前 | 1 把飞剑、5 张基础牌；无主修、正式法器、遗珍或终结牌 |
| 首战所得 | 固定「凝剑诀 / 踏云遁 / 聚灵换息」 |
| 第一层末 | 启动牌与至少 2-3 个万剑组件；不出现神通和终结牌 |
| 第二层 | 必有小诛仙剑阵，并有御剑诀或剑匣至少一个 |
| 第三层 | 必出现万剑诀；高风险路线可额外出现万剑归宗 |
| Boss | 飞剑增殖、剑意积累、剑阵运转与一次明显爆发全部可见 |

连续两次奖励未出现主轴组件后，下一次 Focus 槽触发保底。

## 7. 奖励三槽

每次战后所得固定三槽：

| 槽位 | 作用 |
| --- | --- |
| 当前主轴 | 补飞剑、剑意、剑阵、主修或收束缺口 |
| 生存资源 | 补防御、恢复、灵气或牌库循环 |
| 高波动 | 提供高品质、法器、路线风险专属或通用回退 |

P0 前台奖励只允许卡牌、功法、法器和资源。旧 Relic 数据仅保留兼容，不进入奖励池或独立展示。

奖励上下文必须包含层数、来源、风险、已有组件、生命状态、连续未出主轴次数和固定随机种子。

## 8. Boss 设计

天劫化身三阶段：

| 阶段 | 机制 |
| --- | --- |
| 雷云压境 | 稳定压血并施加轻度感电 |
| 天雷锁魂 | 提高伤害并短暂压制灵气恢复 |
| 天劫降临 | 先蓄雷，再进入 3.5 秒短读条重击；这是主要爆发窗口 |

Boss 目标生命为 3800。标准稳定路线的代表万剑构筑必须在 150-210 秒内完成战斗，高风险额外万剑归宗可以明显加速，但不能成为通关必需。

## 9. 页面职责

- 战后所得：先看得到什么、规则如何改变、距当前构筑里程碑还差什么。
- 择前路：固定展示节点顺序、战斗等级、恢复机会和保证收益，不使用“更快成型”等模糊描述。
- 修炼：强调定向补缺和恢复。
- 整备：强调当前核心缺口与 Boss 前生存。
- 战斗前情：说明此处敌人、风险和奖励档位。
- 全局摘要：只保留生命、牌组数、主修、核心法器和当前里程碑。
- 一世结算：展示抵达层数、核心组件、最大飞剑、最高爆发、Boss 结果和新解锁。

## 10. 局外闭环

DemoMetaProgress 使用版本化持久化，只保存：

- 完成局数和 Boss 胜利数。
- 卡牌、功法、法器图鉴记录。
- 解锁 ID。

不保存局内战力，不做中途存档。

首次击败天劫解锁残剑道痕。下一世在开卷整备时可选择携带，使首战奖励获得一次重铸机会。重铸只改变候选，不增加永久攻击、生命、飞剑或灵气。

## 11. 数据与实现契约

- 新器物语义使用 DemoJourneyVesselDefinition、OpeningSelection.Vessel 和 SetVessel。
- 旧 JourneyLine 字段只用于配置读取和存量代码兼容。
- DemoMapNode 必须有稳定 node_id；战斗节点必须有 encounter_id 与 reward_profile_id；职责节点必须有 action_profile_id。
- 敌人、奖励和行为不得通过中文名或 Contains 判断。
- 所有路线、敌人、奖励档位、器物和区域引用必须通过配置校验。

## 12. 验收标准

必须通过：

- 半实时回灵、抽牌、满手暂停、洗牌、即时出牌、飞剑周期、临时剑三次消耗、敌方意图和 Boss 阶段测试。
- 固定随机种子验证第一层无终结、第二层必有剑阵与引擎、第三层必有万剑诀，高风险可有万剑归宗。
- 所携筛选、未开放地图不可进入、逐战奖励、完整三层路线、胜负结算和 Meta 解锁读写。
- 标准路线 Boss 确定性模拟落在目标时长，并出现明显飞剑规模和单次爆发。
- dotnet build 零警告零错误、完整烟测、git diff --check 和 Unity 日志异常扫描。
- 实际查看 1920×1080 连续截图，并对战斗、奖励、路线补测 1280×720；灰屏或只渲染顶部直接失败。

不通过：

- 仍可进入未完成的器物或地图。
- 战斗退回规划 / 执行固定回合。
- 首战前获得凝剑诀、主修、正式法器或终结牌。
- 第二层结束仍缺剑阵或引擎。
- 战斗胜利后没有奖励，或必须点击额外结算按钮。
- 结算页不展示构筑指标，或道痕继承局内战力。
