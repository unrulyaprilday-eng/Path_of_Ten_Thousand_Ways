# DEMO 第一阶段设计

> 本文档是在完整设计基础上做减法，定义第一阶段只做什么。目标不是展示所有系统，而是验证核心爽点是否成立。

## 1. DEMO 核心目标

DEMO 只验证一句话：

> 玩家在 15-20 分钟内，从一把飞剑修到万剑齐发，靠法宝和功法联动击碎天劫。

如果这件事不好玩，其他长期系统暂不开发。

## 2. DEMO 设计原则

- 只做一个主道途。
- 只做一个核心战斗闭环。
- 只做能支撑飞剑爽点的系统。
- 所有系统必须服务 Build 成型。
- 不做完整局外养成。

## 3. 保留系统

| 系统 | DEMO 范围 |
| --- | --- |
| 节点地图 | 3 层小地图 |
| 战斗系统 | 半即时规划 + 执行 |
| 卡牌系统 | 抽牌、费用、出牌、弃牌 |
| 飞剑系统 | 自动攻击、数量成长、属性变化 |
| 法宝系统 | 4 个法宝，提供规则变化 |
| 功法系统 | 1 主修、1 辅修、1 神通 |
| 遗物系统 | 10 个遗物 |
| 状态系统 | 剑意、感电、灼烧、流血 |
| Boss | 1 个终局 Boss：天劫化身 |
| 商店 | 购买、升级、删除 |

## 4. 暂缓系统

| 系统 | 暂缓原因 |
| --- | --- |
| 宗门建设 | 不影响核心战斗验证 |
| NPC 关系 | 制作成本高，首版收益低 |
| 多境界完整成长 | 容易稀释单局构筑 |
| 灵界 / 魔界 / DLC | 属于长期内容 |
| 图鉴深度成长 | DEMO 只保留基础记录 |
| 多职业全量道统 | 先验证剑修是否成立 |
| 装备系统 | 与法宝、遗物职责重叠 |
| 商业化系统 | DEMO 阶段不考虑 |
| 大道系统 | 复杂度高，留到后期 |
| Ascension 难度 | 等基础循环稳定后再做 |

## 5. DEMO 主流派

只做剑修，并拆成 3 个方向。

| 流派 | 核心状态 | 玩法 |
| --- | --- | --- |
| 万剑流 | 剑意 | 增加飞剑数量和攻击频率 |
| 雷剑流 | 感电 | 飞剑多段攻击触发连锁雷击 |
| 血剑流 | 流血 | 叠流血、吸血、压血爆发 |

火剑可作为过渡组件存在，但不作为完整流派展开。

## 7. DEMO 单局流程

```text
开局选择剑修方向
↓
第 1 层：获得第一批飞剑组件
↓
第 2 层：选择法宝或核心功法，流派开始成型
↓
第 3 层：获得神通或质变遗物
↓
挑战天劫化身
↓
结算展示本局修成的道
```

## 8. DEMO 地图结构

| 层数 | 节点数 | 目标 |
| --- | ---: | --- |
| 第 1 层 | 4-5 | 选择方向 |
| 第 2 层 | 5-6 | 形成联动 |
| 第 3 层 | 4-5 | 补强并进入 Boss |

每层至少包含：

- 1 个普通战斗。
- 1 个奖励节点。
- 1 个路线选择。

Boss 前必须提供：

- 1 次商店或修炼。
- 1 次核心补强机会。

## 12. 天劫 Boss 设计目标

天劫化身要验证：

- 玩家是否有稳定输出循环。
- 玩家是否有爆发窗口。
- 玩家是否能处理生存压力。
- 玩家是否完成了至少一个流派方向。

Boss 三阶段：

| 阶段 | 机制 |
| --- | --- |
| 雷云压境 | 周期性伤害，测试基础防御 |
| 天雷锁魂 | 给玩家施加感电压力，测试资源管理 |
| 天劫降临 | 限时爆发窗口，测试神通和 Build 上限 |

## 13. DEMO 验收标准

DEMO 成立的标准：

- 新玩家 3 分钟内理解出牌和飞剑攻击。
- 10 分钟内能看出自己正在形成哪种剑修流派。
- 至少一次出现“飞剑满屏”或“神通清场”的爽点。
- Boss 战能明显检验构筑，而不是单纯数值战。
- 玩家失败后愿意立刻再开一局。

## 14. 不通过标准

出现以下情况说明 DEMO 需要回炉：

- 飞剑自动攻击存在感弱。
- 卡牌选择只是加伤害，没有联动。
- 三个流派玩起来差异不明显。
- Boss 只是血厚。
- 玩家不知道自己为什么赢或为什么输。
- 单局 20 分钟内没有爆发点。

## 15. 后续扩展顺序

DEMO 成立后再按顺序扩展：

1. 增加法修：雷法、火法、冰法。
2. 增加器修：法宝连锁和阵法。
3. 增加魂修：召唤和献祭。
4. 增加局外境界与宗门。
5. 增加图鉴、成就和高难度。
