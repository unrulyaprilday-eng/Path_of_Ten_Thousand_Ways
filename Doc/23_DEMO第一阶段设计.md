# DEMO 第一阶段设计

> 本文档是在完整设计基础上做减法，定义第一阶段只做什么。目标不是展示所有系统，而是验证核心爽点是否成立；它缩的是内容量，不改“根脚 -> 启程 -> 历练”的世界观入口。

## 1. DEMO 核心目标

DEMO 只验证一句话：

> 玩家在 15-20 分钟内，从一把飞剑修到万剑齐发，靠法器和功法联动击碎天劫。

如果这件事不好玩，其他长期系统暂不开发。

## 2. DEMO 设计原则

- 只做一个主道途。
- 只做一个核心战斗闭环。
- 只做能支撑飞剑爽点的系统。
- 所有系统必须服务 Build 成型。
- 不做完整局外养成。

## 3. 保留系统

| 系统 | DEMO 范围 |
| --- | --- |
| 开局结构 | 3-4 个根脚、6-9 条启程线、3 个首境模板 |
| 节点地图 | 3 层小地图 |
| 战斗系统 | 半即时规划 + 执行 |
| 卡牌系统 | 抽牌、费用、出牌、弃牌 |
| 飞剑系统 | 自动攻击、数量成长、属性变化 |
| 法器系统 | 12-14 件法器，覆盖启动、引擎、爆发与通用补强 |
| 功法系统 | 1 主修、1 辅修、1 神通 |
| 状态系统 | 剑意、感电、灼烧、流血 |
| Boss | 1 个终局 Boss：天劫化身 |
| 商店 | 购买、升级、删除 |

## 4. 暂缓系统

| 系统 | 暂缓原因 |
| --- | --- |
| 宗门建设 | 不影响核心战斗验证 |
| NPC 关系 | 制作成本高，首版收益低 |
| 多境界完整成长 | 容易稀释单局构筑 |
| 灵界 / 魔界 / DLC | 属于长期内容 |
| 图鉴深度成长 | DEMO 只保留基础记录 |
| 多职业全量道统 | 先验证剑修是否成立 |
| 装备系统 | 与法器职责重叠 |
| 商业化系统 | DEMO 阶段不考虑 |
| 大道系统 | 复杂度高，留到后期 |
| Ascension 难度 | 等基础循环稳定后再做 |

补充说明：

- 这里的“商业化系统”指付费、商店、发行与长期运营系统，不等于“商业化展示级 UI 卖相”。
- 只要某项界面或视觉资源直接影响玩家对玩法、流派、战斗反馈和门面气质的判断，就属于 DEMO 当前范围，应及时制作并接入。

## 5. DEMO 主流派

只做剑修，并拆成 3 个方向。

| 流派 | 核心状态 | 玩法 |
| --- | --- | --- |
| 万剑流 | 剑意 | 增加飞剑数量和攻击频率 |
| 雷剑流 | 感电 | 飞剑多段攻击触发连锁雷击 |
| 血剑流 | 流血 | 叠流血、吸血、压血爆发 |

火剑可作为过渡组件存在，但不作为完整流派展开。

具体到每条道途的终局套路、Key 牌席位和减法顺序，见 `24_DEMO构筑细化与减法锚点.md`。
具体到基础动作、首战第一回合和普通飞剑表现规格，见 `25_DEMO基础动作表现与首战节奏.md`。

## 7. DEMO 单局流程

```text
首页整备传承道痕（首版可默认装备）
↓
定根脚
↓
选择启程线
↓
第 1 层：获得第一批飞剑组件
↓
第 2 层：获得关键法器或核心功法，流派开始成型
↓
第 3 层：获得神通或质变法器
↓
挑战天劫化身
↓
结算展示本局修成的道
```

## 8. DEMO 地图结构

| 层数 | 节点数 | 目标 |
| --- | ---: | --- |
| 第 1 层 | 4-5 | 选择方向 |
| 第 2 层 | 5-6 | 形成联动 |
| 第 3 层 | 4-5 | 补强并进入 Boss |

每层至少包含：

- 1 个普通战斗。
- 1 个奖励节点。
- 1 个路线选择。

Boss 前必须提供：

- 1 次商店或修炼。
- 1 次核心补强机会。

## 10. DEMO 开局入口

DEMO 虽然只做剑道，但入口不再使用“直接选剑修方向”的旧结构。

建议保留最小开局骨架：

- `根脚`：至少 3 个，建立身份感
- `启程线`：每个根脚至少 2-3 条，明确来历、携行之物与首境
- `首境`：至少 3 个，支撑万剑 / 雷剑 / 血剑的起势差异

DEMO 中的三种方向处理为：

- 不是首页直接选择“万剑 / 雷剑 / 血剑”
- 而是通过不同启程线和携行之物，让这三种方向更容易在前两层显化

## 12. 天劫 Boss 设计目标

天劫化身要验证：

- 玩家是否有稳定输出循环。
- 玩家是否有爆发窗口。
- 玩家是否能处理生存压力。
- 玩家是否完成了至少一个流派方向。

Boss 三阶段：

| 阶段 | 机制 |
| --- | --- |
| 雷云压境 | 周期性伤害，测试基础防御 |
| 天雷锁魂 | 给玩家施加感电压力，测试资源管理 |
| 天劫降临 | 限时爆发窗口，测试神通和 Build 上限 |

## 13. DEMO 验收标准

DEMO 成立的标准：

- 新玩家 3 分钟内理解出牌和飞剑攻击。
- 10 分钟内能看出自己正在形成哪种剑修流派。
- 至少一次出现“飞剑满屏”或“神通清场”的爽点。
- Boss 战能明显检验构筑，而不是单纯数值战。
- 玩家失败后愿意立刻再开一局。

## 14. 不通过标准

出现以下情况说明 DEMO 需要回炉：

- 飞剑自动攻击存在感弱。
- 卡牌选择只是加伤害，没有联动。
- 三个流派玩起来差异不明显。
- Boss 只是血厚。
- 玩家不知道自己为什么赢或为什么输。
- 单局 20 分钟内没有爆发点。

## 15. 后续扩展顺序

DEMO 成立后再按顺序扩展：

1. 增加法修：雷法、火法、冰法。
2. 增加器修：法器连锁和阵法。
3. 增加魂修：召唤和献祭。
4. 增加局外境界与宗门。
5. 增加图鉴、成就和高难度。
