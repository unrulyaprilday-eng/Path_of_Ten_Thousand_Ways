# DEMO 第一阶段设计

> 本文档定义当前 DEMO 第一阶段的执行范围。目标不是先铺满完整系统，而是先把一条纵切做完整：玩家从一个根脚出发，选择启程线与启程信物，踏入第一张大地图，在牌库驱动的半实时斗法中完成一次构筑成型与 Boss 检验。

## 1. DEMO 核心目标

DEMO 只验证一句话：

> 玩家在 15-20 分钟内，以「世家旁支」身份入旧矿地窟，从一把飞剑修到万剑齐发，靠卡牌、功法与法器联动击碎天劫。

如果这件事不好玩，其他根脚、首境、局外成长和长期内容都暂缓。

## 2. 当前纵切范围

第一阶段先做完整纵切，而不是平均铺内容。

| 模块 | 当前范围 | 处理方式 |
| --- | --- | --- |
| 根脚入口 | 入口完整 | 其他根脚可展示为 `命数未显` / `未开放` |
| 可完整游玩的根脚 | 1 个：世家旁支 | 做完身份、启程线、信物、首境衔接 |
| 启程线 | 3 条 | 同属世家旁支，各自绑定一个启程信物 |
| 首境 / 大地图 | 1 张：旧矿地窟 | 做完 3 层节点、路线、奖励、Boss 前整备 |
| 战斗系统 | 牌库驱动半实时斗法 | 灵气持续增长，卡牌低频介入，飞剑自动演算 |
| 主爽点 | 飞剑增殖 -> 剑意叠加 -> 万剑爆发 | 先保证万剑方向成立 |
| Boss | 天劫化身 | 用于检验输出循环、生存压力和爆发窗口 |

后续扩展根脚时，也按同样结构补：

```text
根脚
↓
3 条启程线
↓
3 个启程信物
↓
1-3 个合理首境去向
↓
至少 1 张完整大地图纵切
```

## 3. DEMO 开局链路

当前前台链路固定为：

```text
开卷（启动页）
↓
定根脚
↓
受信物
↓
入首境
↓
择前路
↓
战斗 / 节点历练
```

页面职责：

| 页面 | 回答的问题 | 当前规则 |
| --- | --- | --- |
| 开卷 | 要不要新开一世 | 首页按正式门面标准制作，技术上对应启动页 |
| 定根脚 | 我这一世是谁 | 首版只开放世家旁支，其他根脚展示为未显化 |
| 受信物 | 我为何出山，承了什么信物 | 根据根脚展示 3 条启程线，每条线有一个启程信物 |
| 入首境 | 这件事把我引向哪里 | 首版完整开放旧矿地窟 |
| 择前路 | 我在这里先走哪段历练 | 展示 2-4 条节点路线，重点是节点顺序和风险收益 |

`携行之物` 不再作为前台页面名。前台统一称为 `启程信物`，页面名用 `受信物`，表达“临行承下的物件”和“本局第一推力”。

## 4. 世家旁支纵切

### 4.1 根脚定位

世家旁支回答的是：

> 你不是天命继承人，也不是散修无根之人。你知道家族规矩，也知道自己随时可能被推出去偿还旧债。

它适合连接：

- 祠堂旧事
- 族中旧债
- 祖龛残匣
- 矿契与旧矿地窟
- 护身玉、符匣、封存器物

### 4.2 三条启程线

| 启程线 | 启程信物 | 出山理由 | 起势方向 |
| --- | --- | --- | --- |
| 祠堂夜雨 | 护身旧玉 | 族中大乱后，叔父把旧玉塞进你袖中，让你连夜离开 | 稳定、防御、剑意起势 |
| 灰烬符匣 | 余烬符匣 | 旧宅焚毁后，你从灰里捡出一只仍有余温的符匣 | 爆发、灼烧 / 雷痕、风险收益 |
| 祖龛残匣 | 祖龛残匣 | 祖龛塌落时，只有这只封死的小匣没有碎 | 秘藏、法器、飞剑组件 |

说明：

- 玩家在 `启程` 页实际选择的是启程线。
- 视觉焦点可以放在启程信物上，但不要把它做成脱离故事的独立物品池。
- 同一根脚下的三条线必须像三种命运，而不是同一个物品换三个数值。

### 4.3 入旧矿地窟

旧矿地窟是第一张完整大地图，原因：

- 和世家旁支的族债、矿契、祖物都容易衔接。
- 战斗、秘藏、法器、飞剑残胚都能自然出现。
- 能快速推动飞剑构筑成型，适合 DEMO 验证爽点。

入首境页只需极短说明，例如：

```text
旧矿地窟
铁屑、尘灰和失踪传闻一起埋在地底。
这里更容易出现：战斗、秘藏、飞剑组件、法器线索。
```

## 5. 大地图结构

旧矿地窟按 3 层推进：

| 层数 | 节点数 | 目标 |
| --- | ---: | --- |
| 第 1 层 | 4-5 | 建立起势，拿到第一批飞剑组件 |
| 第 2 层 | 5-6 | 获得关键法器或核心功法，流派开始运转 |
| 第 3 层 | 4-5 | 补强、压缩、获得神通或爆发件，准备 Boss |

每层至少包含：

- 1 个普通战斗。
- 1 个奖励或补强节点。
- 1 次路线选择。

Boss 前必须提供：

- 1 次商店或修炼。
- 1 次核心补强机会。
- 1 次让玩家确认当前构筑方向的摘要反馈。

## 6. 择前路规则

择前路页表达“接下来怎么走”，不是重选流派。

前路卡应展示：

- 前路名或短标签。
- 2-4 个节点顺序图标。
- 压力取舍：稳 / 险 / 构筑 / 资源。
- 收益重点：卡牌、法器、功法、修炼、秘藏。

示例：

| 路线 | 节点顺序 | 节奏 |
| --- | --- | --- |
| 矿口余烬 | 普通战斗 -> 奖励 -> 修炼 | 稳，适合先拿飞剑组件 |
| 塌井深处 | 精英战斗 -> 秘藏 -> 普通战斗 | 险，适合赌早期法器 |
| 旧账暗室 | 事件 -> 洞府 -> 战斗 | 偏构筑，可能更早拿功法 |

## 7. 战斗系统范围

当前战斗主定义：

> 牌库驱动的半实时斗法。

第一阶段必须验证：

- 灵气持续增长，而不是固定回合恢复。
- 飞剑、敌人、法器、功法持续自动演算。
- 玩家通过手牌低频打出关键牌，改变演算方向。
- 卡牌仍保留牌库、抽牌、手牌、弃牌、洗牌和构筑随机性。
- 卡牌不是固定技能栏，法器和功法也不能全部变成主动技能按钮。

推荐首版手感：

| 项目 | DEMO 建议 |
| --- | --- |
| 初始手牌 | 4-5 张 |
| 手牌上限 | 7-8 张 |
| 灵气 | 持续增长，有上限 |
| 抽牌 | 按时间、出牌效果或功法触发 |
| 卡牌费用 | 消耗灵气 |
| 卡牌冷却 | 用于限制同名牌 / 强牌连续释放，可与弃牌区结合 |
| 法器 | 多数自动触发，少数主动法器带冷却和灵气消耗 |
| 功法 | 主要提供长期循环、触发规则和神通入口 |

## 8. DEMO 内容数量

当前纵切建议量：

| 内容 | 数量 | 说明 |
| --- | ---: | --- |
| 可完整根脚 | 1 | 世家旁支 |
| 根脚入口展示 | 3-4 | 其他根脚未开放也要露出系统入口 |
| 启程线 | 3 | 世家旁支专用 |
| 启程信物 | 3 | 护身旧玉、余烬符匣、祖龛残匣 |
| 大地图 | 1 | 旧矿地窟 |
| 路线模板 | 6-9 | 支撑 3 层路线选择 |
| 卡牌 | 20-30 | 优先服务飞剑、剑意、资源、防御、爆发 |
| 法器 | 8-12 | 至少 3 个能明显改变规则 |
| 功法 | 4-6 | 至少 1 主修、1 辅修、1 神通完整可玩 |
| 普通敌人 | 4-6 | 教学和节奏变化 |
| 精英敌人 | 2-3 | 检验构筑 |
| Boss | 1 | 天劫化身 |
| 事件 | 6-10 | 代价选择和补强 |
| 商店商品池 | 12-20 | 卡牌、法器、升级、删除 |

## 9. 主爽点

第一条必须打磨完整的爽点：

```text
飞剑增殖
↓
剑意叠加
↓
功法 / 法器开始响应
↓
万剑爆发
↓
Boss 或精英被一轮打穿
```

成立标准：

- 普通飞剑自动攻击有存在感。
- 玩家能看到每张牌如何推动飞剑数量、频率或剑意。
- 至少一次出现“飞剑满屏”或“万剑齐发”的视觉峰值。
- 爆发不是单张牌孤立伤害，而是前面构筑积累的结果。

## 10. 天劫 Boss 设计目标

天劫化身要验证：

- 玩家是否有稳定输出循环。
- 玩家是否有爆发窗口。
- 玩家是否能处理生存压力。
- 玩家是否完成了至少一个飞剑构筑方向。

Boss 三阶段：

| 阶段 | 机制 |
| --- | --- |
| 雷云压境 | 周期性伤害和预警读条，测试基础防御 |
| 天雷锁魂 | 施加感电 / 压力状态，测试资源管理 |
| 天劫降临 | 开出爆发窗口，测试神通和 Build 上限 |

## 11. 验收标准

DEMO 成立的标准：

- 新玩家 3 分钟内理解灵气增长、抽牌、出牌和飞剑自动攻击。
- 玩家能说清自己是世家旁支，因哪条启程线带着什么信物入旧矿。
- 10 分钟内能看出自己正在形成飞剑 / 剑意相关构筑。
- 至少一次出现“飞剑满屏”或“神通清场”的爽点。
- Boss 战能明显检验构筑，而不是单纯数值战。
- 玩家失败后愿意立刻再开一局。

不通过标准：

- 根脚、启程信物和旧矿地窟之间像三张无关菜单。
- 卡牌像固定技能栏，牌库构筑感消失。
- 灵气持续增长后，玩家只是在等 CD，没有抽牌和取舍。
- 飞剑自动攻击存在感弱。
- Boss 只是血厚。
- 单局 20 分钟内没有爆发点。

## 12. 后续扩展顺序

当前纵切成立后再按顺序扩展：

1. 补其他根脚的 3 条启程线。
2. 补其他首境或后续境域分支。
3. 补雷剑、血剑的完整纵切构筑。
4. 扩展局外传承道痕和图鉴。
5. 增加新道统、新 Boss 和高难度。
