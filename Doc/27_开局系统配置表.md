## 11. 开局综合公式

### 11.1 首层节点权重

```text
首层节点最终权重
= 境域模板权重
× (1 + 根脚修正)
× (1 + 传承道痕修正)
× (1 + 启程线节点修正)
× (1 + 当前状态修正)
```

### 11.2 奖励标签权重

```text
奖励标签最终权重
= 基础标签权重
+ 根脚标签加值
+ 传承道痕标签加值
+ 启程线标签加值
+ 携行之物标签加值
+ 当前功法 / 法器 / 卡牌标签加值
+ 保底修正
```

### 11.3 道途显化阈值

| 阈值 | 结果 |
| --- | --- |
| 40 | 起势提示出现 |
| 70 | 奖励池开始明显倾斜 |
| 100 | 进入定道状态 |

## 12. 前台展示建议

前台尽量只暴露以下几类信息：

- 根脚
- 启程
- 功法
- 法器

不要在起手页直接堆叠：

- 隐藏标签代码
- 过多百分比
- “你正在选择某条道途”的系统提示

玩家应先感受到的是“故事和去向”，再逐步理解“这一局的方向和构筑”。
