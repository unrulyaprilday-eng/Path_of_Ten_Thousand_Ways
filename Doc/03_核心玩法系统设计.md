# 核心玩法系统设计

> 本文档定义玩家一局游戏中的核心操作、系统边界和循环关系。项目定位见 `01_核心框架设计.md`，开局结构见 `26_开局结构与启程系统设计.md`，地图与节点细则见 `15_地图与节点体系.md`，战斗表现与时间规则见 `04_战斗场景规则设计.md`。

## 1. 核心玩法闭环

```text
首页整备传承道痕
↓
定根脚
↓
受信物：选择启程线与启程信物
↓
入首境与节点地图
↓
战斗或事件
↓
获得卡牌、功法、法器或资源
↓
强化当前构筑
↓
挑战阶段 Boss
↓
结算并回到局外成长
```

设计目标：

- 开局先给身份与出山理由。
- 中段通过节点和奖励逐步显化道途。
- 战斗中持续演算飞剑、法器、功法和敌方行动。
- 玩家用抽到的牌低频落子，改变这场斗法的走向。
- 后段以 Boss 检验“这一世修成了什么道”。

## 2. 开局层

开局层负责建立这局的叙事和起势，不承担完整构筑。

### 2.1 传承道痕

局外整备项，提供轻偏置：

- 启程候选保证。
- 少量路线或奖励权重修正。
- 情报、重掷或预览便利。

传承道痕不能直接替代单局构筑。

### 2.2 根脚

根脚负责：

- 说明玩家从哪里来。
- 提供轻量身份偏置。
- 决定可见启程线池。

根脚不直接锁定唯一启程信物。它只决定“这个身份下会出现哪些启程故事”。

### 2.3 启程线与启程信物

启程线负责：

- 给出出山理由。
- 绑定一个启程信物。
- 给出起手偏向。
- 引出合理首境候选。

启程信物是启程线的一部分，不是独立物品池。它更像一段命运线索和弱化起手法器，负责本局第一推力，但不能直接锁死终局道途。

## 3. 节点式肉鸽地图

节点地图负责提供：

- 路线选择。
- 风险收益。
- 流派成型速度。
- 首境气质延续。

节点类型建议保留：

| 节点 | 功能 |
| --- | --- |
| 普通战斗 | 基础构筑推进 |
| 精英 | 高风险高收益 |
| 事件 | 代价选择和奇遇 |
| 商店 | 修正构筑 |
| 修炼 | 恢复与强化 |
| 洞府 | 功法获取与悟道 |
| 秘藏 | 法器与高价值奖励 |
| Boss | 阶段检验 |

## 4. 玩家决策层

核心玩法把玩家决策拆成六层：

| 层级 | 发生位置 | 主要决策 |
| --- | --- | --- |
| 整备决策 | 首页 | 装备哪枚传承道痕，是否进入新一世 |
| 身份决策 | 开局 | 接受当前根脚还是改命 |
| 启程决策 | 开局 | 选择哪条启程线与启程信物 |
| 首境决策 | 开局 | 这条启程线先引向哪里 |
| 路线决策 | 地图 | 选择稳、险、构筑或资源路线 |
| 构筑决策 | 奖励与商店 | 选择卡牌、功法、法器、升级方向 |
| 战斗决策 | 半实时战斗 | 何时出牌、留灵气、触发主动法器或释放神通 |

## 5. 战斗系统边界

当前战斗主定义：

> 牌库驱动的半实时斗法。

系统分工：

| 系统 | 职责 | 前台感受 |
| --- | --- | --- |
| 卡牌 | 玩家主动打出的低频决策 | 我抽到了什么，现在是否要落子 |
| 灵气 | 持续增长的出牌资源 | 我是在攒势还是抢节奏 |
| 飞剑 | 高频自动输出与视觉爽点 | 斗法一直在发生 |
| 功法 | 长期循环、资源转化、神通入口 | 这一局怎么修 |
| 法器 | 规则强化、自动触发、少量主动爆点 | 靠什么器把规则推强或推歪 |
| 状态 | 可积累、可消耗、可转化的战斗资源 | 构筑方向正在变清楚 |

设计底线：

- 卡牌不能退化成固定技能栏。
- 法器和功法不能全部变成需要频繁点击的主动技能。
- 灵气持续增长后，玩家仍要受手牌、牌库、弃牌、冷却和构筑随机性约束。
- 飞剑与敌人持续演算，保证屏幕体验像修士斗法，而不是静态站桩卡牌。

## 6. 道途系统

完整版本中，道途不作为独立按钮直接裸选。

道途由以下信息共同显化：

- 根脚底色。
- 启程线偏向。
- 启程信物效果。
- 首境奖励口味。
- 已获得功法。
- 已获得法器。
- 已选卡牌标签。
- 战斗中实际形成的状态循环。

道途的作用：

- 控制单局方向。
- 收束奖励池。
- 让 Boss 检验有的放矢。

## 7. 奖励系统边界

前台奖励类型建议收口为四类：

1. 卡牌
2. 功法
3. 法器
4. 资源

奖励设计原则：

- 早期提供方向感。
- 中期补足循环组件。
- 后期提供质变法器、神通或规则修改。
- 奖励应和根脚、启程线、启程信物、首境以及当前构筑共同相关。

## 8. 系统接口

| 系统 | 输入 | 输出 |
| --- | --- | --- |
| 开局 | 传承道痕、根脚池、启程线池 | 本局起势与首境 |
| 地图 | 首境模板、节点权重、玩家状态 | 下一节点选择 |
| 战斗 | 牌库、功法、法器、敌人配置 | 胜负、奖励、损耗 |
| 奖励 | 根脚、启程线、首境、当前构筑 | 卡牌 / 功法 / 法器候选 |
| 商店 | 货币、当前构筑、首境偏向 | 商品列表与刷新 |
| Boss | 层数、流派完成度、法器结构 | 阶段挑战与通关判断 |

## 9. 核心体验标准

一局体验成立时，玩家应能清楚感受到：

- 这一世我是谁、为何出山、带着什么启程信物。
- 这次起手与上一次不一样。
- 战斗一直在演算，我不是等回合，而是在找出牌时机。
- 第 1 层末到第 2 层初，我已经知道自己大概要修什么。
- 中期功法与法器开始一起运转。
- 后期出现明确爆发窗口。
- Boss 战检验了这一局修成的道。
