# 所携与所往开局规则

> 本文是当前开局结构的执行口径。它替代旧的“启程线 + 启程信物 + 入首境”前台分层；历史字段可在迁移期保留兼容，但新功能不得继续依赖旧语义。

## 1. 前台流程

```text
开卷 / 道痕整备
↓
定根脚
↓
所携
↓
所往
↓
初战
↓
战后所得
↓
三层前路与逐战奖励
↓
Boss
↓
一世结算
↓
再启一世
```

| 页面 | 玩家问题 | 系统职责 |
| --- | --- | --- |
| 定根脚 | 我这一世是谁 | 决定身份、叙事候选池与轻量节点偏向。 |
| 所携 | 我带走什么 | 选择一件有来历的器物，决定器物大类、基础战斗语法、初始牌组、首层偏向与所往候选。 |
| 所往 | 我先去哪里 | 在所携器物牵引出的 2-3 个合理去处中落下第一脚。 |
| 初战 | 这里先要我面对什么 | 用最低复杂度战斗兑现器物基础语法与场景气质。 |
| 前路 | 接下来怎样修下去 | 首战奖励后选择节点顺序、风险与补强节奏，不能重选器物大类。 |

前台只使用“所携”“所往”。`首境`、`journey_vessel`、`first_region` 是策划与程序术语，不直接占用玩家页面标题。

## 2. 所携器物

所携器物是“引你入道的临行之物”，不是一件完整法器、不是主修功法、也不是终局 Build。

每件器物必须同时承担五项职责：

1. 叙事：它为何会落到玩家手里，必须和根脚人物关系或旧事有关。
2. 器物大类：飞剑、鼎、法书、阵盘等。它只规定大方向，不规定最终套路。
3. 基础语法：决定最基础自动执行物与首战可读反馈。
4. 初始载入：提供 5 张左右的基础牌组；不得包含主修、正式法器、遗珍或终结牌。
5. 路径牵引：提供首层奖励标签偏向和 2-3 个合理所往候选。

### 2.1 系统职责边界

| 系统 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| 根脚 | 身份、故事候选、轻偏置 | 直接决定流派或赠送核心组件 |
| 所携器物 | 器物大类、基础语法、基础牌组、首层口味 | 赠送主修功法或完成 Build |
| 卡牌 | 当下如何介入战斗 | 长期定道 |
| 功法 | 本局循环规则与主修方向 | 开局身份 |
| 法器 | 局内规则放大或改写 | 取代所携器物 |
| 前路与节点 | 获取顺序、风险收益与补强机会 | 重置器物大类 |

所携器物决定“我靠什么开始修”；功法、法器和关键牌决定“我这一局最终修成什么”。

### 2.2 当前与未来器物

| 器物大类 | 所携示例 | 可形成的后续方向 | P0 状态 |
| --- | --- | --- | --- |
| 飞剑 | 残剑胚、旧剑匣 | 万剑、蓄势一剑、雷剑、血剑 | 完整开放 |
| 鼎 | 百草旧鼎、残炉 | 丹火、炼化、毒丹、资源循环 | 仅保留配置接口，不可选 |
| 法书 | 无字法书、残卷 | 雷法、火法、符箓、召唤 | 仅保留配置接口，不可选 |
| 阵盘 | 破阵盘、古印 | 阵法、机关、自动连锁 | 后续扩展 |

P0 只完整开放“世家旁支 -> 残剑胚 -> 旧矿地窟 -> 万剑齐飞”。未拥有完整卡池、功法、法器、地图叙事和 Boss 检验的器物不得作为可点击选项。

## 3. 起手、战斗与成长节奏

开局严格只有一把飞剑与 5 张基础牌：2 张剑气斩、2 张剑遁、1 张踏云遁。玩家没有凝剑诀、主修、辅修、神通、正式法器和遗珍。

凝剑诀不在初始牌组，只在首战固定奖励与后续保底出现。该规则覆盖旧首战文档和旧后备配置。

半实时基准：

| 项目 | 当前值 |
| --- | ---: |
| 初战 / 普通初始灵气 | 1 / 2 |
| 灵气上限与恢复 | 10；每秒 1 |
| 初战 / 普通初始手牌 | 3 / 4 |
| 手牌上限 | 7 |
| 自动抽牌 | 每 4 秒 1 张；满手暂停 |
| 飞剑齐射 | 每 2.2 秒 |
| 临时飞剑 | 参与 3 次齐射后消散 |
| 敌方意图 | 5-7 秒；Boss 分阶段 |

强制成长门槛：

| 阶段 | 必须获得或理解的内容 | 禁止提前投放 |
| --- | --- | --- |
| 初战前 | 1 把飞剑、5 张基础牌 | 主修、正式法器、遗珍、终结牌 |
| 首战所得 | 固定凝剑诀 / 踏云遁 / 聚灵换息 | 神通、剑阵、终结牌 |
| 第一层末 | 启动牌与至少 2-3 个万剑组件 | 神通和终结牌 |
| 第二层 | 小诛仙剑阵；御剑诀或剑匣至少一个 | 无代价毕业 |
| 第三层 | 必出现万剑诀；高风险可有万剑归宗 | Boss 后补发核心 |
| Boss | 飞剑增殖、剑意积累、剑阵运转与明显爆发 | 重新选择流派 |

P0 万剑 Build 的最小席位：

    凝剑诀（启动）
    ↓
    小诛仙剑阵（循环）
    ↓
    御剑诀或剑匣（引擎）
    ↓
    万剑诀（收束）

奖励固定为 Focus / Utility / Wildcard 三槽，连续两次未出现主轴组件后触发 Focus 保底。Boss 前生存保底必须替换 Utility 槽，不能覆盖万剑诀所在的 Focus 槽。
## 4. 世家旁支 P0 叙事

```text
祖龛坍塌
↓
你携残剑胚离开族地
↓
残剑胚与旧矿矿契共鸣
↓
发现旁支曾被用作镇压劫铁的血契
↓
在矿脉深处斩断旧契
↓
天劫化身现身
↓
以本局修成的剑道破劫
```

残剑胚是故事证物和飞剑起手载体；它不是局外数值装备。它在 P0 中只保证一把基础飞剑存在感，飞剑数量、剑意、剑阵与爆发必须由本局构筑产生。

## 5. 局外成长

P0 局外成长只做“解锁更多选择”，不保留上一局战力。

DemoMetaProgress 使用版本化持久化，记录：

- 完成局数与 Boss 胜利数。
- 卡牌、功法、法器图鉴记录。
- 解锁 ID。

不保存当前牌组、飞剑数量、功法、法器、生命、灵气或地图进度，也不实现中途存档。

首次击败天劫解锁残剑道痕。下一世在开卷整备时可以：

- 不携道痕，保持原首战奖励。
- 携残剑道痕，让首战所得获得一次重铸机会。

重铸消耗后将固定首战候选切换为标准万剑三槽候选，只改变选择，不提供永久攻击或生命加成。

局内 Relic 不建立独立前台系统。现有数据只保留兼容，P0 奖励池与摘要统一使用卡牌、功法、法器和资源。
## 6. 配置契约

新开局数据以 `journey_vessels.csv` 为主表，每条记录对应一个可被根脚提供的所携器物。

| 字段 | 含义 |
| --- | --- |
| `vessel_id` | 器物唯一标识 |
| `root_id` | 所属根脚 |
| `name` | 所携页显示名 |
| `origin_text` | 来历与人物关系文案 |
| `vessel_type` | sword / cauldron / spellbook / array |
| `starter_pool_id` | 该器物选择后载入的基础卡池 |
| `base_style` | 无主修时的奖励与战斗风格回退 |
| `first_region_id` | 所往页强推荐去处 |
| `region_candidate_ids` | 所往候选，使用 `|` 分隔 |
| `risk_level` | 前台风险标签 |
| `summary_tags` | 首层掉落偏向与 UI 标签 |
| `is_available` | 是否可在当前 DEMO 被选择 |

规则：

- 根脚只决定候选池；器物只决定大类与轻偏置；功法才是真正定道来源。
- 选择器物后必须清空默认占位牌组，并按 `starter_pool_id` 载入基础牌组。
- 选择器物绝不能调用主修功法授予逻辑，也不得重置为流派成型牌组。
- 所往页只读取当前器物的区域候选，不从全区域池自由选择。
- 配置缺失时应显式回退到安全基础牌组，而不是偷偷赠送成型构筑。

## 7. 验收

1. 根脚、器物和地图均展示完整入口，但只有世家旁支、残剑胚和旧矿地窟可点击。
2. 残剑胚牌组恰好为 5 张基础牌，凝剑诀不在其中，主修为空，法器与遗珍为空。
3. 所往候选来自残剑胚配置；旧矿可进入，祖地旧库与迷林药谷显示锁定。
4. 选定所往后直接进入半实时初战，不出现主修授予或牌组重置。
5. 首战胜利后自动进入固定三选一；奖励领取后直接进入第一层前路，不经过独立通用奖励节点。
6. 第一层禁止终结，第二层保证剑阵与引擎，第三层保证万剑诀，高风险可额外获得万剑归宗。
7. 完整三层路线能够通过 node_id / encounter_id / reward_profile_id / action_profile_id 抵达天劫化身与一世结算。
8. 胜负结算显示抵达层数、核心组件、最大飞剑、最高爆发、Boss 结果和新解锁。
9. 首次 Boss 胜利只解锁一次残剑道痕；重铸只影响首战奖励，不继承局内战力。
10. 配置生成、CompileCheck、固定种子烟测、git diff --check 和 Unity 连续截图全部通过。
