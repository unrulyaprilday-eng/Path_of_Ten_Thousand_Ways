# Path of Ten Thousand Ways - P0 首页 UI 方案

> 本文档用于补齐当前 DEMO 的首页 / 首屏入口设计，服务 `DEMO 0.4` 之后的第一眼品牌判断、开始路径和功能入口。  
> 依据文档：`Doc/23_DEMO第一阶段设计.md`、`Doc/21_美术资源生成规范.md`、`Doc/22_项目资源生产手册.md`。  
> 取舍说明：当前 DEMO 仍以“单局构筑 -> 三层节点 -> 天劫 Boss”为核心，因此首页不做重社交大厅，不做宗门经营首页，优先做“品牌首屏 + 继续游戏 / 开始新局 / 图鉴占位”的轻入口。  
> 本会话只处理首页，不处理起手道途三选一页的资源和版式。

## 1. 首页目标

首页要先完成三件事：

1. 第一眼传达“黑白水墨修仙 + 天劫压境 + 构筑道途”的品牌气质。
2. 第二眼让玩家知道这是一个可以立刻开始单局构筑的游戏，而不是传统 MMO 大厅。
3. 第三眼把玩家顺滑送进现有新局流程，不要在首页消耗太多阅读成本。

首页不是信息堆场，而是一个短停留、高识别、强氛围的入口页。

## 2. 首页在当前 DEMO 中的定位

当前运行时流程更接近“直接进入起手节点”。  
首页接入后，推荐流程改为：

```text
品牌首页
↓
开始新局 / 继续上次
↓
现有新局流程
↓
节点推进
↓
Boss / 结算
```

因此首页只承担：

- 品牌展示
- 进入单局
- 查看基础记录
- 设置与退出

当前 DEMO 不在首页承担：

- 宗门经营
- 长线局外成长树
- 邮件 / 活动 / 商城
- 多角色切换

## 3. 信息架构

首页建议分为 5 个区块：

1. 背景主视觉区
2. 左上品牌区
3. 中左主操作区
4. 右下运行信息区
5. 右上轻功能区

页面结构示意：

```text
+--------------------------------------------------------------+
| Logo / Slogan                                  设置  图鉴  退出 |
|                                                              |
|                                                              |
|   [开始新局]                                                 |
|   [继续悟道]                                                 |
|   [流派图鉴]                                                 |
|   [设置]                                                     |
|                                                              |
|                 黑白水墨天穹 / 巨物压境主视觉                 |
|                                                              |
|                                                              |
|                                         DEMO 0.4             |
|                                         最近一局：雷剑 / 第2层 |
|                                         已解锁流派：3         |
+--------------------------------------------------------------+
```

## 4. 布局设计

### 4.1 背景主视觉

用途：

- 扛住首页 70% 的品牌气质。
- 传达“孤身修士面对天威”的压迫感。
- 给左侧按钮和顶部 Logo 留足留白。

构图要求：

- 16:9 横版。
- 左上留 Logo 区。
- 中左留按钮区。
- 中央到右侧由主视觉承担世界观压迫感。
- 不要把主体卡死在正中，避免和按钮冲突。

建议视觉关系：

- 近景：孤立修士或悬崖边缘。
- 中景：云海、仙山、断台。
- 远景：巨型天威、龙形劫影、天门裂隙或雷云压境。

### 4.2 左上品牌区

内容：

- 游戏中文标题：`万道归途`
- 英文副标可选：`Path of Ten Thousand Ways`
- 一行短标语

推荐文案方向：

- “修仙不是打怪升级，而是构筑一条属于自己的道途。”

表现要求：

- 标题不放在卡片里。
- 直接压在背景留白上。
- 用淡金或暖白，不做高饱和描边。

### 4.3 中左主操作区

主按钮从上到下建议为：

1. `开始新局`
2. `继续悟道`
3. `流派图鉴`
4. `设置`

其中：

- `开始新局` 是默认高亮主 CTA。
- `继续悟道` 在无存档时置灰或替换为 `暂无未完成道途`。
- `流派图鉴` 当前可先接简版统计面板或占位页。
- `设置` 打开轻量弹窗。

按钮风格：

- 深色卷轴按钮底板。
- 左侧小图标，右侧文字。
- hover 时出现轻微流墨、描金提亮或边缘气流。
- 不做现代扁平矩形按钮。

### 4.4 右下运行信息区

内容建议：

- 当前版本：`DEMO 0.4`
- 最近一局流派：如 `最近一局：万剑 / 第3层`
- 最远进度：如 `最远抵达：天劫化身`
- 已解锁图鉴数：如 `图鉴：12 / 30`

作用：

- 给首页一点“这不是纯海报”的运行感。
- 但信息密度不能喧宾夺主。

表现方式：

- 半透明小卷轴签或简洁竖排签条。
- 贴右下，不做大面板。

### 4.5 右上轻功能区

建议放 3 个图标按钮：

- `图鉴`
- `设置`
- `退出`

如果左侧已有图鉴 / 设置文字入口，这里保留：

- `设置`
- `全屏`
- `退出`

原则：

- 右上只放低频功能。
- 不放商城、邮件、活动、充值这类破坏 DEMO 气质的入口。

## 5. 交互与状态

### 5.1 默认状态

- 镜头静止，背景有极弱云雾漂移。
- Logo 缓慢呼吸。
- 主按钮有 2-3 秒一轮的微弱流光。
- 背景主视觉允许非常轻的雷光明灭。

### 5.2 Hover / Focus

按钮 hover：

- 边框提亮。
- 图标轻微上浮或内发光。
- 背后出现低透明墨痕扩散。

Logo 区 hover：

- 不做复杂反馈，避免像网页营销首屏。

右上图标 hover：

- 出现小型卷轴 tooltip。

### 5.3 点击流程

`开始新局`

- 背景轻微压暗。
- Logo 与按钮区向后收。
- 过渡到起手道途三选一页。

`继续悟道`

- 直接恢复到最近节点。

`流派图鉴`

- 打开一层半透明器面浮层。
- 当前 DEMO 可先显示：已体验流派、已见 Boss、已获得法宝。

`设置`

- 打开轻量设置浮层。

### 5.4 无存档状态

当玩家首次进入时：

- `继续悟道` 为 disabled。
- 右下信息显示 `尚未立道`
- 主按钮更强调 `开始新局`

### 5.5 已通关一局状态

结算返回首页后：

- 背景可切到更明亮一版，或额外出现一道渡劫后的金痕。
- 右下显示最近一次通关流派。
- 首页文案从“踏上道途”转为“再证新道”。

## 8. 资源风格要求

### 8.1 首页主视觉

方向：

- 黑白水墨为主。
- 气质重于叙事细节。
- 要像“品牌首页”，不是战斗截图。

必须具备：

- 大留白。
- 天威压迫感。
- 修士个体渺小感。
- 能承接左上标题和左侧菜单。

避免：

- 满屏动作戏。
- 中央堆主体导致按钮没地方放。
- 高饱和蓝紫奇幻感。
- 类页游登录海报。

### 8.2 按钮资源

要求：

- 按钮不是平面白字条。
- 需要有器物感、卷轴感、旧纸 / 金属混合材质。
- 主按钮和次按钮通过边饰、明度和描金层级拉开差异。

### 8.3 图标资源

要求：

- 线性 + 实心结合。
- 2px 线宽趋势。
- 水墨金属质感。
- 不用现代系统图标风。

推荐图标语义：

- 图鉴：书卷 / 玉简
- 设置：机关盘 / 八卦轮
- 退出：山门 / 离印

## 10. 实现建议

推荐接入顺序：

1. 先实现首页静态结构。
2. 接入 `ui_home_hero_ink_001.png`。
3. 接入左侧主按钮与右下信息签。
4. 把 `开始新局` 接到现有新局入口流程。
5. 再补图鉴 / 设置浮层。

推荐代码拆分：

- `DemoHomeScreenView.cs`：首页视图构建与状态刷新
- `DemoHomeScreenState.cs`：记录首页显示状态
- `DemoRuntimeCanvasUI.cs`：只负责在首页 / 起手页 / 战斗页之间切换

## 11. 最小验收标准

首页设计成立的标准：

- 截图单独拿出来时，已经像游戏首页而不是程序占位画布。
- 玩家 3 秒内知道主操作是“开始一局修仙构筑”。
- 首页与当前战斗 / 奖励 / 新局流程在风格上连续，不像两个项目。
- 右下信息区足够轻，不抢主视觉。
- 即使先不接完整图鉴 / 设置，首页本身也已具备对外展示价值。
