# Path of Ten Thousand Ways - Unity DEMO

这是第一阶段 DEMO 的 Unity 目录骨架和可玩规则原型。

## 当前版本目标

当前版本是 `DEMO 0.4`，当前已验证：

- 三次路线分叉驱动的三层小地图，替代原先的线性闯关。
- 半即时规划 / 演武战斗。
- 抽牌、费用、出牌、弃牌。
- 飞剑自动攻击。
- 剑意、感电、流血三种核心状态。
- 战斗胜利后的奖励三选一。
- 终局 Boss：天劫化身。
- 运行时 Canvas UI，替代原先的 IMGUI 原型面板。
- 空中斗法战场原型：分层云海、御剑悬浮、顺序飞剑结算、命中反馈与伤害浮字。
- Boss 三阶段原型：雷云压境、天雷锁魂、天劫降临，含预警与蓄雷窗口。
- DEMO 法宝原型：剑匣、昊天镜、紫金葫芦、雷印，已接入战斗规则与补强节点。
- 简化功法原型：主修 / 辅修 / 神通三段式长期被动选择，爽点更多落在构筑后的演武连锁。
- 水墨强化版战场表现：流云层、暖火星、疾电分叉、笔刷擦染与命中晕墨。
- 战斗 UI 架构重构：顶部战况栏、左侧道途栏、中央主舞台、底部手牌带、右侧上下文面板。
- UI 水墨化深化：暗色卷轴器面、墨金边饰、功法/奖励/卡牌器物化排版，开始向商业化卖相收束。
- 起手立道入口升级：三张大幅水墨道途牌直接承担首屏门面，弱化 Hover，强化展示感与选择决心。
- 当前视觉目标已重新锚定：主页面参考黑白水墨巨物压境的品牌首屏；道途选择参考纵向展示海报式三联牌；战斗舞台参考大角度空中对峙，但整体改为黑白水墨气质。
- 战场 HUD 升级：阶段卷轴、左右战况签、Boss 天机预警签，主舞台信息层更接近正式产品。
- 商业化识别层补强：卡牌、奖励、功法、法宝加入图标字印与品质色阶，信息分档开始从文本走向视觉识别。
- 第一批真实资源生成准备：已整理 AI 批量出图提示词包，优先覆盖卷轴底板、卡牌边框、云海战场和天劫 Boss 立绘。

## 使用方式

1. 用 Unity 当前 LTS 版本打开 `UNITY/` 目录。若 Unity Hub 提示版本不同，可选择本机已安装的 LTS 版本继续打开。
2. 创建或打开任意空场景。
3. 点击 Play。
4. `DemoBootstrap` 会自动生成 `DEMO_GameController`，屏幕上会出现运行时搭建的 Canvas 原型界面。
